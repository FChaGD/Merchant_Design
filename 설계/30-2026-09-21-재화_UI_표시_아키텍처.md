## 1. 명명에 대한 결정 — "Panel"이 아니라 "Hud"

27번 문서는 이 UI를 "재화 패널"이라 부르지만, `IUIPanel`(`UIManager.Open/Close`로 제어)이 아니다 — 열고 닫는 화면이 아니라 항상 떠 있는 상태 표시다. CLAUDE.md 명명 규칙상 `XxxPanel`은 "화면 단위 조율자"에 쓰는 접미사라 여기 쓰면 오해를 부른다. 대신 상시 노출 UI 요소를 다루는 기존 사례인 `HubUIController`와 같은 성격으로 분류하고, 클래스명은 `PlayerCurrencyHudController`로 짓는다.

## 2. 렌더링 순서 — 기존 컨벤션의 반대 방향 적용

`HubSceneInstaller.BuildTacticsUI`(현재 82-115줄)에 이미 "상시 노출 요소 vs 모달 패널" 렌더 순서를 다루는 정확한 선례가 있다. 그 요약 주석: "늦은 형제일수록 위에 그려지는 Unity UI 특성상, 상시 노출 버튼이 모달 패널보다 뒤에 있으면 모달이 열려 있어도 그 위로 떠 보인다" — 그래서 TacticsButton은 모달들보다 **앞쪽**(먼저) 형제로 강제된다. `FormationDragCoordinator`/`FormationGridView`의 드래그 고스트·경로선·이동 아이콘은 반대로 `SetAsLastSibling()`으로 항상 맨 위에 오도록 강제한다.

27번 §3.5(다른 패널이 열려도 재화 HUD는 가려지지 않는다) 결정에 따라, 이번 HUD는 **드래그 고스트와 같은 방향**을 택한다 — 설치 시 `SetAsLastSibling()`으로 Formation/Trip/Tactics 패널 및 TacticsButton보다 항상 늦은 형제가 되게 강제한다. Hub의 Canvas는 단일 Canvas이고(`HubSceneInstaller.EnsureContentRoot`, 중첩 Canvas/overrideSorting 없음) 형제 순서만으로 렌더 깊이가 결정되므로 이 방식으로 충분하다. 씬 전환 커튼(`SceneTransitionCanvas`, sortingOrder=100)은 별도 Canvas라 이 순서와 무관하게 항상 그 위에 그려진다 — 전환 연출 중에는 커튼이 HUD도 정상적으로 가린다.

## 3. 새 컴포넌트 — `PointerHoverRelay` (범용 재사용 가능)

위치: `Core/UI/PointerHoverRelay.cs`. 프로젝트에 호버 감지 컴포넌트가 아직 없어(조사 완료) 최소 형태로 신설한다 — 특정 기능(재화)에 종속되지 않는 이름으로 지어 이후 다른 툴팁에도 재사용한다.

```csharp
using System;
using UnityEngine;
using UnityEngine.EventSystems;

namespace Game.Core
{
    /// <summary>
    /// 마우스 호버 진입/이탈을 이벤트로 중계하는 범용 컴포넌트. 특정 UI 로직을 모른다 -
    /// 툴팁을 띄우는 쪽(PlayerCurrencyHudController 등)이 이 이벤트를 구독해 자신의 표시 로직을 수행한다.
    /// </summary>
    public class PointerHoverRelay : MonoBehaviour, IPointerEnterHandler, IPointerExitHandler
    {
        public event Action PointerEntered;
        public event Action PointerExited;

        public void OnPointerEnter(PointerEventData eventData) => PointerEntered?.Invoke();
        public void OnPointerExit(PointerEventData eventData) => PointerExited?.Invoke();
    }
}
```

## 4. 새 컴포넌트 — `IPlayerCurrencyHudController` / `PlayerCurrencyHudController`

위치: `Core/UI/`(Hub 전용 상시 노출 컨트롤러 자리, `HubUIController`와 동일 폴더).

```csharp
namespace Game.Core
{
    public interface IPlayerCurrencyHudController
    {
        void RegisterCurrencyUI(SceneUIRoot sceneUIRoot, IPlayerCurrencyReader currencyReader);
    }
}
```

```csharp
using TMPro;
using UnityEngine;
using UnityEngine.UI;

namespace Game.Core
{
    /// <summary>
    /// Hub 재화 HUD - 현재값만 상시 표기하고 상한은 호버 시 툴팁으로 보여준다(기획 27번 §3.2).
    /// 다른 패널이 열려도 가려지지 않아야 하므로(27번 §3.5) HubUIController의 OnAnyPanelOpenChanged
    /// 숨김 로직을 따르지 않는다 - 렌더 순서로만 항상 위에 오도록 인스톨러가 보장한다(§2).
    /// </summary>
    public class PlayerCurrencyHudController : MonoBehaviour, IPlayerCurrencyHudController
    {
        [SerializeField] private Sprite currencyIcon;

        private IPlayerCurrencyReader currencyReader;
        private TMP_Text amountText;
        private GameObject capacityTooltipRoot;
        private TMP_Text capacityTooltipText;

        public void RegisterCurrencyUI(SceneUIRoot sceneUIRoot, IPlayerCurrencyReader currencyReader)
        {
            if (!sceneUIRoot.TryGetElement<RectTransform>(HubUIElementIds.CurrencyPanelRoot, out var panelRoot)
                || !sceneUIRoot.TryGetElement<TMP_Text>(HubUIElementIds.CurrencyAmountText, out amountText))
            {
                Debug.LogWarning($"Hub UI에서 재화 HUD 요소를 찾을 수 없다. {nameof(UIElementMarker)}가 부착되어 있는지 확인하라.");
                return;
            }

            this.currencyReader = currencyReader;

            // 재화 지갑이 아직 등록되지 않았으면(인스톨러 미실행 등) HUD 전체를 숨긴다 - 값 없이 "0"을
            // 보여주는 건 오해를 부른다(CLAUDE.md "값이 없으면 창작하지 말 것").
            if (currencyReader == null)
            {
                panelRoot.gameObject.SetActive(false);
                return;
            }

            if (sceneUIRoot.TryGetElement<Image>(HubUIElementIds.CurrencyIcon, out var icon) && currencyIcon != null)
            {
                icon.sprite = currencyIcon;
            }

            RefreshAmount(currencyReader.CurrentAmount);
            currencyReader.OnAmountChanged += RefreshAmount;

            if (sceneUIRoot.TryGetElement<RectTransform>(HubUIElementIds.CurrencyCapacityTooltip, out var tooltipRoot)
                && sceneUIRoot.TryGetElement<TMP_Text>(HubUIElementIds.CurrencyCapacityTooltipText, out capacityTooltipText)
                && sceneUIRoot.TryGetElement<PointerHoverRelay>(HubUIElementIds.CurrencyAmountText, out var hoverRelay))
            {
                capacityTooltipRoot = tooltipRoot.gameObject;
                capacityTooltipRoot.SetActive(false);
                hoverRelay.PointerEntered += ShowCapacityTooltip;
                hoverRelay.PointerExited += HideCapacityTooltip;
            }
        }

        private void RefreshAmount(int amount) => amountText.text = amount.ToString("N0");

        private void ShowCapacityTooltip()
        {
            capacityTooltipText.text = $"상한 {currencyReader.Capacity:N0}";
            capacityTooltipRoot.SetActive(true);
        }

        private void HideCapacityTooltip() => capacityTooltipRoot.SetActive(false);
    }
}
```

`HubUIElementIds.CurrencyAmountText`로 조회한 같은 GameObject에서 `TMP_Text`와 `PointerHoverRelay` 둘 다 얻는다 — 호버 대상이 곧 수치 텍스트 자신이라 별도 "행" 오브젝트를 만들 필요가 없다(27번 §3.1 "아이콘+수치"만 요구, 별도 배경 프레임 요구 없음). 다만 이 텍스트는 `EnsureLabel`이 기본값으로 끄는 `raycastTarget`을 인스톨러에서 다시 켜야 포인터 이벤트를 받는다(§6, 2026-09-21 실전 확인).

툴팁은 프레임(`CurrencyCapacityTooltip`, 배경 Image)과 텍스트(`CurrencyCapacityTooltipText`, TMP_Text)를 **서로 다른 GameObject**(부모/자식)로 분리한다 — 최초안은 배경+텍스트를 한 GameObject에 합쳐 `SetActive` 한 번으로 같이 토글하려 했으나, `Image`가 이미 붙은 GameObject에 `TextMeshProUGUI`를 추가로 붙이는 시도가 `AddComponent` 실패로 이어져 `NullReferenceException`이 났다(2026-09-21 실전 확인). 기존 버튼류(`EnsureImage`+자식 `EnsureLabel`)와 같은 구조로 되돌려 해결했다 — 컨트롤러는 프레임을 `SetActive`로 토글하고 텍스트는 내용만 갱신한다.

## 6. `HubSceneInstaller` — HUD 생성

`BuildTacticsUI`와 같은 자리(콘텐츠 씬 전용 시각 요소)에 새 메서드를 추가하고 `BuildHubScene()`에서 호출한다.

```csharp
private static void BuildPlayerCurrencyHud(Transform contentRoot)
{
    // 퍼센트 앵커 박스(고정 크기)로 만들었다가, 아이콘(32px 고정)이 박스보다 커서 밖으로 튀어나오고
    // 텍스트는 남은 폭이 모자라 짜부라지는 문제가 있었다(2026-09-21 실전 확인) - 한 점에 고정하고
    // ContentSizeFitter로 내용(아이콘+텍스트+패딩)에 맞춰 패널 크기가 스스로 결정되게 바꿨다.
    var root = EditorUIBuilder.GetOrCreateUIObject(contentRoot, "PlayerCurrencyHud");
    var rootRect = root.GetComponent<RectTransform>();
    rootRect.anchorMin = new Vector2(0f, 1f);
    rootRect.anchorMax = new Vector2(0f, 1f);
    rootRect.pivot = new Vector2(0f, 1f);
    rootRect.anchoredPosition = new Vector2(16f, -16f);
    EditorUIBuilder.EnsureMarker(root, HubUIElementIds.CurrencyPanelRoot);
    // 패널 배경 - 없으면 아이콘/텍스트만 화면에 떠 있어 "패널 형태"로 보이지 않는다(2026-09-21 실전 확인).
    EditorUIBuilder.EnsureImage(root, new Color(0f, 0f, 0f, 0.6f));

    var layout = EditorUIBuilder.GetOrAddComponent<HorizontalLayoutGroup>(root);
    layout.childAlignment = TextAnchor.MiddleLeft;
    layout.spacing = 8f;
    layout.padding = new RectOffset(8, 8, 4, 4);
    layout.childControlWidth = true;
    layout.childControlHeight = true;
    layout.childForceExpandWidth = false;
    layout.childForceExpandHeight = false;

    var sizeFitter = EditorUIBuilder.GetOrAddComponent<ContentSizeFitter>(root);
    sizeFitter.horizontalFit = ContentSizeFitter.FitMode.PreferredSize;
    sizeFitter.verticalFit = ContentSizeFitter.FitMode.PreferredSize;

    var iconGo = EditorUIBuilder.GetOrCreateUIObject(root.transform, "Icon");
    EditorUIBuilder.EnsureImage(iconGo, Color.white); // currencyIcon 미할당 시 자리표시자
    EditorUIBuilder.EnsureMarker(iconGo, HubUIElementIds.CurrencyIcon);
    var iconLayoutElement = EditorUIBuilder.GetOrAddComponent<LayoutElement>(iconGo);
    iconLayoutElement.preferredWidth = 32f;
    iconLayoutElement.preferredHeight = 32f;

    var amountLabel = EditorUIBuilder.EnsureLabel(root.transform, "0");
    EditorUIBuilder.EnsureMarker(amountLabel.gameObject, HubUIElementIds.CurrencyAmountText);
    EditorUIBuilder.GetOrAddComponent<PointerHoverRelay>(amountLabel.gameObject);
    // EnsureLabel은 기본적으로 raycastTarget=false로 만든다 - 이 텍스트는 호버 대상이라 켜야 한다.
    amountLabel.raycastTarget = true;
    // EnsureLabel 기본 색상은 검정(밝은 배경 버튼 기준) - 이 패널은 어두운 배경이라 흰색으로 바꿔야
    // 보인다(2026-09-21 실전 확인).
    amountLabel.color = Color.white;
    var amountLayoutElement = EditorUIBuilder.GetOrAddComponent<LayoutElement>(amountLabel.gameObject);
    amountLayoutElement.minWidth = 60f;

    // 프레임(Image)과 텍스트(TextMeshProUGUI)를 부모/자식으로 분리한다(기존 버튼류와 같은 구조) -
    // 같은 오브젝트에 Image+TMP를 함께 붙이면 AddComponent가 실패해 NullReferenceException으로
    // 이어진 적이 있다(2026-09-21 실전 확인).
    // anchorMin=(0,0)/anchorMax=(1,0)은 위아래 앵커가 같은 y=0이라 sizeDelta 없이는 높이가 0이다 -
    // 알파를 1로 올려도 덮을 영역이 없어 수치가 그대로 보였다(2026-09-21 실전 확인). 부모(amountLabel)와
    // 완전히 같은 영역을 덮도록 SetStretch로 바꾼다.
    var tooltipGo = EditorUIBuilder.GetOrCreateUIObject(amountLabel.transform, "CapacityTooltip");
    EditorUIBuilder.SetStretch(tooltipGo.GetComponent<RectTransform>());
    EditorUIBuilder.EnsureImage(tooltipGo, new Color(0f, 0f, 0f, 1f)); // 불투명(사용자 확정, 2026-09-21)
    EditorUIBuilder.EnsureMarker(tooltipGo, HubUIElementIds.CurrencyCapacityTooltip);

    var tooltipLabel = EditorUIBuilder.EnsureLabel(tooltipGo.transform, "상한 -");
    EditorUIBuilder.EnsureMarker(tooltipLabel.gameObject, HubUIElementIds.CurrencyCapacityTooltipText);
    tooltipLabel.color = Color.white; // 어두운 배경 기준 - 기본 검정이면 안 보인다.

    tooltipGo.SetActive(false);

    root.transform.SetAsLastSibling(); // §2 - 항상 최상단
}
```

`BuildHubScene()`에 `BuildPlayerCurrencyHud(contentRoot);` 호출 추가(다른 UI들보다 마지막에 — 마지막에 호출해야 `SetAsLastSibling()`이 재실행마다 정확히 유지된다).

우상단 여백값(`anchoredPosition (-16, -16)`, 2026-09-21 변경 — 최초 좌상단 `(16, -16)`에서 이동)은 대략적인 배치 값이다 — 제작 후 Hub 씬에서 실제 크기를 보고 조정한다(27번 §2 "정확한 좌표/크기는 설계/제작 단계 재량").

## 8. `HubUIWiring` — 조회 및 연결

`Wire(...)`(현재 14-81줄)에 추가:

```csharp
var currencyHudController = GetComponent<IPlayerCurrencyHudController>();
if (currencyHudController == null)
{
    throw new InvalidOperationException($"{nameof(HubUIWiring)}와 같은 GameObject에 {nameof(IPlayerCurrencyHudController)} 구현체가 없다.");
}

// InMemoryPlayerCurrencyWallet은 IPlayerCurrencyWallet으로만 DI 등록되어 있다(DependencyManager는
// 정확한 타입 키로만 조회하므로 IPlayerCurrencyReader로는 찾지 못한다) - IPlayerCurrencyWallet으로
// 조회한 뒤 컨트롤러에는 IPlayerCurrencyReader 타입으로만 넘긴다(ISP, 암묵적 업캐스트).
registrar.TryResolve<IPlayerCurrencyWallet>(out var currencyWallet);
...
currencyHudController.RegisterCurrencyUI(sceneUIRoot, currencyWallet);
```

기존 `IFormationRepository` 등과 같은 TryResolve 패턴 — 지갑이 없어도(인스톨러 미실행) Hub UI 전체가 죽지 않는다(§4의 null 처리로 HUD만 숨겨짐).

## 9. 이 설계가 건드리지 않는 것

- `HubUIController`의 상단 버튼 숨김 로직(`HandleAnyPanelOpenChanged`) — 무변경, 재화 HUD는 이 이벤트를 구독하지 않는다.
- `IPlayerCurrencyWallet`/`InMemoryPlayerCurrencyWallet` — 무변경.
- Field 씬 — 이번 설계는 Hub만 다룬다(27번 §2).
- 툴팁의 위치 추적(마우스 커서를 따라다니는 방식) — 고정 위치(수치 텍스트 바로 아래) 툴팁으로 충분하다고 보고 커서 추적은 범위 밖.
- 재화 외 다른 자원 행 추가 — `HorizontalLayoutGroup`을 쓴 것은 이후 행이 늘어날 때 재배치 계산 없이 자연히 옆으로 붙게 하려는 목적이지만, 실제로 행을 추가하는 코드(반복 생성/리스트 관리)는 만들지 않는다(27번 §3.3, 지금은 1행).

## 10. 제작 체크리스트

1. `Core/UI/PointerHoverRelay.cs` 신설(§3).
2. `Core/UI/IPlayerCurrencyHudController.cs`, `PlayerCurrencyHudController.cs` 신설(§4).
3. `HubUIElementIds.cs`에 상수 4개 추가(§5).
4. `HubSceneInstaller.cs`에 `BuildPlayerCurrencyHud` 추가 + `BuildHubScene()`에서 호출(§6).
5. `ManagerHierarchyInstaller.WireUIManagerPanels`에 `PlayerCurrencyHudController` 부착(§7).
6. `HubUIWiring.Wire`에 조회/연결 추가(§8).
7. Unity 컴파일 확인 → `Tools > Game > Build Bootstrap Scene`, `Tools > Game > Build Hub Scene` 재실행 → Ctrl+S로 두 씬(Bootstrap, Hub) 저장.
8. (수동) `PlayerCurrencyHudController.currencyIcon` 필드에 임시 스프라이트 연결(없으면 흰 사각형 placeholder로 보임 — 27번 §2 "아이콘 그래픽 자체는 범위 밖"이라 나중에 교체 가능).
9. 플레이 모드에서 확인: 우상단에 "1,000" 표시 → 수치 위 호버 시 "상한 1,000" 툴팁 → 정비창/상행 준비/방향성 지시 패널을 열어도 HUD가 가려지지 않는지.
