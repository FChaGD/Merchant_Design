# 상행 날짜 흐름 개정 제작계획

작성일: 2026-10-18
설계: [93 상행 날짜 흐름 개정 아키텍처](93-2026-10-18-상행_날짜_흐름_개정_아키텍처.md)
작업 브랜치 `system`. 테스트: `ut.sh ALL`(EditMode). 커밋은 사용자 확인 후.

## 전역 제약
- 하루 = `SecondsPerDay`(기본 30). 궤주 추가 비율 = `RoutDayMultiplier − 1`(0 미만이면 0, 배율 ≤ 0이면 기본 1.5).
- 경계 보정 = 기존 `TravelDayRules` 1e-4일.
- 짧음 = 20초 / 160초. 0일 문구 = "당일 도착".
- 씬은 텍스트 편집 금지 — 인스톨러·CLI SerializedObject.

## 점검 초점(테스트로 고정)
1. 도착 프레임 초과분은 이동에 안 들어간다 → Task 1.
2. 경계 직하 값(89.99999초)에서 나머지가 음수가 되지 않는다 → Task 2.
3. 배율 ≤ 1(추가 비율 0 이하)에서 궤주 추가가 음수가 되지 않는다 → Task 2.
4. 판정 시계가 도착 틱을 세지 않는다(이동 신호 기준) → Task 3 Play 확인.
5. 0일 구간·합계 문구 → Task 5.
