## 4. 구조·변경 상세

### 4.1 보유 목록 계약 확장

```csharp
public interface ICaravanRosterProvider
{
    IReadOnlyList<IFormationUnit> GetRoster();
    // 고용·해고·사망 제거·구매·파괴 등으로 목록이 바뀌면 발생한다.
    event Action RosterChanged;
}
```

- `PlaceholderCaravanRosterProvider`: `OnHiredChanged`·`OnOwnedChanged`를 발생시키는 5곳에서 `RosterChanged`도 발생.
- 테스트 가짜 2곳에 이벤트 추가(빈 구현).

### 4.2 순수 로직

| 클래스 | 책임 |
|---|---|
| `CaravanCompositionCounter`(정적) | 목록 → 마차·시설·캐릭터 수. 표기 `FormatWagons(n)` = `"n"`, `FormatUnits(m, k)` = `"m/k"` |
| `HudUniformFontFitter`(정적) | `Fit(requiredWidthsAtMax, availableWidth, maxSize, minSize)` → `clamp(max × available ÷ Σrequired, min, max)`. Σrequired ≤ 0이면 max. 최소에서도 넘치면 최소(넘친 채 표시) |

### 4.3 `PlayerCurrencyHudController` 변경

- 연결 인자에 `ICaravanRosterProvider roster`(null 허용) 추가 — `IPlayerCurrencyHudController.RegisterCurrencyUI`, `HubUIWiring`이 `TryResolve`로 전달.
- 조회 추가: `CurrencyGoldSection`(중계 2개), `CurrencyWagonCount`, `CurrencyUnitCount`, `CurrencyWagonIcon`, `CurrencyUnitIcon`.
- 같은 GameObject의 `GetComponent<ITooltipController>()`(없으면 `InvalidOperationException`)에 골드 구역의 중계 2개 + 툴팁 띠를 등록해 핸들 보유. 재연결 시 이전 핸들 Dispose.
- 짧은 클릭 → 변환 모달 연결은 골드 구역의 `PointerPressRelay.ShortClicked`로 유지.
- 삭제: `hovering`·`longPressing` 필드, 호버/길게 누름 핸들러, `UpdateTooltip`(→ 공용 컨트롤러).
- `Refresh`(골드 `Changed`·`RosterChanged`):
  1. 금액 문구·색상(현행 그대로).
  2. 보유 수 문구 — `roster`가 null이면 `"-"`.
  3. 툴팁 문구 → `tooltipHandle.SetText(...)`(현행 문구 그대로).
  4. 공통 글자 크기 적용(§4.4).
- 구독 해제(`Unbind`)에 `RosterChanged` 추가. 레이블이 Unity null이면 무시(Hub 언로드 뒤 이벤트 안전).

### 4.4 공통 글자 크기 적용

- 직렬화 값: `maxFontSize`(기본 = 현행 금액 레이블 크기), `minFontSize = 12`.
- 계산: 세 레이블 각각 `GetPreferredValues(text)`를 `maxFontSize` 기준으로 잰 폭 → 남은 폭 = 패널 폭 − 패딩 − 아이콘 폭 합 − 간격 합 → `HudUniformFontFitter.Fit` → 세 레이블 `fontSize`에 같은 값.
- 다시 계산하는 때: `Refresh` 시, 그리고 패널 크기 변경 시(해상도 변경). 후자는 패널 루트에 `RectTransformDimensionsChangeRelay`(범용 중계, `OnRectTransformDimensionsChange` → 이벤트)를 붙여 받는다 — `Update` 폴링 없음.
- 레이블 TMP 자동 크기는 끈다(컨트롤러가 소유).

## 5. 화면 요소·설치

### 5.1 `HubSceneInstaller.BuildPlayerCurrencyHud`

| 요소 | 내용 |
|---|---|
| 패널 루트 | 앵커·폭·여백·가로 레이아웃 유지. 배경 Image `raycastTarget=false`. 루트의 `PointerHoverRelay`·`PointerPressRelay` 제거(옛 구성 정리). `RectTransformDimensionsChangeRelay` 추가 |
| `GoldSection` | 신규 자식: 투명 Image(`raycastTarget=true`) + `PointerHoverRelay` + `PointerPressRelay` + 가로 레이아웃. 기존 `Icon`·금액 레이블을 이 아래로 이동(재부모화, get-or-create 유지) |
| `WagonIcon` / `WagonCount` | 흰 사각형 32×32(`raycastTarget=false`) / 흰 레이블(`raycastTarget=false`, 자동 크기 끔) |
| `UnitIcon` / `UnitCount` | 위와 같음(용병&시설) |
| 툴팁 띠 | 옛 `CapacityTooltip` 정리 후 `EditorUIBuilder.EnsureTooltip(패널 루트, "CapacityTooltip", CurrencyCapacityTooltip, CurrencyCapacityTooltipText)`, `LayoutElement.ignoreLayout`, 위치는 현행(패널 아래 띠, 패널 전체 폭) |
| 요소 Id | `HubUIElementIds`에 `CurrencyGoldSection`, `CurrencyWagonIcon`, `CurrencyWagonCount`, `CurrencyUnitIcon`, `CurrencyUnitCount` 추가 |

- 재실행 안전: 모든 요소 get-or-create, 옛 중계 컴포넌트·옛 툴팁 구조는 정리 로직으로 제거.
- 골드 구역의 Image는 색 알파 0이어도 레이캐스트 대상이 된다(UGUI는 알파와 무관하게 레이캐스트).

### 5.2 디버그 재화 조절 줄

- 패널 높이(아이콘 32 + 패딩)가 바뀌지 않으므로 코드 변경 없음. Play 실측으로 겹침만 점검하고, 겹치면 디버그 쪽 상수를 조정한다.

### 5.3 실행 순서(CLI 직접)

설계 100 반영(Bootstrap `UITooltipController`)이 선행. Bootstrap 열기 → Build Bootstrap → 저장 → Hub 열기 → Build Hub → 저장.

### 6.2 Play(CLI 실측)

- HUD 한 줄: 골드 · 마차 수 · 용병/시설 수.
- 용병 고용 → 용병 수 즉시 증가. 마구간 마차·시설 구매 → 해당 수 즉시 증가.
- 골드 부분: 짧게 클릭 → 변환 모달, 호버·길게 누름 → 툴팁. 마차·용병 부분: 클릭·호버 무반응.
- 디버그로 골드를 크게 올려 폭 초과 → 세 레이블이 같은 크기로 축소.
- 겹침 점검(Game 뷰 실제 해상도): 평상시(날짜 HUD, 디버그 재화 줄 내린 상태, 상단 물류품 버튼), 툴팁 표시 중, 모달 팝업 열린 상태.
- 미확인: 전투 정산 파괴 시 갱신은 Field에서 일어나므로 Hub 복귀 시 다시 그려지는 것만 확인.
