## 1. 목적

설계 120 인게임 테스트 A4에서 잡초·꽃 지대가 바둑판처럼 사각형으로 보였다. 원인은 칸마다 그림을 통째로 바꿔 끼우는 구조 자체다(같은 분류 안에서도 잎 크기·밀도 차이가 칸 경계에서 직선으로 끊김, 기획 119 §11.6). 칸 단위 Tilemap을 버리고 전장 바닥을 메시 1장 + 스플랫 셰이더로 그려 칸 흔적을 원리상 없앤다. 맵 계산·로딩·잘라 쓰기와 기존 전투·카메라·배틀 테스트 동작은 회귀 없이 유지한다.

- 목표: 확대해도 칸 경계 직선 없음, 반복 무늬 없음, 흙 경계는 A3 통과 모양 유지, 드로우 1회.
- 비목표: 지역별 바닥 세트, 조정 값 테이블화, 스플랫을 꼭짓점보다 잘게, 모바일 전용 최적화.
- 반(反)목표: 유닛·마차 등이 바닥 아래로 가려짐, 바닥 밖 빈 배경 노출, 씬 재진입마다 GPU 메모리 누적, 바닥 문제로 전투가 막힘.

## 2. 접근안

### 2.1 바닥 그리기 방식 (기획 단계 결정, 기획 119 §11.6)
| 안 | 판단 |

| 안 | 내용 | 판단 |
|---|---|---|

## 4. 맵 데이터·생성

### 4.1 맵 1장
- 꼭짓점(맵 크기 + 1)² 마다 3비트: 잡초 이상 / 꽃 / 흙. 맵 시드 1개(int, 생성 시 `System.Random`에서 뽑음).
- 기존 칸별 밑층 그림 번호·덮개 코드는 제거.

### 4.2 판정
- 흙: 기존 그대로(흙 노이즈 꼭짓점 표본의 하위 흙 비율 분위).
- 잔디 계열: 잔디 계열 노이즈를 **꼭짓점**에서 표본. 누적 분위(기본 65 : 23 : 12)로 하위 = 잔디, 중간 = 잡초, 상위 = 꽃. 꽃 꼭짓점은 잡초 이상 꼭짓점에도 포함한다 - 고정 순서(잡초 위에 꽃)에서 꽃 지대 가장자리가 잡초로 감싸진다.
- 흙·잔디 계열 노이즈 필드 분리, 분위수 절단, 2겹 노이즈, 맵마다 시작 위치 무작위 - 설계 120 §4.3·§4.4 유지.
- 분류에 그림이 없을 때(배열 장 수 0): 그 분류 비중을 0으로 취급(잡초 0장 → 잡초 꼭짓점 없음). 잔디 0장이면 세트 사용 불가(단일 그림 모드).

### 4.3 변형 선택
- 셰이더로 이동. 잔디·잡초·꽃 = 육각 꼭짓점 해시, 흙 = 칸 좌표 해시(흙 3종은 가장자리 공통이라 칸 전환 이음매 없음). 해시 입력에 맵 시드 포함 - 같은 맵을 다시 써도 같은 모습, 맵마다 다른 모습.

### 4.4 스플랫 변환
- 꼭짓점 1개 = 픽셀 1개: R = 잡초 이상, G = 꽃, B = 흙 (0 / 255), A = 255(미사용).
- 픽셀 (x, y) = 꼭짓점 (x, y), y 위쪽(텍스처 행 0 = 맵 y 0). 텍스처: RGBA32, 선형(sRGB 아님), 쌍선형, clamp, 밉맵 없음.
- 크기: 46² × 4B ≈ 8.5KB / 장.

### 4.5 테스트 개정
- 비율 허용 오차(꼭짓점 기준), 꽃 ⊂ 잡초 이상, 스플랫 픽셀 ↔ 꼭짓점 일치(방향 포함), 시드 재현성, 분류 장 수 0 처리.
- 잘라내기·장 수·사용 순서·맵 크기 테스트 유지.

## 5. 셰이더

### 5.1 좌표
- 메시: 한 변 n칸 사각형, 위치 원점 중심 [−n, n]m(칸 2m, 기존과 동일). 꼭짓점 UV = 칸 좌표 (0 ~ n).
- 스플랫 UV = (칸 좌표 + 잘라내기 시작 칸 + 0.5) / (맵 꼭짓점 수). 텍스처 행 0 = 맵 y 0(아래).
- 육각 해시·흙 칸 해시·경계 노이즈는 **맵 칸 좌표**(칸 좌표 + 잘라내기 시작 칸)로 계산한다 - 같은 맵의 다른 잘라내기에서도 같은 자리는 같은 모습. 시작 칸·맵 꼭짓점 수·맵 시드는 머티리얼 속성(전투마다 갱신).

### 5.2 섞는 순서
| 단계 | 계산 | 읽기 |
|---|---|---|
| ① 잔디 | 육각 샘플링(잔디 배열) | 3 |
| ② 잡초 | w = 스플랫 R → 부드러운 경계 a. a > 0일 때만 육각 샘플링 후 lerp | 0 / 3 |
| ③ 꽃 | w = 스플랫 G, ②와 같음 | 0 / 3 |
| ④ 흙 | w = 스플랫 B → 또렷한 경계 a + 테두리. a > 0일 때만 흙 배열 일반 반복(칸 해시 변형) 후 lerp | 0 / 1 |
| 공통 | 스플랫 1 + 경계 노이즈 1 | 2 |

- 픽셀당 5 ~ 12회(대부분 5 ~ 8, 추정). 출력 불투명, 블렌드 없음.

### 5.3 육각 무작위 샘플링
- p = 칸 좌표 / 육각 크기 → 기울인 삼각 격자(skew [[1, 0], [−1/√3, 2/√3]])에서 둘러싼 꼭짓점 3개·무게중심 가중치.
- 꼭짓점마다 해시(꼭짓점, 맵 시드, 재질 번호) → 오프셋(0~1)², 변형 번호(배열 장 수 내). 회전 없음(잎 방향 유지).
- 가중치^날카로움 정규화 후 합산.
- 이음매 대책: 오프셋을 더하기 전 칸 좌표의 ddx/ddy로 `SampleGrad` - 꼭짓점 경계·칸 해시 전환에서 미분 튐(밉 선) 방지. 흙도 동일.

### 5.4 경계
- m = w + N × 세기 × 4w(1 − w). 같은 재질 꼭짓점 사이(w = 0 또는 1)는 노이즈 0 → 이웃과 어긋나지 않음.
- N = 경계 노이즈 텍스처(칸 좌표로 읽음, 2m 주기) 채널 값을 (값 − 0.5) × 2 × 노이즈 범위로 복원.
- 흙: N = R, 세기 0.6, a = clamp((m − 0.5) × 칸픽셀 / 폭 + 0.5), 폭 = 칸의 3/256. 테두리 = 경계 안쪽 폭 1.5배 지점을 정점으로 하는 삼각 함수 × a로 25% 어둡게 - `build_final.py` 흙 경계와 같은 공식(A3 통과 모양 재현). 칸픽셀 = 256(그림 기준 해상도, 화면 해상도와 무관).
- 잡초·꽃: N = G·B, 세기 0.6, a = smoothstep(clamp((m − 0.5) / 0.35 + 0.5)). 테두리 없음.

### 5.5 2D Renderer·정렬
- URP 17.3 2D Renderer, 2D 라이트 없음(확인). 패스 `LightMode = Universal2D`, unlit. 색 공간 Linear, 재질 배열 sRGB.
- MeshRenderer sortingOrder −30000(기존 바닥값), 레이어 = 전투 레이어. 그림자·라이트 프로브 끔.
- 이전 Tilemap(Sprite 기본 머티리얼)과 밝기 동일 여부 미확인 → 제작 검증에서 캡처 비교(§8).

### 5.6 조정 값 (바닥 세트, 인스펙터)
| 값 | 기본 |
|---|---|
| 육각 크기(칸) | 0.6 |
| 육각 날카로움 | 6 |
| 흙 경계 세기 / 폭(칸) / 테두리 어둡기 | 0.6 / 3/256 / 0.25 |
| 잡초·꽃 경계 세기 / 폭(칸) | 0.6 / 0.35 |

- 바닥 세트 값은 뷰가 머티리얼 복사본에 매 전투 적용(Play 중 인스펙터 조정이 다음 전투에 반영).

### 5.7 단일 그림 모드
- 셰이더 키워드 `_FLOOR_SINGLE`. 그림 1장을 칸마다 반복(frac(칸 좌표) → Sprite 사각 영역 UV, `SampleGrad`). 그림 없음 → 기존 녹색 틴트 단색(0.32, 0.4, 0.28).
- 사용처: 배틀 테스트 씬(정비창 배치 칸 그림, 틴트 없음 - 설계 120 C3), 맵·세트 없음(Field는 `Grass_1`).
