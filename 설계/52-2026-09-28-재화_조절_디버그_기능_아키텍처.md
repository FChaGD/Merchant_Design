# 재화 조절 디버그 기능 아키텍처

작성일: 2026-09-28
상태: 확정(2026-09-28, §8 추천안 그대로 사용자 확정). 제작 완료, 사용자 Play 검증 통과(2026-09-28 — 스핀 동작·경계·Hub 전용 표시 정상, 재화 패널 높이 추정값 40px 조정 불필요). 작업 브랜치 `ui`.

참고 구현: `BattleDebugResultView`/`BattleDebugResultInstaller`(화면 직접 그리기 디버그 버튼 + 전용 설치기), `DebugToolsBulkInstaller`(일괄 설치/제거), `InMemoryPlayerCurrencyWallet`, `HubSceneInstaller.BuildPlayerCurrencyHud`(재화 패널 배치)

## 1. 설계 목표

기존 디버그 영역(`Core/Debug/`, `Editor/Debug/`, `Tools/Game/Debug/Install|Remove/`)에 같은 규칙으로 편입해 **추가·제거가 파일 단위로 끝나게** 한다.

| 요구 | 설계 대응 |
|---|---|
| 게임 코드가 디버그 코드를 모른다 | 의존 방향은 디버그 → 게임(지갑 인터페이스) 한 방향. 게임 코드·게임 빌드 인스톨러(`ManagerHierarchyInstaller`)는 수정하지 않는다 |
| 추가가 쉽다 | 새 파일 2개 + 일괄 설치기 2줄 |
| 제거가 쉽다 | Remove 메뉴 1회 실행 → 파일 2개 삭제 → 일괄 설치기 2줄 삭제. 다른 코드에 흔적이 남지 않는다 |
| 빌드에 포함되지 않는다 | 컴포넌트 소스 전체를 `#if UNITY_EDITOR`로 감싼다(기존 디버그 뷰와 동일) |
| 게임 빌드 재실행과 독립 | 설치 대상 오브젝트(지갑 오브젝트)는 Build Bootstrap Scene이 get-or-create로 재사용하므로, 게임 빌드를 다시 돌려도 디버그 컴포넌트가 유지된다 |

## 2. 구성

| 구분 | 파일 | 역할 |
|---|---|---|
| 신규 | `Assets/Scripts/Core/Debug/Player/PlayerCurrencyDebugSpinView.cs` | 화면에 재화 증감 버튼 한 줄을 그리는 디버그 컴포넌트. 네임스페이스 `Game.Core.DebugTools`, `#if UNITY_EDITOR` |
| 신규 | `Assets/Scripts/Editor/Debug/PlayerCurrencyDebugInstaller.cs` | `Tools/Game/Debug/Install/Currency Spin Buttons`, `Tools/Game/Debug/Remove/Currency Spin Buttons` 메뉴. 네임스페이스 `Game.Core.Editor.DebugTools` |
| 수정 | `Assets/Scripts/Editor/Debug/DebugToolsBulkInstaller.cs` | `InstallAll`/`RemoveAll`에 각 1줄 추가 |

- `Core/Debug/Player/` 폴더는 신설한다. 기존 분류(`Battle/`, `Formation/`, `Trip/`)가 게임 코드 도메인 폴더(`Core/Player/`의 지갑)와 대응하는 규칙을 따른다.
- 게임 코드(`Core/Player/`, `Core/UI/`)와 `ManagerHierarchyInstaller`, `HubSceneInstaller`는 **변경 없음**.

## 3. 디버그 컴포넌트 — `PlayerCurrencyDebugSpinView`

### 3.1 부착 위치와 지갑 조회

- Bootstrap 씬 `Managers/.../UIManager/InMemoryPlayerCurrencyWallet` 오브젝트에 형제 컴포넌트로 부착한다.
- `Awake`에서 같은 오브젝트의 `IPlayerCurrencyWallet`을 직접 조회한다(`BattleDebugResultView`가 `BattleManager` 오브젝트의 인터페이스를 조회하는 것과 같은 방식). 구체 클래스 `InMemoryPlayerCurrencyWallet`에는 의존하지 않는다 — 지갑 구현이 바뀌어도 인터페이스만 유지되면 그대로 동작한다.
- 전역 DI 대상이 아니다(`IManagedComponent` 미구현). DI에 등록하면 게임 쪽 조립 목록(`managedComponents`)을 건드려야 하므로 "파일 단위 제거" 목표와 충돌한다.
- 지갑 조회 실패 시 `Debug.LogWarning` 한 번 후 아무것도 그리지 않는다(조기 드러냄).

### 3.2 동작

| 버튼 | 처리 | 경계 |
|---|---|---|
| `+100`, `+1000` | 지갑의 증가 기능을 그대로 호출 | 지갑이 이미 상한까지만 반영한다(초과분 손실 규칙) — 추가 처리 불필요 |
| `-100`, `-1000` | 차감량을 `min(요청량, 현재 금액)`으로 줄인 뒤 지갑의 차감 기능 호출 | 지갑의 차감은 부족하면 전체를 거부하므로, 디버그 쪽에서 가능한 만큼으로 줄여 0에서 멈추게 한다(기획 51번 §4) |

- 금액 변경은 지갑의 기존 변경 이벤트를 발생시키므로 재화 패널·무역품 구매 화면의 구매 가능 판정이 별도 연결 없이 갱신된다.
- 현재 금액 표시는 매 `OnGUI`에서 지갑 값을 읽는다(디버그용 즉시 모드 GUI라 이벤트 구독 불필요).
- 지갑 인터페이스에 "강제 설정" 같은 디버그 전용 기능을 추가하지 않는다 — 게임 계약에 디버그 흔적이 남으면 제거 시 게임 코드를 고쳐야 한다.

### 3.3 표시 조건

- `Application.isPlaying`이고 지갑을 찾았고 **Hub 씬이 로드된 동안에만** 그린다(2026-09-28 사용자 정정, 기획 51번 §4). 지갑은 Bootstrap에 상주해 부착 위치로 씬을 가를 수 없으므로, 씬 로드/언로드 이벤트로 Hub 로드 여부를 추적한다(OnGUI는 프레임당 여러 번 불려 매번 씬을 조회하지 않음). 씬 이름은 게임 코드의 `SceneNames.Hub` 상수를 읽기만 한다(디버그 → 게임 한 방향 의존 유지).
- 전투 강제 승패 버튼(좌상단 10,10)과 영역이 겹치지 않는다(우상단).

### 3.4 화면 좌표

Hub/Field 캔버스는 `ConstantPixelSize`(scaleFactor 1)라 재화 패널은 화면 픽셀 좌표 그대로 배치된다. `OnGUI` 좌표계(좌상단 원점, 화면 픽셀)와 단위가 같으므로 재화 패널 배치 값을 그대로 옮겨 맞춘다.

| 값 | 재화 패널(`HubSceneInstaller`) | 디버그 줄 |
|---|---|---|
| 가로 범위 | 화면 70%~100%, 우측 여백 32px | 동일(x = 화면폭×0.7 − 32, 폭 = 화면폭×0.3) |
| 세로 | 상단 여백 32px, 높이는 콘텐츠 맞춤(아이콘 32 + 상하 패딩 8 ≈ 40px, 글자 높이에 따라 달라짐 — 미확인) | 재화 패널 아래: y = 32 + 패널 높이 추정값 + 간격 8 |

- 재화 패널 배치 값은 컴포넌트 상단 상수 한곳에 모으고 "`HubSceneInstaller.BuildPlayerCurrencyHud`와 맞춘 값"임을 주석으로 표시한다. 두 곳이 어긋나도 디버그 버튼 위치만 틀어질 뿐 기능 영향은 없다 — 게임 코드에서 좌표를 공유 상수로 끌어오지 않는 이유는 디버그 코드 제거 시 게임 코드를 고치지 않기 위해서다.
- 패널 높이는 실측 전이라 추정값으로 시작하고, Play 검증에서 겹치면 상수만 조정한다.

### 3.5 크기·글자

- 캔버스가 픽셀 고정이라 재화 패널도 해상도에 따라 확대되지 않는다. 디버그 줄도 픽셀 고정으로 맞춘다: 줄 높이 32px, 글자 크기 16(기본 GUI 스킨 글자는 작아 `GUIStyle` 복사본에 글자 크기만 지정).
- 한 줄 배치: `[-1000] [-100] 현재 금액 [+100] [+1000]`. 폭(화면의 30%)을 5칸으로 나누고 가운데 칸에 금액을 가운데 정렬한다.
- 줄 배경에 반투명 상자를 깔아 게임 화면 위에서 구분되게 한다(기본 GUI 상자 스타일).

## 4. 설치기 — `PlayerCurrencyDebugInstaller`

`BattleDebugResultInstaller`와 같은 구조.

| 메뉴 | 동작 |
|---|---|
| `Tools/Game/Debug/Install/Currency Spin Buttons` | 현재 열린 씬에서 지갑 컴포넌트(`InMemoryPlayerCurrencyWallet`)를 찾아 그 오브젝트에 `PlayerCurrencyDebugSpinView`가 없으면 추가(get-or-create), 씬 dirty 표시. 못 찾으면 "Bootstrap.unity를 열고 다시 실행" 경고 |
| `Tools/Game/Debug/Remove/Currency Spin Buttons` | 같은 오브젝트에서 컴포넌트 제거, 씬 dirty 표시. 못 찾으면 조용히 종료 |

- 설치기는 에디터 코드라 지갑 오브젝트 탐색에 구체 클래스를 쓴다(씬에 실제 붙어 있는 컴포넌트를 찾는 용도 — `BattleDebugResultInstaller`가 `BattleManager`를 찾는 것과 동일).
- 두 메서드는 `public static`으로 열어 `DebugToolsBulkInstaller`가 호출한다.
- 요약 주석에 제거 절차(Remove 메뉴 → 파일 2개 삭제 → 일괄 설치기 2줄 삭제)를 적는다.

## 5. 일괄 설치기 편입

```
InstallAll: ... BattleDebugResultInstaller.InstallResultButtons();
            PlayerCurrencyDebugInstaller.InstallSpinButtons();   // 추가
RemoveAll:  ... BattleDebugResultInstaller.RemoveResultButtons();
            PlayerCurrencyDebugInstaller.RemoveSpinButtons();    // 추가
```

## 6. 제거 절차 (완전 배제)

1. `Tools/Game/Debug/Remove/Currency Spin Buttons` 실행 → Ctrl+S(Bootstrap 씬에서 컴포넌트 참조 제거).
2. `PlayerCurrencyDebugSpinView.cs`, `PlayerCurrencyDebugInstaller.cs`(+`.meta`) 삭제. `Core/Debug/Player/`가 비면 폴더도 삭제.
3. `DebugToolsBulkInstaller`의 2줄 삭제.

1번 없이 파일을 먼저 지우면 Bootstrap 씬에 "Missing Script" 컴포넌트가 남는다 — 기존 디버그 도구와 같은 제약.

## 7. 알려진 제약

- 컴포넌트 소스가 `#if UNITY_EDITOR`라 설치된 채로 게임 빌드를 만들면 빌드에서 해당 컴포넌트가 "Missing Script" 경고로 남는다(동작 영향 없음). `BattleDebugResultView` 등 기존 디버그 뷰와 같은 상태이며, 빌드 전 `Remove All`로 해소한다.
- 재화 패널 높이는 추정값(§3.4) — 실측 후 조정.

## 8. 확정 사항 (추천안 그대로 확정, 2026-09-28)

| 항목 | 결정 | 대안(기각) | 근거 |
|---|---|---|---|
| EditMode 테스트 | 추가하지 않음. Play 검증으로 확인 | 경계 처리(0에서 멈춤) 테스트 1개 추가 | 새 로직은 차감량을 현재 금액으로 줄이는 한 줄뿐이고, 증감 자체는 기존 지갑 테스트가 검증함. 테스트를 추가하면 제거 대상 파일이 하나 늘어난다 |
| 금액 표시 형식 | 현재 금액만(`1234`) | `1234 / 10000`(상한 병기) | 기획 51번 §4가 "현재 금액"으로 확정. 상한은 재화 패널 툴팁으로 확인 가능 |

## 9. 검증 절차 (제작 후)

1. Bootstrap.unity 열기 → `Tools/Game/Debug/Install/Currency Spin Buttons` → Ctrl+S.
2. Play → 마을: 재화 패널 아래에 버튼 줄 표시, 겹침 없음.
3. `-1000` 반복 → 0에서 멈춤, 재화 패널 동시 갱신. `+1000` 반복 → 10,000에서 멈춤.
4. 무역품 구매 화면: 재화를 가격 미만으로 줄이면 구매 버튼 비활성+사유, 다시 늘리면 활성.
5. 상행 출발 → Field(이동·전투 뷰)에서 버튼 줄이 보이지 않음. 마을 복귀 시 다시 표시.
6. `Remove All` → Play 시 버튼 줄 없음. `Install All` → 다시 표시.
