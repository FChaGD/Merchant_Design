## 1. 기획 요약

- 상행 중 **이동을 멈추지 않는** 대화. 말풍선 + 좌우 스탠딩. 20초마다 대화를 띄울지 검사(랜덤 30%), 특정 일 뒤의 상황 대화(출발 직후·전투 직후·이벤트 직후·중간 도시 도착), 플레이어가 거는 수동 대화.
- 대사: 타자기(초당 12자) → 길이 비례 대기 → 자동 넘김, 2단계 클릭. 선택지는 출력 직후 표시 + 10초 제한, 만료 시 무응답 분기.
- 랜덤·수동 대화는 같은 대화가 상행당 1회, 반복 대화·상황 대화는 제한 없음.
- 전투·이벤트로 상행이 멈추면 대화 즉시 종료(기록 없음). 정비창·방향성 지시를 열면 일시정지.
- 상단주(플레이어)는 대사가 없다 — 선택지로만 참여.

### 1.1 이 설계 중 바로잡은 사항 (2026-10-12)

| 항목 | 정정 |
|---|---|
| 이벤트 대화 화면 | 이벤트의 상황·결과·전투 후 대사는 **화면 전체를 쓰는 이벤트 전용 대화 화면**(89). 이 문서의 말풍선 화면과 다르다. 대사 진행 규칙만 공용(기획 86 §3.4 정정) |
| 이벤트 전투 뒤 이동 중 대화 | 이벤트 전투의 '전투 직후'·'이벤트 직후'는 이벤트가 끝나고 상행이 재개된 뒤 생긴다(설계 87 §6.4 정정) |
| Field 인벤토리·상행 정보 화면 | Field에 없다. 이번엔 정비창·방향성 지시만 일시정지 원인. 화면이 생기면 모달 열림 신호에 참여시키면 된다(향후) |

## 2. 구성

| 단위 | 위치 | 역할 |
|---|---|---|
| 대화 진행자 | FieldManager 하위 컴포넌트(Bootstrap, 설계 87 §6.1) | 20초 검사·상황 신호를 받아 대화를 고르고 시작, 수동 걸기 요청, 중단·완료 기록 |
| 대화 고르기 | 순수 C# | 진행자의 판정 규칙(§3). EditMode 테스트 대상 |
| 대화 화면 `FieldDialogueView` | Field 씬 이동 뷰 | 말풍선·좌우 스탠딩·선택지·남은 시간 막대·화면 클릭 받기(§5) |
| 수동 걸기 뷰 | Field 씬 좌하단 버튼 열 | "대화" 버튼 + 상단원 목록(§6) |

진행자는 설계 87의 후보 추첨·이력 기록·대사 실행기(자동 넘김 켬, 선택지 제한 10초)를 쓴다.

**씬 연결**: 진행자는 Bootstrap 상주라 Field 씬을 다시 로드해도 남는다. 영속 신호 구독은 최초 1회, 뷰 참조는 Field 로드마다 교체한다(`FieldEncounterFlowCoordinator`의 Bind/RebindViews와 같은 방식). 뷰 연결은 `FieldUIWiring`이 한다.

## 3. 대화 고르기 (20초 검사)

진행자는 지난 검사 이후 생긴 일(상황 신호)을 순서대로 쌓아 둔다.

1. 대화 진행 중 → 아무것도 하지 않음. 쌓인 일도 지운다(소멸).
2. 쌓인 일이 있으면 상황 대화 후보를 찾는다.
   - '이벤트 직후'가 있으면 그것을 먼저 본다.
   - 그다음 먼저 생긴 순서로, 후보가 있는 첫 번째 일의 대화를 시작. 후보는 그 일에 해당하는 상황 대화 행 중 테이블 순서 첫 행(설계 87 §5.2).
3. 2에서 시작한 대화가 없으면 30% 판정 → 성공 시 랜덤 대화 가중치 추첨.
4. 검사 후 쌓인 일을 지운다.

| 생긴 일 | 상황 신호(설계 87 §6.4) |
|---|---|
| 출발 직후 | 상행 시작 → 첫 검사(1.25초) |
| 전투 직후 | 전투 종료 — 랜덤 전투는 이동 재개 시, 이벤트 전투는 이벤트가 끝나 재개 시. **20초 검사에 쌓지 않는다 — §3.1** |
| 이벤트 직후 | 이벤트 종료 |
| 중간 도시 도착 | 중간 도시 도착 |

수치(30%, 20초)는 설계 87의 상수를 쓴다(판정 시계·대화 상수).

### 3.1 전투 직후 대화 (2026-10-13 변경)

전투 직후 대화는 20초 검사를 기다리지 않는다. 사용자 Play 확인 후 지시로 바꿨다.

- 전투 종료 신호(상행 재개 시점)부터 **상행 시간 5초** 뒤에 전투 직후 상황 대화를 찾아 시작한다. 상행 시간이라 정지 중엔 멈추고, 정비창이 열려 있으면(상행은 계속 흐름) 5초가 지나 일시정지 상태로 시작한다.
- 후보가 없으면 아무것도 띄우지 않는다 — 랜덤 대화로 대체하지 않는다.
- 5초 시점에 대화가 진행 중이면(수동 대화 등) 버린다(§3의 1과 같은 규칙).
- 대기 중 정지(전투·이벤트)·상행 종료·새 상행 시작이 오면 취소한다. 그 사이 20초 검사는 전투 직후를 보지 않는다.
- 디버그 "대화" 창에 남은 시간을 표시한다.

## 4. 수동 걸기 · 중단 · 일시정지 · 기록

### 4.1 수동 걸기

- 목록 = 고용 상단원 전원(상단주 제외).
- 고른 상단원이 화자인 **수동 대화** 중 이번 상행에서 아직 안 했고 조건이 참인 것 → 테이블 순서 첫 행 시작.
- 없으면 그 상단원의 **반복 대화** 중 가중치 추첨.
- 둘 다 없으면 목록에서 흐리게 "할 말 없음", 선택 불가. 목록을 열 때 상단원별로 판정한다.
- 20초 검사와 무관하게 즉시 시작.
- "대화" 버튼 비활성: 대화 진행 중, 상행 정지 중(전투·이벤트), 인카운터 진행 중(기존 상단 버튼 비활성 규칙에 포함).

### 4.2 중단·일시정지·완료

| 상황 | 처리 |
|---|---|
| 상행 정지가 걸림(정지 조율자의 정지 시작 — 전투 판정 성공, 이벤트 발생) | 진행 중 대화 즉시 종료. 무응답 분기 미적용, 기록 없음(설계 87 §7.2) |
| 모달 화면 열림(정비창·방향성 지시) | 대사 실행기 일시정지. `IUIVisibilitySignal.ModalPopupOpenChanged`를 원인으로 연결 — 열려 있는 동안 출력·대기·10초 제한이 멈춘다 |
| 끝까지 진행 | 이번 상행·전체 발생 기록. 반복·상황 대화도 기록(조건 `seen` 용, 횟수 제한에는 안 씀) |
| 상행 종료 | 진행 중 대화 종료(기록 없음). 도착 틱엔 검사 없음(설계 87 §6.3) |

## 5. 대화 화면

### 5.1 배치 (이동 뷰, 화면 비율 기준값)

```
┌──────────────────────────────────────────┐
│        [===== 진행 게이지 =====]          │ y .92~.97 (기존)
│            [구간 도착 알림]               │ y .82~.90 (기존)
│            [인카운터 경고]                │ y .42~.58 (기존, 대화와 동시 표시 없음)
│          ┌──── 말풍선 ────┐               │ y .30~.44
│          │ 이름 / 대사     │               │
│          └────────────────┘               │
│  ┌─────┐  [선택지 1]       ┌─────┐        │ 선택지 y .14~.28
│  │일러1│  [선택지 2]       │일러2│        │ 스탠딩 y .06~.34
│  │(반전)│ [▬▬ 10초 ▬▬]    │(원본)│        │
│[대화]└─┘                   └─────┘        │ 대화 버튼 y .22~.30
│[방향]                                     │ (기존 y .12~.20)
│[정비]                                     │ (기존 y .02~.10)
└──────────────────────────────────────────┘
```

- 일러1(왼쪽) x .16~.32 — 좌하단 버튼 열(x .02~.14)을 피한다. 일러2(오른쪽) x .68~.84. 말풍선·선택지 x .34~.66.
- **확정(2026-10-13)**: 위 기준값 그대로. Play 실측 1920×1080에서 진행 게이지·구간 알림·좌하단 버튼·OnGUI 디버그(좌상단 전투·상행, 오른쪽 위 이력·대화)와 겹침 없음(말풍선·좌우 스탠딩·선택지·시간 막대·대화 버튼·상단원 목록). 결과 팝업(도착)과는 겹치지만 도착 처리가 대화를 먼저 끝내 동시에 뜨지 않는다. 1280×720은 계산상 겹침 없음(실측 미확인).

### 5.2 요소

| 요소 | 내용 |
|---|---|
| 말풍선 | 화자 이름 + 대사(타자기). 서술 줄은 이름 칸 비움 |
| 좌·우 스탠딩 | Placeholder: 색 사각형 + 이름. 색은 화자 Id에서 결정(같은 인물 = 같은 색). 말하는 쪽 밝게 / 듣는 쪽 어둡게 / 서술 줄은 양쪽 어둡게. 대화에 나오지 않는 자리는 숨김 |
| 마주보기 | 원본 일러스트는 **일러2(오른쪽) 자리 기준 방향**으로 제작한다고 전제. **일러1(왼쪽)을 좌우반전**해 마주보게 한다. 반전은 그림 요소에만 — 이름 글자는 별도 요소라 반전되지 않는다 |
| 선택지 | 말풍선 아래 세로 목록. 잠긴 선택지는 흐림 + `#lock` 문구, 선택 불가. `#timeout` 선택지는 표시하지 않음 |
| 남은 시간 막대 | 선택지 아래, 10초 동안 줄어듦. 일시정지 중 멈춤 |
| 화면 클릭 받기 | 대화 진행 중에만 켜지는 투명 전체 화면 영역. 이동 뷰의 버튼들보다 **뒤**에 두어 버튼은 그대로 눌리고 빈 곳 클릭은 대사 넘김(출력 중 = 전체 표시, 출력 후 = 다음 줄). 선택지가 떠 있는 동안은 반응하지 않음. 모달 화면이 열려 있으면 그 화면이 위라 닿지 않는다 |

### 5.3 화자 자리 (`#left` / `#right`)

- 화자마다 **첫 대사의 태그**로 자리가 정해지고 대화 끝까지 유지.
- 첫 대사에 태그 없는 화자, 한 대화에서 같은 자리를 두 화자가 씀 → 콘텐츠 검증 테스트 오류(설계 87 §9 검증에 추가).

### 5.4 형태

`IUIPanel`이 아닌 표시 전용 뷰(`XxxView`). 이동 뷰 위에 겹칠 뿐 화면 전환·상행 차단이 없어 `FieldEncounterWarningView`와 같은 성격이다. 대사 실행기의 화면 계약(설계 87 §7.1)을 구현한다.

## 7. 화면 생성

## 8. 디버그

전용 인스톨러 `Tools/Game/Debug/Install|Remove/Dialogue Debug`, 일괄 설치 목록 등록.

| 기능 | 내용 |
|---|---|
| 대화 강제 발생 | 대화 Id 선택 → 즉시 시작. 조건·횟수·화자 고용 무시. 진행 중 대화가 있으면 종료 후 시작 |
| 상태 표시 | 다음 20초 검사까지 남은 시간, 쌓인 일 목록, 진행 중 대화 Id |
| 이력 보기·초기화 | 설계 87 §8.2 기반 디버그 사용 |

배치 확정 전 대화 화면·수동 걸기 목록·기존 디버그 UI 겹침 점검.

## 9. 예시 콘텐츠 (기획 86 §7)

| Id | 내용 | 확인 대상 |
|---|---|---|
| D1 | 출발 직후, 상단원 A 한마디 | 출발 직후 대화, 말풍선, 왼쪽 스탠딩 |
| D2 | 전투 직후, 상단원 A·B 주고받기 | 좌우 마주보기, 말하는 쪽 밝게 |
| D3 | 랜덤, 상단원 B 질문 → 응답 2 + 무응답(각 플래그) | 선택지, 10초 막대, 무응답 |
| D4 | 수동 반복, 상단원 일상 대사 | 대화 버튼, 목록, 반복 대화 |

상단원 A·B는 시작 고용 캐릭터 중 제작 시 지정. 대사 문구는 제작 시 초안 → 사용자 검토.

| 대상 | 핵심 경우 |
|---|---|
| 대화 고르기 | 진행 중이면 무시·쌓인 일 소멸, '이벤트 직후' 우선, 그 밖은 먼저 생긴 순서, 후보 없으면 30% 랜덤(난수 고정), 검사 후 쌓인 일 비움 |
| 수동 고르기 | 안 한 수동 대화 우선(테이블 순서), 없으면 반복 대화, 둘 다 없으면 "할 말 없음" |
| 기록 | 완료 = 기록, 중단 = 기록 없음, 반복 대화 횟수 제한 없음 |
| 콘텐츠 검증 | 화자 첫 대사 자리 태그, 같은 자리 중복 없음 |
| 회귀 | 전체 EditMode |

## 11. 제작 순서 (87 제작 완료 전제)

1. 대화 진행자 고르기·기록 로직 + 테스트
2. 대화 화면·Field 인스톨러·진행자 연결
3. 수동 걸기 버튼·목록
4. D1~D4 콘텐츠(엑셀 행 + Yarn)
5. 디버그 도구
6. 사용자 Play 확인

### 11.1 Play 확인 항목 (사용자 실행)

- 출발 직후 D1 표시
- 전투 후 D2 표시, 두 인물 마주보기
- D3에서 10초 무선택 → 무응답 결과
- 대화 버튼 → D4
- 정비창 열면 대화 정지, 닫으면 재개
- 디버그 인카운터 발생 시 진행 중 대화 즉시 종료
