## 4. 구조·변경 상세

### 4.1 정리 계약 확장

```csharp
public interface IInventoryArrangement : IInventoryStagingDiscarder
{
    bool TryApplyPlacements(IReadOnlyList<ItemPlacement> placements);
    bool CanApplyPlacements(IReadOnlyList<ItemPlacement> placements);
    // 그리드·임시 보관에서 함께 찾는다. 하나라도 없으면 아무것도 지우지 않고 false. 성공 시 OnChanged 1회. 환급 없음.
    bool TryDiscard(IReadOnlyCollection<string> instanceIds);
}
```

- `InventoryGrid.RemoveAll(IReadOnlyCollection<string>)`: 전부 존재 확인 후 일괄 삭제(원자적).
- 구현: `PlaceholderFixedGridInventoryRepository`, `PlaceholderTradeGoodsInventoryRepository`, 테스트 가짜 `GridInventory`.
- 골드 상자를 버리면 `LoadedGold`가 재계산으로 줄어든다. 골드 HUD 갱신은 기존 저장소 변경 → 골드 보유 서비스 `Changed` 경로를 쓴다(제작 시 연결 여부 확인).

### 4.2 골드 정보 읽기 계약

```csharp
public interface IGoldItemInfo
{
    bool IsGoldItem(string itemId);
    int GoldValuePerItem { get; }   // 골드 상자 1개 가치(현재 500)
}
```

- `GoldHoldingsService`가 구현하고 `RegisterSelf`에서 등록(DI 읽기 타입 미등록 함정 — 등록 타입 확인).
- `HubUIWiring`·`FieldUIWiring`이 `TryResolve`로 조회해 **상단 물류품 화면**(상단 물류품 팝업, 무역품 구매, 회수 적재)에만 전달. 다른 그리드는 null.

### 4.3 `InventoryDiscardController`(순수 C#, 편집 컨트롤러 소유)

| 입력 | 동작 |
|---|---|
| 쓰레기통 클릭 | 선택 상태 토글 |
| 선택 상태 + 아이템 클릭 | 선택 토글, 빨간 표시(`SetDiscardMarked`) |
| 선택 상태 + 확인 | 경고 대화상자 → 확인: `TryDiscard(선택)` 후 선택 상태 종료 / 취소: 선택 유지, 선택 상태 유지 |
| 선택 상태 + 취소·쓰레기통 재클릭 | 선택 상태 종료(표시 해제) |
| 쓰레기통에 드롭 | 경고 대화상자 → 확인: `TryDiscard([그 아이템])` / 취소: 무동작(아이템은 원위치) |
| 섹션 전환 | 선택 상태에서도 허용, 다른 마차의 선택 유지, 개수 = 전체 합 |
| 본문 숨김(`Hide`) | 선택 상태 종료, 대화상자 닫기 |
| 저장소 변경 | `InventoryDiscardSelection.Prune`으로 사라진 아이템 제거 후 표시 갱신 |

- 노출: `IsSelecting`, `IsMarked(instanceId)`(뷰 구성 시), `HandleItemClicked(instanceId)`, `RequestDropDiscard(instanceId)`, `InfoText`(선택 상태면 "버릴 아이템을 선택하세요 (n개 선택)", 아니면 null).
- 확인 버튼 활성 = 선택 1개 이상. 확인/취소 버튼은 선택 상태에서만 표시.
- `TryDiscard`가 false(다른 경로로 아이템이 이미 사라짐 등)면 선택을 정리하고 정보 줄에 "버리지 못했습니다. 다시 선택하세요." 표시.

**편집 컨트롤러(`InventoryArrangementController`) 변경**
- 생성자 인자 `IGoldItemInfo goldInfo`(null 허용) — 설계 99의 `IInputManager`와 같은 경로.
- 선택 상태일 때: 드래그 시작 무시(Q 구독도 생기지 않음), 정렬 버튼 `interactable=false`, 아이템 클릭은 정보 선택 대신 `HandleItemClicked`, 정보 줄은 `InfoText` 우선.
- 뷰 구성(`ConfigureItemView`)에서 `SetDiscardMarked(IsMarked(id))`.
- `Hide`·`Dispose`에서 협력 객체 정리.

### 4.4 드래그 컨트롤러

- 드롭 대상에 `Trash` 추가. 포인터가 쓰레기통 RectTransform 안이면 `Trash`(임시 보관 영역 판정과 같은 방식, 그리드·임시 보관보다 먼저 판정).
- `Trash` 드롭: 재배치하지 않고 생성자 콜백 `onDiscardDrop(itemId)` 호출 → 편집 컨트롤러 → `RequestDropDiscard`.
- 쓰레기통 위에서는 그리드 미리보기를 지운다.

### 4.5 순수 로직(테스트 대상)

| 클래스 | 책임 |
|---|---|
| `InventoryDiscardSelection` | `Toggle`, `Contains`, `Count`, `Ids`, `Clear`, `Prune(존재 판정)` |
| `InventoryDiscardWarning` | `Compose(items, goldInfo)` → `"다음 아이템을 버립니다. 되돌릴 수 없습니다.\n이름 ×n, 이름, ..."` (같은 이름은 처음 나온 순서로 묶고 1개면 ×1 생략). 골드 상자가 있고 `goldInfo`가 있으면 `"\n골드 상자 n개(골드 x)가 사라집니다."` 추가(x = n × 가치) |

### 4.6 아이템 뷰

- `InventoryItemView.SetDiscardMarked(bool)`: 반투명 빨강 오버레이 자식 토글(`raycastTarget=false`). 선택 테두리와 독립. 오버레이는 아이템 템플릿 조립 시 생성.

## 5. 화면 요소·설치

### 5.1 공용 본문 조립 — `InventoryPopupUIBuilder.BuildArrangementBody`

| 요소 | 클래식(하단 줄) | 상단 물류품(우측 열) |
|---|---|---|
| 쓰레기통 버튼 `DiscardButton` | 정렬 오른쪽(x 0.22~0.32), 정보 줄은 x 0.34~ | 정렬 위(y 0.13~0.21) |
| 확인/취소 `DiscardConfirmButton`/`DiscardCancelButton` | 정보 줄 오른쪽 끝(x 0.70~0.83 / 0.85~0.98), 선택 상태에서만 활성 | 쓰레기통 위(y 0.22~0.30, 좌우 반분) |
| 정보 줄 | 남은 폭 | y 0.31~0.88 |
| 경고 대화상자 `DiscardDialog` | 본문 전체를 덮음(`EditorUIBuilder.BuildConfirmDialog`), 문구 자동 크기, 최소 크기 지정, 본문의 마지막 자식, 저장 상태 비활성 | 같음 |
| 아이템 템플릿 | 빨강 오버레이 자식 `DiscardMark` 추가 | 같음 |

- 쓰레기통은 지금은 글자 버튼("버림"). 아이콘은 아이콘 작업 때 교체.
- 좌표는 잠정 — 제작 시 Play 실측 겹침 점검으로 확정.
- 요소 Id는 `InventoryPopupUIElementIds`에 접두사 방식(`DiscardButton(prefix)` 등). `InventoryArrangementElements.TryBind`가 함께 바인딩하고, 못 찾으면 본문 바인딩 실패(기존 동작과 같음).
- 재실행 안전: get-or-create, 확인/취소는 저장 상태 비활성.

- 인벤토리 팝업: 드래그 → 쓰레기통 → 경고 → 확인 사라짐 / 취소 원위치. 쓰레기통 클릭 → 다중 선택 → 확인 → 경고 → 확인 버림 / 취소 선택 유지.

- 상단 물류품: 마차 전환 후 선택 유지, 골드 상자 경고 줄, 확인 후 HUD 적재량 감소.

- 겹침 점검(Game 뷰 실제 해상도): 쓰레기통·확인/취소·정보 줄, 선택 상태·대화상자 열린 상태, 개인 물품 3×3 창의 대화상자 가독성.
- 회수 적재 패널: 전투 후에만 열려 CLI로 띄우지 못하면 "미확인".

## 8. 범위 밖

- 판매와 버리기의 역할 분담, 버릴 수 없는 아이템 종류(기획 95 §5).
