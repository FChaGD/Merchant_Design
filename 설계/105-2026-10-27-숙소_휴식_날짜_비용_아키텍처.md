## 1. 목적

설계 103의 휴식 계약(`IInnRestService`)을 Placeholder 대신 실제 구현으로 채운다 — 1일 경과마다 게임 날짜 +1, 개인 골드에서 1일 비용 차감. 화면은 바꾸지 않는다.

## 2. 결정 사항

| 항목 | 결정 | 출처 |
|---|---|---|
| 날짜 | 1일 경과마다 +1(진행 화면 게이지의 하루 단위와 같은 시점). 날짜 HUD는 날짜 변경 이벤트로 즉시 갱신 | 사용자 결정(2026-10-27) |
| 비용 | 1일 경과마다 1일 비용(10골드, 인스펙터) 차감. **개인 골드에서만**(골드 상자 자동 인출 없음) | 기획 94 4-3, 사용자 결정(2026-10-27) |
| 중단 | 지난 일수만큼만 날짜·비용 반영(1일 경과 때마다 이미 반영되므로 추가 처리 없음) | 기획 94 4-12 |
| 회복 | **보류** — 대상 없음(지략·행정력 미구현, HP는 상행 시작·종료 전원 회복) | 사용자 결정(2026-10-27) |
| 날짜 경과의 효과 | 없음(재입고·급여 등 미정, 기획 84 §5) | 기획 84 |

## 3. 구조

| 대상 | 내용 |
|---|---|
| `InnRestSession`(신규, 순수 C#) | 휴식 1회의 상태 — 예정 일수, 경과 일수, 진행 중 여부. 시작(1 이상만), 1일 경과 가능 여부(진행 중이고 경과 < 예정), 종료. 상태 판정만 하고 부수효과는 없다 |
| `InnRestService`(신규, `Core/Town/Inn/` 또는 기존 Placeholder 폴더, MonoBehaviour·`IManagedComponent`) | `IInnRestService` 구현. 의존성 `IPlayerCurrencyWallet`(개인 골드 차감)·`IDateAdvancer`(날짜) — 둘 다 `TryResolve`, 등록 타입으로 조회 |
| `PlaceholderInnRestService` | **삭제** |

### 3.1 동작

| 호출 | 처리 |
|---|---|
| `CostPerDay` | 인스펙터 값(10) |
| `BeginRest(plannedDays)` | 세션 시작. 이미 진행 중이면 이전 세션을 경고 후 종료하고 새로 시작(씬 전환 등으로 종료가 누락된 경우 방어) |
| `AdvanceDay()` | 세션이 1일 경과를 허용할 때만: 지갑에서 1일 비용 차감 → 날짜 +1. 차감 실패(개인 골드 부족)는 UI가 확정 단계에서 막아 정상 경로에 없다 — 발생하면 경고하고 **날짜는 진행**(하루는 이미 지났고, 진행 중 HUD 입력이 막혀 있어 다른 경로로 골드가 줄 수 없다). 진행 중이 아니거나 예정 일수를 넘으면 무시 + 경고 |
| `EndRest(restedDays)` | 세션 종료. `restedDays`가 세션 경과 일수와 다르면 경고만(실제 반영은 1일 경과 시점에 끝남) |

의존성이 없으면: 지갑 없음 → 비용 생략, 날짜 관리자 없음 → 날짜 생략(각각 경고 1회). 숙소 화면 등록 조건(휴식 계약·골드 조회)은 기존 그대로.

진행 화면은 시작 시점 날짜·개인 골드를 고정해 예상값을 계산하므로(설계 103 §4.3) 실제 차감과 같은 값을 보인다 — 화면 변경 없음. 재화 HUD는 지갑 변경 → 골드 원장 변경 이벤트로 갱신된다.

## 4. 설치·Placeholder 제거

- `ManagerHierarchyInstaller`: `PlaceholderInnRestService` 생성 줄을 `InnRestService`(같은 UIManager 하위)로 교체, 반환 목록 교체, 삭제된 클래스 오브젝트는 이름 상수(`RemovedPlaceholderInnRestServiceName`)로 `DestroyChildIfExists`. 1일 비용 인스펙터 값은 새 컴포넌트 기본값 10.
- 실행: Bootstrap 열기 → Build Bootstrap Scene → 저장(CLI 직접). 설계 104와 같은 빌드에서 함께 처리한다.

## 5. 테스트(EditMode)

| 대상 | 경우 |
|---|---|
| `InnRestSession` | 시작 0 이하 거부, 예정 일수까지만 경과 허용, 종료 후 경과 거부, 재시작 |
| `InnRestService` | 3일 휴식 완주 → 날짜 +3·개인 골드 −30, 1일 후 중단 → +1·−10, 시작 전·종료 후 경과 무시, 예정 초과 경과 무시, 개인 골드 부족 시 날짜만 진행, 지갑·날짜 관리자 없을 때 예외 없음 |

## 6. 사용자 확인(Play)

Hub 숙소: 3일 휴식 → 날짜 HUD가 하루마다 +1, 개인 골드가 하루마다 −10, 결과 문구 비용과 실제 차감 일치. 중단 시 지난 일수만 반영. 휴식 중 씬 전환 없이 끝까지 진행 후 상행 출발에 날짜가 이어지는지.
