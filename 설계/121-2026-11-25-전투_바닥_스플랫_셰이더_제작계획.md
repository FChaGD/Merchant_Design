# 전투 바닥 스플랫 셰이더 제작계획

> 실행 방식: 세션 내 직접 실행(사용자 "제작을 시작하라", 2026-11-25). 단계는 체크박스로 추적. 2026-11-25 전 단계 완료(결과는 설계 121 §10).

**목표:** 설계 121대로 전투 바닥을 Tilemap 2층에서 메시 1장 + 스플랫 셰이더로 교체한다.
**구조:** 순수 로직(꼭짓점 판정 맵·스플랫 변환) → Bootstrap 매니저가 맵마다 스플랫 텍스처 보관 → Field 바닥 뷰가 메시 1장에 머티리얼 복사본으로 그림.
**기술:** Unity 6(URP 17.3, 2D Renderer), 수기 HLSL, Texture2DArray(플립북 임포트), NUnit EditMode, 로컬 Python(ArtSource).
**설계:** [121](121-2026-11-25-전투_바닥_스플랫_셰이더_아키텍처.md)

## 전역 제약
- `.unity`/`.prefab` 직접 편집 금지 - 인스톨러(CLI 실행: open_scene → menu → save_scene).
- 바닥 정렬값 −30000, 전투 레이어. 바닥 뷰 클래스명 `BattleBackgroundGridView` 유지, 진입점 `ConfigureField(float)`·`SetLayoutSource(IBattleFloorLayoutSource)` 유지.
- 맵 크기 45칸(꼭짓점 46), 비율 기본 흙 0.15 / 65·23·12.
- 셰이더 조정 기본값: 육각 0.6칸·날카로움 6, 흙 세기 0.6·폭 3/256칸·테두리 0.25, 잡초·꽃 세기 0.6·폭 0.35칸, 노이즈 범위 1.0, 칸픽셀 256.
- Resources 삭제: `DirtEdge_*` 14장, `Grass_1` 외 낱장 15장. ArtSource `final_256/` 보관.
- 메인 저장소 미커밋 Event 관련 파일(세션 밖 수정)은 건드리지 않는다.

## 검토 초점
1. 스플랫 방향(행 0 = 맵 y 0) - 뒤집히면 흙 위치가 배치와 어긋남 → 변환 테스트로 고정.
2. 셰이더 밉맵 이음매(육각 꼭짓점·흙 칸 전환) → `SampleGrad` + 최대 줌 아웃 캡처.
3. 씬 재진입 반복 시 텍스처·머티리얼 누적 → Destroy 경로 확인.
4. 맵/세트/머티리얼 없음 → 단일 그림·경고, 전투 진행.
5. 이전 전투보다 작은 전장 → 메시 크기 갱신.
