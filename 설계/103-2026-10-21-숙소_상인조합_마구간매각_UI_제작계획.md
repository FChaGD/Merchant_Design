# 숙소·상인조합·마구간 매각 UI 제작 계획

> **For agentic workers:** superpowers:executing-plans로 직접 실행(사용자 지시 2026-10-21 — 100~103 연속 자동 진행, 검진은 전체 제작 후).

**Goal:** 숙소(휴식 설정·탭 편집)·휴식 진행 화면·상인조합 화면·마구간 매각 모드를 UI와 Placeholder 계약까지 만든다. 실제 상태 변경은 system 브랜치 몫.

**Architecture:** 기존 시설 화면 패턴(plain C# 패널, `HubUIWiring`이 Hub 로드마다 생성·모달 채널 등록). 휴식 진행은 별도 패널(`UIPanelIds.InnRestProgress`)로 열어 채널 네비게이션이 숙소 숨김·복귀를 처리. 진행 중 `PopupExemptLayer` CanvasGroup으로 HUD 입력 차단. 마구간 매각은 `StablePanel` 소유 협력 객체.

**Tech Stack:** Unity 6000.3.7f1, UGUI, TMP, NUnit EditMode.

**Spec:** `Docs/설계/103-2026-10-20-숙소_상인조합_마구간매각_UI_아키텍처.md`

## Global Constraints

- 브랜치 `ui`. 커밋은 사용자 지시 시에만. `Docs/` 커밋 금지.
- 씬은 인스톨러 메뉴로만 변경(CLI 직접 실행). 공용 조립은 `EditorUIBuilder`·`InventoryPopupUIBuilder.BuildArrangementBody`.
- Placeholder 요약 주석에 "실제 시스템 설계 후 대체/제거 대상". 값 없는 문자열은 "값 없음".
- 값: 1일 비용 10, 일수 1~30, 진행 기준 3·목표 20·최소 1초, 매각 비율 0.5(내림). 퀘스트 3건 `퀘스트이름1`~`3`.
- 문구: 매각 사유 "화물이 실린 마차는 매각할 수 없습니다." / "마지막 마차는 매각할 수 없습니다.", 매각 확인 "{n번 이름}을 {x}골드에 매각합니다"(확인 "매각"/취소 "취소"), 빈 퀘스트 "수락 가능한 의뢰 없음", 수락 상태 "수락함", 결과 "n일 휴식 완료, 비용 x" / "n일 휴식 중단, 비용 x". 휴식 비용 부족 사유는 스펙에 문구가 없어 "개인 골드가 부족합니다."(제작 판단).
- 테스트: `bash ~/.claude/projects/C--Users-addmin-Desktop-Merchant/tools/ut.sh <클래스|ALL>`.

## Review Focus

1. 진행 화면이 닫히는 모든 경로(확인·Hub 언로드·Dispose)에서 HUD 레이어 CanvasGroup이 복구되는가.
2. 한 프레임에 여러 날을 넘는 경과(프레임 끊김) → 1일 경과 계약이 빠짐없이 호출.
3. 숙소 탭 전환·닫기 → 숨긴 본문의 드래그·버리기 선택 상태 정리.
4. 매각 모드 중 무역품 인벤토리 구독이 모드 해제·Close·Dispose에서 해제.
5. Hub 재방문 → 새 패널 3종 이전 인스턴스 Dispose(골드·게시판·보유 구독 누적 없음).
