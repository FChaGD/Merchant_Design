# 유닛 공격 애니메이션·타격 판정 제작계획

> 실행: 이 세션에서 직접 작업(native, superpowers:executing-plans). 체크박스로 진행 추적.

**목표:** 배틀 테스트 씬에서 검사·약탈자(도적1) 공격 클립을 재생하고, 타격 프레임 시점에 피해가 들어가게 한다.
**구조:** 시뮬레이션 유닛이 공격 클립 타이밍에서 타격 지연을 계산해 "공격 시작 → 지연 → 타격"으로 나눈다. 화면은 공격 시작 이벤트로 클립만 재생한다.
**기술:** Unity 6000.3, C#, NUnit EditMode, Unity CLI(`tools/ut.sh`, `unity command menu/save_scene/eval`).
**설계:** [124 유닛 공격 애니메이션·타격 판정 아키텍처](124-2026-11-27-유닛_공격_애니메이션_타격_판정_아키텍처.md)

## 공통 제약

- 그림·애니메이션 세트가 없는 유닛의 공격 시점·이벤트 순서는 현행과 같아야 한다(지연 0 → 같은 틱).
- Field 실전투 경로(`LiveBattleSimulationRule`)는 건드리지 않는다.
- `.unity`/`.prefab` 직접 편집 금지 - 씬은 기존 인스톨러 재실행으로 갱신.
- 커밋은 사용자 지시 시에만(메인 저장소에 이 작업과 무관한 미커밋 변경 다수).
- 주석은 한국어, "왜" 위주.

## 검토 초점 (테스트로 못 잡는 위험)

1. 근접끼리 밀어내기로 타격 시점에 사거리(1.5)를 살짝 벗어나 헛손질이 잦아짐 → CLI 전투에서 피해가 정상적으로 들어가는지 확인.
2. 공격하며 이동하는 아군(방향성 지시)에서 공격 클립 재생 중 걷기 전환으로 끊김 → 공격 재생 우선 구현 확인.
3. 풀 재사용 시 이전 유닛의 공격 재생 상태 잔류 → `Unbind` 초기화.
4. 도주 시작 시 타격 취소 - 도주는 확률 판정이라 단위 테스트 미작성, 코드 리뷰로 확인.
5. 가져오기 후 공격 클립 크기·피벗이 대기와 달라 튐 → CLI 캡처 확인.
