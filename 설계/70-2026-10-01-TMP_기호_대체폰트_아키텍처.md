# 70-2026-10-01-TMP 기호 대체 폰트 아키텍처

> 상태: 확정(2026-10-01, §7 결정 4건 모두 추천안). 제작·검증·커밋 완료(`fb84ffc`). 선행 기획 없음 — 2026-10-01 지역 시스템 검증 중 확인 패널의 `·`가 □로 깨진 문제에서 출발.

## 1. 목적

한글 TMP 폰트 자산에 없는 문자가 □로 깨지는 문제를 매번 손으로 고치지 않도록, **기호 전용 동적 대체 폰트**를 두고 이를 재실행 가능한 인스톨러로 만든다.

## 2. 현황 (코드·자산 확인 결과)

| 항목 | Youth SDF | KCC-Ahnjunggeun SDF |
|---|---|---|
| 사용처 | TMP Settings 기본 폰트 + 씬 3개(Hub/Field/BattleTest)·UI 프리팹 5개 | **어디에서도 참조하지 않음** |
| 아틀라스 | 정적, 4096², 샘플링 76pt, 패딩 5, SDFAA | 정적, 4096², 74pt, 패딩 5, SDFAA |
| 아틀라스 생성 시 문자 범위 | `32-126, 가-힣, ㄱ-ㅣ, 8200-9900` | 미확인(문자 수가 원본 TTF와 거의 같음) |
| 대체 폰트 목록 | 비어 있음 | 비어 있음 |
| 남은 공간 | 약 12% | 약 9.6% |

- **`·`(U+00B7)·`×`(U+00D7)가 깨진 원인**: Youth 아틀라스를 만들 때 문자 범위에 Latin-1 보충(160-255)이 빠졌다. 원본 `Youth.ttf`에는 두 글자가 모두 있다.
- **`—`(U+2014)**: 두 한글 TTF 모두에 없다. 반면 TMP에 기본으로 들어 있는 `LiberationSans.ttf`에는 있다.
- **TMP Settings**: 전역 대체 폰트 목록이 비어 있고, 빠진 글자는 □로 표시한다.
- **동적 폰트가 빌드에서도 동작하는 조건**: TMP(ugui 2.0.0)는 동적 모드일 때만 원본 폰트 참조를 런타임 필드에 남긴다. 두 TTF 모두 `includeFontData: 1`이므로 빌드에 폰트 데이터가 포함된다.
- **정적 자산에는 글자가 추가되지 않는다**: 정적 자산에 대해서는 글자 추가 요청이 항상 실패한다(`TMP_FontAsset.TryAddGlyphInternal`). 한글 SDF 자체를 동적으로 바꾸면 남은 10% 공간이 찬 뒤 다시 깨지므로, 별도 자산으로 분리한다.

## 3. 구조

```
한글 SDF(정적, 기존 그대로)
  └ 대체 폰트 목록[0] → "<원본> Symbol Fallback"(동적, 같은 TTF, 1024² 다중 아틀라스)
TMP Settings 전역 대체 폰트 목록
  └ LiberationSans SDF (한글 TTF에도 없는 문자용 최종 단계)
```

TMP는 글자를 찾을 때 해당 자산의 대체 폰트 목록을 먼저 보고, 그다음 TMP Settings 전역 목록을 본다. 그래서 다음 순서로 찾는다:

1. 한글 SDF 정적 아틀라스
2. 같은 TTF로 만든 동적 대체 폰트 — 글씨체가 같고, 처음 쓰일 때 아틀라스에 자동으로 추가된다
3. LiberationSans — 한글 TTF에 없는 `—` 같은 문자. 글씨체는 다르다
4. 모두 없으면 □

## 4. 인스톨러: `Editor/FontFallbackInstaller`

- 메뉴: `Tools/Game/Fonts/Install Symbol Fallback`
- 대상: 한글 SDF 목록(코드 상수 — Youth SDF, KCC-Ahnjunggeun SDF). 대상 SDF마다 아래를 수행한다.
  1. **대체 자산을 가져오거나 새로 만든다**: `Resources/Font/FontAssets/<원본 이름> Symbol Fallback.asset`이 없으면 다음 설정으로 새로 만든다.
     - 원본 SDF의 원본 TTF로 동적 자산 생성
     - 원본과 같은 샘플링 크기·패딩·렌더 모드(같은 글자 크기와 굵기로 보이게)
     - 1024², 다중 아틀라스 사용
     - 아틀라스 텍스처와 머티리얼을 하위 자산으로 저장
     
     자산이 이미 있으면 그대로 재사용한다.
  2. **기본 기호를 미리 채운다**: 자주 쓰는 기호 집합(§5)을 넣는다. 이미 있는 글자는 건너뛴다.
  3. **원본 SDF에 등록한다**: 원본 SDF의 대체 폰트 목록에 없으면 맨 앞에 추가한다. 이미 있으면 그대로 둔다.
- 전역 단계: TMP Settings 전역 대체 폰트 목록에 LiberationSans SDF가 없으면 추가한다.
- 모든 단계가 "있으면 재사용, 없으면 생성"이라 재실행해도 안전하다. 바꾼 자산은 저장 표시 후 `AssetDatabase.SaveAssets`로 저장한다.
- 원본 TTF를 찾지 못하면(원본 SDF에 원본 폰트 GUID가 비어 있는 경우) `Debug.LogWarning` 후 그 대상만 건너뛴다.
- 씬과 프리팹은 바꾸지 않는다. 폰트 자산과 TMP Settings만 바꾸므로 씬을 저장할 필요가 없다.

## 5. 미리 채울 기호 집합

`EditorTextSymbols` 같은 별도 상수 대신 인스톨러 안의 문자열 상수 하나로 둔다. 다른 곳에서 쓰지 않으므로 클래스로 분리하지 않는다.

- Latin-1 보충 전체(U+00A0–U+00FF: `·` `×` `÷` `°` `±` 등). 지금 빠진 범위가 이 구간이다.
- 그 밖의 기호는 동적 추가에 맡긴다(원본 아틀라스가 이미 8200-9900 구간을 포함).

## 6. 영향 범위

| 대상 | 변화 |
|---|---|
| `Youth SDF`·`KCC-Ahnjunggeun SDF` | 대체 폰트 목록에 1개 추가(아틀라스 변화 없음) |
| 신규 자산 2개 | `... Symbol Fallback.asset` (텍스처·머티리얼 하위 자산 포함) |
| `TMP Settings.asset` | 전역 대체 폰트 목록에 LiberationSans SDF 추가 |
| 런타임 코드 | 변화 없음 |
| 빌드 크기 | 원본 TTF 데이터가 대체 자산을 통해 포함됨(Youth.ttf·KCC TTF 파일 크기만큼 증가, 정확한 수치 미확인) |
| `TripMapDebugEditor` 확인 문구 | 임시로 `, `로 바꿨다가 대체 폰트 적용 후 `·`로 되돌림(2026-10-01 정상 표시 확인) |
| 마구간 "마차·시설" 문구 | 대체 폰트 적용으로 별도 수정 없이 해결 예상 |

## 7. 결정 사항 (2026-10-01 확정 — 전부 추천안)

| # | 항목 | 확정(추천) | 기각된 대안 |

| 4 | 아틀라스 크기 | **1024² + 다중 아틀라스** — 기호용이라 충분하고, 넘치면 페이지가 자동으로 늘어난다 | 512²(LiberationSans Fallback과 같음) — 더 작지만 76pt 글자는 약 30자에서 첫 페이지가 찬다 |

## 8. 테스트

- 인스톨러는 에디터 자산 작업이라 EditMode 자동 테스트는 두지 않는다.
- 사용자 검증:
  1. 메뉴 실행 → Console에 경고가 없는지
  2. 메뉴를 다시 실행해도 대체 폰트 목록이 중복되지 않는지
  3. Play → `·` `×`와 `—` 문구가 각각 한글 글씨체와 LiberationSans로 표시되는지
