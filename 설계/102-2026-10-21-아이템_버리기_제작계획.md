# 아이템 버리기 제작 계획

> **For agentic workers:** superpowers:executing-plans로 직접 실행(사용자 지시 2026-10-21 — 100~103 연속 자동 진행, 검진은 전체 제작 후).

**Goal:** 인벤토리 편집 본문(팝업 4종·무역품 구매 좌측·회수 적재, 이후 숙소 탭)에 쓰레기통 드롭 버리기와 선택 버리기를 추가한다.

**Architecture:** 저장 계약 `IInventoryArrangement.TryDiscard`(원자적 일괄 삭제, `InventoryGrid.RemoveAll`). UI는 편집 컨트롤러가 소유하는 협력 객체 `InventoryDiscardController`가 선택 상태·경고 대화상자를 맡고, 순수 로직 `InventoryDiscardSelection`·`InventoryDiscardWarning`을 쓴다. 골드 상자 경고는 읽기 계약 `IGoldItemInfo`(상단 물류품 화면만).

**Tech Stack:** Unity 6000.3.7f1, UGUI, TMP, NUnit EditMode.

**Spec:** `Docs/설계/102-2026-10-20-아이템_버리기_아키텍처.md`

## Global Constraints

- 브랜치 `ui`. 커밋은 사용자 지시 시에만. `Docs/` 커밋 금지.
- 씬은 인스톨러 메뉴로만 변경(CLI 직접 실행). 공용 조립은 `EditorUIBuilder`·`InventoryPopupUIBuilder`.
- 문구(스펙 그대로): 경고 `"다음 아이템을 버립니다. 되돌릴 수 없습니다."` + `\n` + `"이름 ×n, 이름"`; 골드 줄 `"\n골드 상자 n개(골드 x)가 사라집니다."`; 선택 안내 `"버릴 아이템을 선택하세요 (n개 선택)"`; 실패 `"버리지 못했습니다. 다시 선택하세요."`. 버튼: 쓰레기통 `"버림"`, 확인 `"확인"`, 취소 `"취소"`.
- 편집 컨트롤러 생성자: `(elements, IInputManager input, IGoldItemInfo goldInfo, reader, arrangement, allowsRotation, hasStaging, hasSections)` — 설계 103이 따른다.
- 테스트: `bash ~/.claude/projects/C--Users-addmin-Desktop-Merchant/tools/ut.sh <클래스|ALL>`.

## Review Focus

1. 경고 대화상자가 열린 사이 아이템이 다른 경로로 사라짐 → `TryDiscard` false, 아무것도 지우지 않고 실패 문구.
2. 선택 상태에서 드래그·Q·정렬 → 막힘(드래그 시작 무시로 Q 구독도 안 생김).
3. 본문 숨김(팝업 닫기·탭 전환) → 선택 상태 종료, 대화상자 닫힘.
4. 골드 상자 버림 → 적재 골드 감소·환급 없음, HUD 갱신.
5. 쓰레기통 위 드롭 판정이 그리드·임시 보관보다 우선, 그 위에서 미리보기 지움.
