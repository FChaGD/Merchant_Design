## 1. 기획 요약

| 화면 | 요점 |

### 4.3 숙소 화면 `InnPanel` (`IUIPanel`, `IPanelCloseGuard`, `IDisposable`)

- 패널 Id `UIPanelIds.Facility(TownFacilityIds.Inn)`.
- 탭 3개 = 편집 본문 컨트롤러(`InventoryArrangementController`) 3개. 생성자 인자는 99(입력)·102(버리기) 이후의 경로를 따른다. 탭 전환 시 선택 본문만 Show, 나머지 Hide.
- 열 때마다 개인 물품 탭 + 1일로 초기화.
- 휴식 버튼: 스테퍼·골드 변경(`IGoldHoldingsReader.Changed`) 때마다 `InnRestPlan`으로 판정. 사유는 `ITooltipController`(설계 100, UIManager 하위 컴포넌트)에 등록한 핸들로 표시, 사유 없을 때만 활성.
- 휴식 클릭 → 진행 화면의 시작 기능에 일수 전달(진행 화면이 자기 패널 Id로 `UIManager.Open` — 네비게이션이 숙소를 닫는다).
- 닫기 직전 확인: 세 본문의 임시 보관 비우기 시도(지금은 항상 통과). 실패 시 안내 + 차단.
- 나가기 → `UIManager.Close(PanelId)`. Dispose에서 골드 구독·툴팁 핸들·컨트롤러 3개 해제.

### 4.4 휴식 진행 화면 `InnRestProgressPanel` (`IUIPanel`, `IDisposable`)

- 패널 Id `UIPanelIds.InnRestProgress`(신규 상수). 모달 채널 등록.
- 시작(일수): 시작 날짜(`IDateReader.Today`)·시작 개인 골드·1일 비용 스냅숏, `RestPacing`으로 하루당 시간, `RestProgressRun` 생성, 휴식 시작 계약 호출, `UIManager.Open`.
- Open: 루트 표시, 진행 상태(중단 버튼 표시·확인 버튼 숨김), `PopupExemptLayer` CanvasGroup의 interactable·blocksRaycasts 끔, 실행 주체(`HubUIWiring`)로 코루틴 시작.
- 매 프레임 `Time.unscaledDeltaTime`으로 진행. 하루가 지날 때마다 1일 경과 계약 호출 + 표시 갱신: "n / 총 m일", 예상 날짜(시작 + n일, `GameDate.ToDisplayString`), 누적 비용(n × 1일 비용), 예상 남은 개인 골드(시작 골드 − 누적 비용). 게이지는 전체 비율.
- 이벤트 알림·회복 표시 영역은 빈 자리.
- 완료 또는 "휴식 중단": 코루틴 정지 → 휴식 종료 계약(실제 일수) → 결과 상태(게이지 정지, 결과 문구 "n일 휴식 완료/중단, 비용 x", 중단 버튼 숨김·같은 자리 확인 버튼 표시).
- 확인 → `UIManager.Close(PanelId)` → 숙소 복귀.
- Close/Dispose: 코루틴 정지, HUD 레이어 CanvasGroup 복구.
- HUD 레이어 CanvasGroup이 없으면(인스톨러 미실행) 경고 후 차단 없이 동작.

### 4.5 상인조합 화면 `MerchantGuildPanel` (`IUIPanel`, `IDisposable`)

- 패널 Id `UIPanelIds.Facility(TownFacilityIds.MerchantGuild)`.
- 전용 요소 묶음 `MerchantGuildElements`, 행 뷰 `GuildQuestRowView`(제목 | 의뢰자 | 상태 "수락함", 선택 외곽선). 구매 행(아이콘·가격) 전용인 `RosterShopCandidateList`는 재사용하지 않는다.
- 행 선택 → 상세(제목·설명·보상) + 수락 버튼. 수락함이면 버튼 비활성 + 상태 문구 "수락함".
- 수락: 확인 창 없이 계약 호출 → 게시판 변경 이벤트로 목록·상세 재그림.
- 빈 목록: "수락 가능한 의뢰 없음". 나가기 → `UIManager` 위임.

### 4.6 마구간 매각 `StableSaleController` (`StablePanel` 소유, plain C#)

> 2026-10-26 개정: 아래 "우측 정보 영역 모드" 구조는 폐기 — 좌측 개체 정보 화면의 수리 오른쪽에 매각가·사유·[매각]을 두고 `StableOwnedSection`이 협력 객체를 소유한다(머리말 개정 참조).

- `StableOwnedSection`에 선택 이벤트 추가(개체 선택 시 Id, 목록 복귀 시 null).
- `StablePanel`은 우측 정보 영역 모드(구매/매각)만 보유:
  - 보유 개체 선택 → 후보 선택 해제, 매각 모드.
  - 후보 선택 → 구매 모드.
  - 보유 영역 목록 복귀 → 매각 모드 해제(정보 영역 비움).
- 매각 모드 표시(협력 객체가 담당): 이름(`OwnedCaravanAssetNames.Format`), 종류, "매각가 x", 사유("화물이 실린 마차는 매각할 수 없습니다." / "마지막 마차는 매각할 수 없습니다."), 매각 버튼은 Available일 때만 활성.
- 구매 버튼과 같은 자리의 별도 매각 버튼, 모드에 따라 하나만 활성 — 버튼 문구·리스너 교체를 피한다.
- 매각 → 공용 확인 대화상자 "n번 이름을 x골드에 매각합니다"(확인 "매각" / 취소 "취소") → 확인 시 매각 계약 → 재그림.
- 갱신: 보유 변경은 기존 구독, 무역품 인벤토리 변경은 매각 모드일 때만 추가 구독(모드 해제·Close·Dispose 시 해제).
- 판매 서비스가 없으면(미등록) 매각 버튼 비활성 + 사유 "값 없음".

### 4.7 배선 (`HubUIWiring`)

- 추가 조회(`TryResolve`): `IInnRestService`, `IGuildQuestBoard`, `ICaravanAssetSaleService`. `ITooltipController`는 UIManager 하위 컴포넌트로 `GetComponent`(설계 100).
- `RegisterInn`(숙소 + 진행 화면 함께), `RegisterMerchantGuild` 추가. `RegisterStable`에 매각 서비스·무역품 인벤토리 전달.
- 진행 화면은 `this`(MonoBehaviour)를 실행 주체로, `RestPacingSettings`(직렬화 필드)를 받는다.
- 새 패널 3종도 이전 인스턴스 Dispose + `OnDestroy` 해제 목록에 추가.
