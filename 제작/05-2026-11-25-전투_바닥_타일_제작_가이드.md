## 1. 기획 (유료 생성 전에 확정)

| 항목 | 정할 내용 | 근거 |
|---|---|---|
| 분류·장 수 | 예: 잔디 5·잡초 3·꽃 5·흙 3 | 장 수는 띠 PNG 줄 수로 자동 반영 |
| 비율 | 꼭짓점 기준 비율 | 인게임 후 바닥 세트 인스펙터로 조정 |
| 쌓는 순서 | 고정 순서표상의 위치(현재 잔디 → 잡초 → 꽃 → 흙) | 생성 비율로 순서를 정하면 비율 변경 시 순서가 뒤집혀 기각(기획 119 §4.6) |
| 샘플링 | 결만 있는 재질(잔디류) = 육각 무작위 샘플링 / 큰 구조가 있는 재질(흙 균열) = 일반 반복 | 육각 샘플링을 흙에 쓰면 균열이 조각남(기획 119 §11.6) |
| 경계 | 또렷한 곡선+테두리 / 부드럽게 옅어짐 | 흙 = 또렷, 잡초·꽃 = 부드러움 |
| 기준 잔디 | 색·밝기를 맞출 기준 그림 1장 | 현재 wgrass_3(Grass_1) |

## 2. 생성 (Ludo)

- **꽉 찬, 자기와 이음매 없는 타일만** 만든다. 경계 그림(전환 타일·덮개)은 셰이더가 만들므로 필요 없다.
- `createTile`(square, texture), `art_style: Western Cartoon`, **레퍼런스 없이**가 가장 잘 나왔다. 레퍼런스를 주면 결이 잘고 옅어진다.
- 분류별로 몇 장 시험 생성 → 선정. 받은 URL은 7일 후 만료 - 즉시 `ArtSource/BattleFloor/<날짜>/`에 1024px 원본 저장, README에 생성 조건·판단 기록.
- 크레딧은 생성 전 잔액 확인. 시험분은 장당 약 1크레딧(2026-11 기준).

## 3. 로컬 후처리 (`ArtSource/.../tools/`, 크레딧 0)

- 잔디류: 큰 명암 평탄화(저주파 제거) → Lab 평균·편차를 기준 잔디에 맞춤 → 채도 보정(현재 +15%).
- 구조 있는 재질(흙 등): **원본 1장 + 노이즈 얼룩 변형**으로 장 수를 만든다. 가장자리는 공통으로 맞춘다(변형끼리 칸 전환 이음매 없음). 균열 모양이 다른 원본끼리 섞으면 사각형·이중 균열이 드러난다.
- 축소(1024 → 256)는 타일을 감아(wrap) 덧댄 뒤 줄이고 잘라 이음매를 보존한다.
- PIL LAB 모드는 a·b를 부호 있는 바이트로 담는다 - numpy로 직접 변환.

## 4. 미리보기 판단 (가장 중요)

- 낱장이 아니라 **섞어 깐 상태**로 판단한다. 개별 타일은 자기와만 이음매가 없고 서로 섞으면 경계가 드러난다.
- **확대·축소를 둘 다** 본다. 설계 120 A4(잡초·꽃 바둑판)는 멀리서는 괜찮고 확대에서만 드러났다.
- 셰이더 계산(스플랫 보간 + 경계 공식 + 육각 샘플링)을 Python으로 흉내 낸 미리보기를 쓴다. 비교안은 라벨 붙인 한 장으로 합쳐 띄우고, 결정 후 합친 파일은 삭제(원본 유지).

## 5. 자산 굽기·적용

1. `tools/build_final.py`에 선정본 목록을 고쳐 실행 → `final_256/`(낱장) + `{분류}_Array.png`(세로 띠, 위 = 1번) + `FloorEdgeNoise.png`.
2. 수치 확인: 띠 재분할 = 낱장 픽셀 일치. 경계 노이즈를 바꿨다면 흙 경계 모양 재현 확인.
3. `VibeProject1/Assets/Resources/UI/Textures/BattleFloor/`에 띠·노이즈 복사(단일 그림용 `Grass_1.png` 유지). 임포트 설정(2D Array·Repeat·밉맵 / 노이즈 Linear)은 `UIArtImportPostprocessor`가 파일 이름으로 자동 적용 - `.meta` 직접 편집 금지.
4. Build Bootstrap Scene 실행 → 바닥 세트(`BattleFloorSet.asset`)에 배열·노이즈·머티리얼 재연결(조정 값은 유지됨) → 씬 저장. CLI로 직접 실행.
5. EditMode 테스트 + 배틀 테스트 씬 Play 캡처(기본·최대 줌 아웃·줌 인).

## 6. 인게임 판단 → 조정

- 바닥 세트 인스펙터: 비율(흙·잔디·잡초·꽃), 군집 크기, 작은 노이즈 크기·세기, 육각 크기·날카로움, 흙 경계 세기·폭·테두리, 잡초·꽃 경계 세기·폭.
- Play 중 조정은 다음 전투부터 반영(맵 판정 값은 다음 Field 진입부터).
- 인게임 테스트 항목은 설계 121 §11을 기준으로 쓴다.

## 7. 새 재질 추가 (코드 작업 필요)

현재 셰이더는 잔디·잡초·꽃·흙 4재질 고정이다.

| 추가 수 | 변경 범위 |
|---|---|
| 1재질 | 스플랫 빈 채널(A) 사용 - 셰이더 단계 1개, 배열 1개, 맵 판정 1개(비트·비율), 바닥 세트 필드, 빌더·후처리 이름 규칙 |
| 2재질 이상 | 스플랫 텍스처 2장으로 확장 - 설계 변경 범위 큼 |

- 순서표상 위치·샘플링 방식·경계 종류를 §1처럼 기획에서 먼저 정한다.
- 지역별 바닥 세트 연결은 아직 범위 밖(기획 119 §5) - 지역마다 다른 바닥이 필요하면 별도 기획.
