## 1. 씬 구성

| 씬 | 역할 |
|---|---|
| Bootstrap | 영속. 매니저·패널 로직·검은 커튼(정렬 순서 100)·로딩바 |
| Hub(마을) / Field(필드) | 콘텐츠 씬. Additive로 로드, 한 번에 하나. 각자 EventSystem·Camera를 가진다 |
| BattleTest | 독립 테스트 씬(이 전환 절차를 쓰지 않음) |

## 2. 전환 절차 (최초 진입 포함 모든 전환)

| 순서 | 최초 진입(Bootstrap → 마을) | 마을 ↔ 필드 |
|---|---|---|
| 가리기 | 첫 화면이 그려지기 전에 커튼을 불투명으로 띄운다 | 현재 씬 콘텐츠가 슬라이드 아웃(0.9초, ease-in cubic), 커튼이 반대편에서 함께 들어온다 |
| 로딩바 표시 | 커튼과 함께 | 커튼이 화면을 다 덮은 뒤 |
| 로딩 작업 | ① 마을 불러오는 중 → ③ 화면 연결 중 → ④ 준비 작업 | ① 불러오는 중 → ② 이전 화면 정리 중 → ③ 화면 연결 중 → ④ 준비 작업 |
| 완료 | 100%를 1프레임 보여 준 뒤 로딩바 숨김 | 같음 |
| 드러내기 | 커튼 2초 페이드(ease-in cubic) → "화면 드러남" 신호 | 같음 |
| 상호작용 | 드러남 신호 전에는 상행 시작·배치 등 버튼 비활성 | 같음 |

- 방향: 마을 → 필드는 왼쪽으로, 필드 → 마을은 오른쪽으로 빠진다(기획 10 §4).

## 3. 로딩바

| 항목 | 현행 |
|---|---|
| 표시 | "로딩 중" + 게이지 + 현재 작업 이름 + 백분율(정수 %) |
| 게이지 | **끝난 작업 수 ÷ 전체 작업 수**. 작업 내부 진행은 연동하지 않는다(작업 단위) |
| 작업 수 확정 | 전환을 시작할 때 정해지고 도중에 늘지 않는다(게이지가 뒤로 가지 않음) |
| 예 | 최초 진입(마을) 3개: 33 → 66 → 100%. 필드 → 마을 4개: 25%씩 |

## 4. 준비 작업 (로딩 ④)

| 씬 | 작업 이름 | 내용 |
|---|---|---|
| 마을 | 상단 배치 준비 중 | 정비창 칸·아이콘 풀 미리 생성(첫 클릭 지연 해소) |
| 필드 | 정비창 준비 중 | 상행 중 정비창 칸·아이콘 풀 미리 생성 |

- 추가 방법: Bootstrap 상주 컴포넌트(UIManager 산하)가 `ISceneLoadingTaskSource`로 작업을 내놓으면 UIManager가 초기화 때 `SceneLoadingCoordinator`에 등록한다. 작업 1개 = 로딩바 1칸.
- 작업이 예외를 내면 로그만 남기고 끝난 것으로 친다(로딩이 멈추지 않음).

## 5. 미정·후속

- 로딩이 길어질 작업(저장 데이터 불러오기 등)이 생기면 작업을 추가만 하면 된다 — 작업 내부 진행 표시가 필요해지면 그때 계약을 넓힌다.
