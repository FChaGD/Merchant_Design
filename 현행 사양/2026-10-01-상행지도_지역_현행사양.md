## 1. 지역과 지도

| 항목 | 현행 |
|---|---|
| 지역 | 월드를 여러 지역으로 나눈다. 도시·관문은 정확히 한 지역에 속한다 |
| 지도 | 한 번에 **지역 하나**만 표시. 그 지역의 도시·관문·도로만 그린다 |
| 좌표 | 지역별 지도 기준(좌하단 원점). 지도 크기 2400 × 2400 |
| 열 때 보이는 지역 | 현재 위치 도시의 지역 |
| 지역 전환 | ① 관문(지역 아이콘) 클릭 → 짝 관문의 지역 ② 지도 상단 지역 드롭다운(이어지지 않은 지역도 볼 수 있음) |
| 빌드 | 지도·도착지 선택이 빌드에도 포함(디버그 편집만 에디터 전용) |

## 2. 출발지·도착지

| 항목 | 현행 |
|---|---|
| 출발지 | 항상 **현재 위치**. 정보 패널은 표시 전용 |
| 현재 위치 최초값 | 도시 4(대도시, 임시값 — 시작 도시 결정은 후속 과제) |
| 현재 위치 갱신 | 필드에서 도착이 판정되는 시점에 그 상행의 도착지로. Play 세션 동안만 유지 |
| 도착지 지정 | 지도에서 도시 클릭만. 현재 위치 클릭은 무효. 같은 도시 다시 클릭 = 해제. 다른 도시 = 도달 가능하면 교체 |
| 도달 판정 | 현재 위치와 같은 끝점 그래프(도로 + **관문 짝**)에 이어져 있으면 도달 가능. 홉 수 제한 없음, **지역을 넘어 판정** |
| 지역을 바꿔도 | 도착지는 유지. 도착지 정보 패널에 도시 이름 + 지역 이름 |
| 강조 표시 | 현재 위치·도착지는 그 도시가 있는 지역을 볼 때만 강조 |
| 관문 클릭 | 지도 전환만(도착지가 될 수 없음) |
| 상행 시작 | 도착지가 있어야 활성(빌드·에디터 공통) |
| 이름 없는 도시 | 이름 "디버그 도시 N", 설명 "값 없음" |

## 3. 관문(지역 아이콘)

| 항목 | 현행 |
|---|---|
| 정의 | 도로의 중간 지점. 서로 다른 두 지역의 관문 한 쌍이 서로를 짝으로 가리킨다 |
| 쌍 개수 | 두 지역 사이에 여러 쌍 허용 |
| 모양 | 보라색 사각형 + 가리키는(짝이 있는) 지역 이름 라벨 |
| 도로 없는 관문 | 허용 — 지도 전환 통로만, 상행 경로는 아님 |

## 4. 데이터 (`Assets/Table/City/City.xlsx`)

| 시트 | 열 | 비고 |
|---|---|---|
| `RegionData` | `Id`, `Width`, `Height` | 전 지역 2400 |
| `RegionStrings` | `Id`, `Name` | |
| `CityData` | `Id`, `RegionId`, `X`, `Y`, `Scale` | `Scale` = 대도시·도시·촌락(마을 규모, 시설 결정) |
| `CityStrings` | `Id`, `Name`, `Description` | |
| `GateData` | `Id`, `RegionId`, `X`, `Y`, `PairGateId` | |
| `RoadData` | `NodeA`, `NodeB` | 끝점 표기 `C`+도시 Id / `G`+관문 Id(번호 공간 분리) |

- 임포트(Play 시 자동) → `TripCityMap.asset`·`TripCityStringsTable.asset`·`TripRegionStringsTable.asset`.
- 임포트 오류: 없는 지역 Id, 관문 짝 없음·서로 안 가리킴·같은 지역, 도로 끝점 형식 오류·없는 끝점, **도로 두 끝점이 다른 지역**(지역 사이는 관문 짝이 잇는다).

## 5. 디버그 편집 (에디터 전용, 보이는 지역 대상)

| 기능 | 현행 |
|---|---|
| 도시 배치·이동 | 팔레트에서 끌어 놓기 / 드래그 |
| 관문 배치 | 팔레트 옆 `연결할 지역` 드롭다운(보이는 지역 제외, 기본 첫 항목)에서 고른 뒤 놓는다 → 짝이 상대 지역 지도 중앙에 자동 생성. 다른 지역이 없으면 팔레트 비활성 |
| 도로 | 도로 모드에서 끝점 사이 드래그(같은 지역만). 선 더블클릭 삭제 |
| 삭제 | 끝점을 지도 밖으로 끌기. 관문은 짝과 연결 도로까지 함께 삭제. 도착지였던 도시가 지워지면 도착지 해제 |
| 전체 삭제 | 도시·도로 전체 삭제는 보이는 지역만 |
| 지역 추가 | Id = 최대 + 1, 이름 "지역N", 2400. 추가 후 그 지역으로 전환 |
| 지역 삭제 | 보이는 지역 대상. 지역 1개뿐·현재 위치 지역이면 불가. 내용이 있으면 확인 패널("도시 N개·관문 M개가 함께 삭제됩니다"). 그 지역 도시·관문, 다른 지역 짝 관문, 연결 도로를 함께 삭제 → 현재 위치 지역으로 전환 |
| 저장 | 저장 버튼 → `City.xlsx` 전 시트 다시 쓰기. `Scale`·스트링의 입력값 보존, 새 도시·지역에만 자리표시자 행. 다음 Play에 자동 반영 |

## 7. 미정·후속

- 지도 콘텐츠 크기 2400 고정 — 지역별 크기가 달라지면 콘텐츠 크기 조정 필요.
- 범위 밖(기획 68 §2): 지역별 배경 그림, 지역 간 이동 시간·위험도 차등, 지역 해금, 월드 전체 지도.
- 시작 도시(현재 위치 최초값) 결정, 현재 위치 영속 저장.
