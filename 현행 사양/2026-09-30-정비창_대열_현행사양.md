## 1. 판과 대열

| 항목 | 현행 |
|---|---|
| 외곽 판 | 50 × 50 고정. 기준 칸(원점) = (24, 24) |
| 대열(영역) | 판 중 유닛을 놓을 수 있는 칸. 마차·시설(·디버그 핀) 영역의 합집합. 배치가 바뀔 때마다 다시 계산 |
| 마차가 없을 때 | 대열 = 기준 칸 1칸(+ 디버그 핀 영역) |
| 판 가장자리 | 판 밖으로 나가는 영역 칸은 잘린다 |

## 2. 영역 모양 (데이터)

| 항목 | 현행 |
|---|---|
| 데이터 | `Wagon.xlsx`·`Facility.xlsx` 데이터 시트 `AreaShape` 열(개체 단위 — 한 행 = 마차 1대 / 시설 1개) |
| 표기 | 마스크 문자열. `/` 줄 구분(위 줄부터), `1` = 대열 칸, `0` = 아님, `2` = 기준 칸(유닛이 놓인 칸, 정확히 1개, 대열 칸으로 침) |
| 배치 | 기준 칸을 유닛 칸에 맞춰 겹친다. 정비창 화면 기준 방향, 회전 없음 |
| 기본값 | 전 행 7 × 7 전부 대열, 가운데 기준 칸 |
| 떨어진 조각 | 허용. 조각도 대열 칸이다 |
| 형식 오류 | 임포트 오류(Play 시 자동 임포트). 임포트 전 자산이 틀렸으면 기준 칸 1칸으로 처리 + 경고 |

## 3. 배치 규칙

| 대상 | 규칙 |
|---|---|
| 캐릭터 | 대열 칸 안에만 |
| 시설 | **마차 영역(디버그 핀 영역 포함) 안에만**. 시설이 넓힌 칸에는 시설을 놓을 수 없다(캐릭터·마차는 가능) |
| 마차 — 마을 정비창 | 판 어디든. 이미 마차가 있으면 놓은 뒤 모든 마차가 이어져야 한다 |
| 마차 — 상행 중 정비창 | 새로 배치·제거 불가(팔레트에 마차 안 보임). 현재 대열 안에서 이동만 |
| 연결 판정 | 연결 칸 = 마차·핀 영역 + 그 위 시설 영역. 4방향으로 맞닿은 칸을 한 덩어리로 보고, **모든 마차 칸이 한 덩어리 안**이면 연결. 조각은 다른 마차들을 이어 줄 수 있지만 조각만 닿고 기준 칸이 떨어진 마차는 이어지지 않은 것으로 본다 |
| 편집 판정 시점 | 이동·제거·배치를 반영하고, 마차 영역 밖이 된 시설 해제까지 반영한 **최종 상태**로 연결을 본다. 끊기면 그 편집 거부(해제도 일어나지 않음), 거부된 칸은 붉게 깜빡임 |
| 영역 밖 유닛 | 편집 결과 대열 밖이 된 캐릭터·마차 영역 밖이 된 시설은 자동 해제(팔레트로) |
| 마차가 없을 때 | 기준 칸에는 마차만(디버그 핀 영역에는 캐릭터도 가능). **편집 후** 마차가 0대가 되는 배치도 같은 규칙 — 마을 팔레트 드롭으로 마지막 마차를 캐릭터·시설로 덮어쓰면 거부(2026-10-12) |
| 점유 칸에 놓기 — 그리드 이동 | 기존 유닛과 맞바꾼다(마을: 로컬 사본, 상행: 활동으로 반영). 밀려나는 유닛이 원래 칸에 있을 수 없으면 거부 |
| 점유 칸에 놓기 — 팔레트 드롭 | 마을: 기존 유닛을 덮어쓰고 배치에서 뺀다(팔레트로). 빠지는 유닛이 마차면 연결 판정, 마지막 마차면 위 규칙으로 거부. 상행 중: 빈 칸에만 놓을 수 있다(거부) |
| 배치 상한 | 없음(기획 80 §3-10에서 폐기). 대열 영역과 보유 수만 제약 |

## 4. 로스터·팔레트

| 항목 | 현행 |
|---|---|
| 보유 단위 | 개체 단위 — 캐릭터(직업당 시작 2명, 고용으로 증가), 마차·시설(종류별 시작 1개, 마구간 구매로 증가). 보유 상한 없음(기획 80 §3-10) |
| 팔레트 | 카테고리당 1줄, "잔여 / 보유" 표시, 잔여 0이면 흐림(드래그 불가) |
| 보유 순서 | 시작 보유 → 획득 순(`IOwnedCaravanAssetReader`) — 상단 물류품 마차 순서도 이것을 따른다 |

## 5. 마을 정비창 vs 상행 중 정비창

| 항목 | 마을(상단 배치) | 상행 중 |
|---|---|---|
| 반영 | 로컬 편집 후 적용 버튼 | 즉시 반영, 배치·이동은 시간이 걸리는 활동 |
| 신규 배치 | 즉시 | 소요시간(캐릭터 짧음, 마차·시설 김). 진행 중 칸에 반투명 표시 + 잔여 시간 |
| 이동 | 즉시 | 경로를 따라 실시간 이동(다른 유닛 칸·대열 밖 칸을 피함). 도착지 고스트를 드래그해 목적지를 실시간 수정 — 지나온 구간 유지, 남은 구간만 다시 계산 |
| 제거 | 즉시(연결 판정) | 캐릭터 즉시. 진행 중 활동은 취소하고 로스터로 복귀 |
| 인카운터 | — | 타이머 일시정지·이동 중단(중단 지점 좌표로 전투 참가). 전투 중 타이머가 끝나면 즉시 소환. 승리·도주 후 재개, 패배(궤주·포로·사망)면 즉시 완료 |
| 대열 계산 | 배치된 유닛 | 배치 완료된 유닛만(진행 중 배치는 영역을 넓히지 않음) |

## 6. 화면

| 항목 | 현행 |
|---|---|
| 칸 색 | 주황 타일 = 대열 칸, 민트 = 판 칸(대열 아님), 어두운 회색 = 판 밖 |
| 여는 화면 | 대열 경계 + 2칸 범위 전체 보기(최대 축소). 마차가 없으면 기준 칸 중앙 |
| 칸을 까는 범위 | 마을: 대열 경계 + (로스터 마차들의 기준 칸~가장 먼 대열 칸 거리 최댓값 + 1), 최소 2. 상행: 대열 경계 + 2 |
| 확대·스크롤 | 최대 축소 범위 안에서 확대 후 스크롤. 휠 한 칸 = 배율 20%, 목표 배율까지 부드럽게 |
| 편집 중 화면 | 대열이 바뀌어도 보던 위치·배율 유지. 마지막 마차를 뺀 순간만 기준 칸으로 이동 |
| 첫 열기 | 씬 로딩 중(검은 커튼 뒤) 칸·아이콘 풀을 미리 만들어 첫 클릭 지연 없음(설계 67) |

## 7. 전투로 넘기는 값

- 대열 범위(`FormationExtent`) = 중심은 마차 칸 평균(없으면 기준 칸), 반폭은 중심에서 대열 경계 상자 가장자리까지의 최대 거리(열·행 각각). 전장·출현·활동 반경과 아군 시작 위치가 이 값에서 나온다.
- 정비창 행은 전장 x축, 열은 y축. 전투에는 고정된 전방이 없다(적 출현점은 원형).
- 알려진 제한: 전투 대열 범위 계산에 디버그 핀은 포함되지 않는다(디버그 전용).

## 8. 디버그 도구 (에디터 전용)

| 도구 | 현행 |
|---|---|
| 디버그 핀 | 모양 마스크 입력칸 1개(기본 9 × 9, 가운데 2). 핀을 판에 끌어다 놓으면 그 모양의 영역 생성. 판 어디든 여러 개. 형식 오류면 핀을 놓지 않고 빨간 안내. 핀 클릭 = 제거 시도(마차 연결을 끊으면 거부, 마차·시설 영역과 겹치는 칸은 남음). 설치: `Tools/Game/Debug/Install|Remove/Formation Debug Pins` |
| 대열 외곽선 | 마을 정비창만. 파랑 = 마차 영역, 보라 = 시설 영역. 설치: `Tools/Game/Debug/Install|Remove/Formation Area Outline` |

- 마차 종류별 영역 모양 차등(현재 전 행 같은 값).
