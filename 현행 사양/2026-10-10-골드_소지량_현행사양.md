# 골드 소지량·적재 골드 현행 사양

작성일: 2026-10-10 (기획 82 / 설계 83 제작 완료, `system` 브랜치 `89116d5`~`3d6d09f`)
성격: 골드(개인·적재)의 계산·지출·변환·출발 버림·HUD 규칙을 **지금 코드 기준 하나로** 모은 요약. 규칙이 바뀌면 이 문서도 함께 고친다.
출처: [기획 82](../기획/시스템/82-2026-10-09-골드_소지량_적재골드_기획.md), [설계 83](../설계/83-2026-10-10-골드_소지량_적재골드_아키텍처.md)
대체된 이력(참고만): 기획 26·설계 29의 지갑 상한(기본 소지 재화 = 상한), 기획 31 §3.4의 골드 상자 배치 시 지갑 차감·제거 시 환급 → 기획 82

## 1. 용어와 계산식

| 용어 | 정의 |
|---|---|
| 개인 골드 | 지갑 금액. 획득 상한 없음 |
| 개인 소유 가능량 | 500(지갑 인스펙터). 상한이 아니라 출발 시 버림 기준 |
| 적재 골드 | 골드 상자 수 × 500. 모든 보유 마차 그리드 + 임시 보관 합산 |
| 빈 칸 | 모든 보유 마차의 적재 가능 칸 − 그리드에 놓인 아이템 점유 칸(임시 보관 제외) |
| 여유 공간 환산 | 빈 칸 × 골드 아이템 칸당 가치(현재 500) |
| 소유 골드 | 개인 골드 + 적재 골드 |
| 최대량(소지 가능 골드량) | 개인 소유 가능량 + 여유 공간 환산 + 적재 골드 |
| 버려질 골드 | max(0, 개인 골드 − 개인 소유 가능량) |

- 시작 개인 골드: 10,000(지갑 인스펙터, 검증용).
- 골드 아이템: `gold-box` 1종(1×1, 가치 500 — 가치는 골드 보유 서비스 인스펙터 값). 1×1이 아니면 변환을 막는다.

## 2. 지출 (무역품 구매·용병 고용·마차/시설 구매 공통)

| 항목 | 현행 |
|---|---|
| 구매 가능 판정 | 소유 골드 ≥ 가격 |
| 지출 순서 | 개인 골드 먼저. 부족하면 ⌈부족분 ÷ 500⌉개 상자를 인출해 개인 골드로 바꾸고 지출, 거스름돈은 개인 골드에 남음 |
| 인출 순서 | 임시 보관 상자 → 점유율(점유 칸 ÷ 사용 가능 칸) 높은 마차(동률이면 보유 목록 뒤쪽) → 마차 안 아래 행·오른쪽부터. 점유율은 인출 시작 시 한 번만 계산 |
| 지급 실패 롤백 | 개인 골드로만 환불. 인출한 상자·적용된 재배치는 되돌리지 않음 |

## 3. 무역품 구매 공간 판정

| 항목 | 현행 |
|---|---|
| 판정 순서 | 품절 → 소유 골드 부족 → 공간 부족 |
| 자리 찾기 | 인출될 상자 자리를 빈 칸으로 보고, 보이는 마차부터 바로 놓을 자리를 찾음 |
| 재배치 | 바로 놓을 자리가 없으면 후보 자리를 덮는 물품만 1단계로 옮김(같은 마차 → 다른 마차, 보유 순서). 옮길 물품 수 → 옮길 칸 수가 적은 자리, 같으면 위 행·왼쪽 우선(회전 방향끼리 동률일 때는 회전 없는 쪽 유지 — 보류 경미 사항). 연쇄 이동 없음 |
| 공간 부족 예 | 개인 골드가 충분한데 마차가 골드 상자로 꽉 참 / 개인 골드 0에서 2칸 이상의 싼 물품(상자 1개만 인출) |

## 4. 골드 상자 변환 (Hub만)

| 항목 | 현행 |
|---|---|
| 진입 | HUD 골드 패널 짧은 클릭 → 변환 모달(모달 채널. 상행 준비 화면에서 열면 닫을 때 상행 준비로 복귀) |
| 최대 변환 개수 | min(⌊개인 골드 ÷ 500⌋, 빈 칸) |
| 초과분 전부 | min(⌈버려질 골드 ÷ 500⌉, 최대 변환 개수). 모달을 열 때 스테퍼 초기값 |
| 표시 | 개인 골드, 개인 소유 가능량, 빈 칸, 변환 후 개인 골드, 출발 시 버려질 골드, "골드 상자 n개 (금액)" |
| 배치 | 보유 목록 앞쪽 마차, 위 행·왼쪽부터 첫 빈 칸(회전 없음) |
| 변환 후 | 모달 유지, 스테퍼는 남은 초과분 전부로 다시 맞춤 |
| 역변환 | 없음. 그리드에서 상자를 빼도 환급하지 않음(골드 상자 사용은 후속) |

## 5. HUD (Hub)

| 항목 | 현행 |
|---|---|
| 표기 | 한 줄: [골드 아이콘] 소유 골드(천 단위 구분) (마차 적재량 n)  [마차 아이콘] 마차 수  [용병&시설 아이콘] 용병 수/시설 수(설계 101). 아이콘은 자리표시(흰 사각형). 폭은 화면 30% 고정, 넘치면 세 글자가 같은 크기로 축소(최소 12) |
| 보유 수 | 정비창 팔레트와 같은 보유 목록 기준. 고용·구매·제거 즉시 갱신 |
| 색 | 소유 골드 > 최대량 → 빨강 / 개인 골드 > 개인 소유 가능량 → 노랑 / 그 외 흰색 |
| 툴팁 | 골드 구역에서만 호버 또는 0.3초 이상 누름. 패널 바로 아래 띠(공용 툴팁 모양, 줄 수에 맞춘 높이). `최대량 n (개인 a / 적재 b / 여유 공간 c)` |
| 누르기 구분 | 골드 구역만 입력을 받는다(마차·용병 칸은 무반응). 짧게 눌렀다 떼면 모달, 길게 누른 뒤 떼면 모달 안 열림, 누른 채 패널 밖으로 나가면 클릭 취소 |
| 골드 보유 서비스 없음 | HUD 숨김 |

## 6. 출발 경고·버림

| 항목 | 현행 |
|---|---|
| 경고 | 배치 유닛 0 → 골드 순서로 순차 표시, 각각 독립 판정 |
| 골드 경고 문구 | `개인 소유 가능량 {a}을 넘는 {n}골드가 버려집니다. 마차에 적재하거나 은행에 보관하지 않은 골드는 버려집니다. 그래도 출발하시겠습니까?` |
| 취소 | 어느 단계든 취소하면 출발·골드 모두 변화 없음 |
| 확정 | 모두 확인하면 개인 골드를 개인 소유 가능량으로 줄이고 출발. 적재 골드는 그대로 |
| 확인 대화상자 없음(깨진 씬) | 경고 없이 버리고 출발(사용자 결정 2026-10-10) |
| 금지 조건 | 대열 끊김·임시 보관 잔여·도착지 미지정은 버튼 비활성(골드 초과는 금지 아님) |

## 7. 변경 알림

- 골드 보유 변경 이벤트는 지갑·교역품 저장소 어느 쪽 변경에도 발생하고, 지출·변환처럼 여러 번 바꾸는 연산은 끝난 뒤 한 번만 발생한다.
- 전투 손실로 골드 상자가 사라지면 그대로 손실(환급 없음).

## 8. 디버그

- 재화 디버그 버튼 줄(±100/±1000): 개인 골드만 조절, 상한 없이 증가. HUD 왼쪽 같은 줄에 표시하고, 배치 화면 디버그 패널이 보이는 동안 숨김.

## 9. 미정·후속

- 골드 아이템 종류 확장(칸당 최대 효율 재계산, 변환 자리 탐색), 골드 상자 사용(역변환), 상행 중 변환·Field HUD, 은행 시설.
- 연쇄 재배치(2단계 이상), 인출 순서 선택·수동 인출.
- 전투 정산 계약(`ITradeGoodsCargoSettlement`)과 일반 경로 통합.
