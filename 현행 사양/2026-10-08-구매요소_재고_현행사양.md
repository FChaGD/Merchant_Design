# 구매 요소·마을 재고 현행 사양

최종 갱신: 2026-10-10 (판정 기준 소유 골드로 변경 — 기획 82 / 설계 83). 이전: 2026-10-08 (기획 80 / 설계 81, `system` 브랜치)
근거: [기획 80](../기획/80-2026-10-08-구매요소_재고_기획.md), [설계 81](../설계/81-2026-10-08-구매요소_재고_아키텍처.md)

## 재고 테이블 `Assets/Table/Town/TownStock.xlsx` (시트 `TownStock`)

| 열 | 내용 |
|---|---|
| CityId | City.xlsx CityData Id |
| Category | `Wagon` / `Facility` / `TradeGoods` (이름 문자열) |
| ItemId | Category 테이블(Wagon/Facility/TradeGoods ItemData)의 Id |
| Quantity | 1 이상 |

- 행 있음 = 그 마을에서 판매, 행 순서 = 화면 순서. 판매 시설: 마차·시설 → 마구간, 무역품 → 무역품 구매.
- 의뢰 화물(TradeGoods.xlsx `TradeKind` = 3)은 퀘스트 수락 때만 지급되는 전용 행이라 재고 행으로 넣을 수 없다(임포트 오류, 2026-10-27, 설계 107 §16).
- 임포트 오류: 알 수 없는 Category, 없는 CityId/ItemId, 수량 ≤ 0, (CityId, Category, ItemId) 중복.
- 마을 규모상 시설이 없는 마을의 행: 실행 중 경고 1회 후 무시.
- 재고는 앱 실행 중 유지(재시작 시 초기화). 재입고 없음. 파손·파괴로 보유가 줄어도 재고는 늘지 않음. **예외: 마구간 매각은 판 마을 재고 +1, 그 종류 행이 없으면 목록 끝에 수량 1로 추가**(2026-10-27, 설계 104). 매각가 = ⌊구매가 × 0.5 × 현재 ÷ 최대 내구도⌋, 개인 골드로 지급, 대열은 파괴와 같은 정리(재배치·팔레트 복귀).

## 구매 규칙

- 판정 순서: 품절 → 소유 골드(개인 + 적재) 부족 → (무역품) 공간 부족. 재고 차감은 지급 뒤 마지막. 지출·인출 규칙은 [골드 소지량 현행 사양](2026-10-10-골드_소지량_현행사양.md).
- 구매·배치 상한 없음(캐릭터·마차·시설 모두).
- 무역품: 품목당 1행 + "남은 수량 n", 0이면 "품절" 행 유지.
- 마구간: 재고 1대 = 1행(종류 이름), 산 행은 사라짐. 빈 목록 "판매 품목 없음".

## 마차·시설 개체

- 테이블 행 = 종류. 보유 개체 Id = `{종류 Id}#{n}`(종류별 증가, 재사용 없음). 시작 보유: 종류별 첫 행 1대.
- 표시 이름 `{n}번 {종류 이름}` — n = 같은 종류 안 보유 순서. 제거되면 당겨서 다시 매김. 적용: 마구간 보유 목록, 상단 물류품 섹션 이름, 정비창 정보 패널.
- 정비창 팔레트는 여전히 "마차"/"시설" 한 줄(종류 선택 불가 — 후속 과제).

## 캐릭터

- 같은 캐릭터는 월드에 하나. 고용 중이면 모든 마을 후보에서 제외(후보는 모든 마을에 표시).
- 사망: 상행 중 회색(배치 불가) → 상행 종료(정상 도착·궤주 귀환) 시 배치 칸 비움 + 상단 제거 + 사망 기록 → 월드에서 재고용 불가.
- 해고 기능 없음. 디폴트 캐릭터 생성 절차는 향후 기획.
