## 1. 카테고리와 저장 방식

| 카테고리(팝업 제목) | 그리드 | 회전(Q) | 임시 보관 |
|---|---|---|---|
| 교역품/전리품(상단 물류품) | **보유 마차마다 슬롯 1개**, 모양 = `Wagon.xlsx` `CargoShape` | O | O(모든 마차 공용) |
| 장비(전투 장비) | 6 × 4 | X | X |
| 전투 소모품 | 5 × 4 | X | X |
| 상단주 개인 물품 | 3 × 3 | X | X |

- 모든 인벤토리는 가로×세로 좌표 그리드. 아이템은 크기만큼 칸을 점유한다.
- 장비·소모품·개인 물품 크기는 잠정치(밸런싱 재검토 대상).

## 2. 상단 물류품 — 마차별 적재

| 항목 | 현행 |
|---|---|
| 적재 모양 | `CargoShape` 마스크: `/` 줄 구분, `1` = 적재 가능, `0` = 막힌 칸. 기본 전 행 5 × 4 전부 1. 형식 오류는 임포트 오류 |
| 대상 마차 | 보유한 모든 마차(정비창 배치 여부 무관). 보유 순서대로. 마구간에서 사면 빈 슬롯 추가 |
| 막힌 칸 | 그리지 않는다. 놓을 수 없다 |
| 마차 전환 | 슬롯 좌우 스테퍼(`<` / `>`), 끝에서 순환. 슬롯 위 `마차이름 (n/N)` |
| 마차 간 이동 | 아이템을 끈 채 스테퍼 위에 0.5초 머물면 전환(계속 머물면 반복), 그 마차에 놓는다. 실패하면 원래 마차·원래 칸 |
| 골드 상자 | 1 × 1, 골드 500. 저장소에서는 일반 아이템(놓기·제거·재배치 모두 지갑 무관). 변환·인출은 골드 보유 서비스 담당 → [골드 소지량 현행 사양](2026-10-10-골드_소지량_현행사양.md) |

## 3. 조작 (팝업·구매 화면 공통)

| 조작 | 현행 |
|---|---|
| 드래그 | 누른 채 끌어서 놓기. 잡은 칸 중심이 포인터를 따라온다 |
| 드롭 | 빈 칸 = 이동 / 아이템 1개와 겹침 = 교환(밀려난 아이템은 드래그 아이템의 원래 마차·칸, 원래가 임시 보관이면 임시 보관) / 2개 이상과 겹침·범위 밖·막힌 칸·그 밖 = 원위치 |
| 미리보기 | 드래그 중 놓일 칸을 이동(초록)·교환(노랑)·불가(빨강)으로 표시 |
| 회전 | 드래그 중 Q = 시계방향 90°, 잡은 칸 기준. 드롭 후 유지. 입력은 InputManager `Inventory/RotateHeldItem` 구독(설계 99), 텍스트 입력 중 무시 |
| 버리기 | 쓰레기통(버튼 "버림")에 드롭 → 경고 → 확인 시 버림 / 취소 원위치. 쓰레기통 클릭 → 선택 상태(아이템 클릭으로 다중 토글, 빨간 표시, 마차 전환해도 유지) → 확인 → 경고 → 확인 시 버림 / 취소 시 선택 유지. 선택 중 드래그·Q·정렬 막힘. 임시 보관도 대상. 환급 없음, 상단 물류품은 경고에 사라지는 골드 상자 줄 추가(설계 102) 실패 문구(경고 중 아이템이 사라진 경우): 선택 버리기 "버리지 못했습니다. 다시 선택하세요." / 드롭 버리기 "아이템이 이미 사라져 버리지 못했습니다."(다음 조작에서 지움, 2026-10-26) |
| 상시 호출 키 | I/B/C/P = 상단 물류품/전투 장비/소모품/개인 물품 팝업 토글(설계 99). 버튼 오른쪽 열에 키 글자 표시, 버튼을 누를 수 없는 상태(모달·시설 화면)에서는 무시 |
| 자동 정렬 | **현재 마차 + 임시 보관**을 현재 마차 안에서 큰 것부터 좌상단, 안 되면 회전. 다 못 넣으면 취소. 다른 마차는 그대로 |
| 선택·정보 | 클릭(또는 드래그 시작)한 아이템 이름만 표시(설명 문구 없음). 빈 곳 클릭 = 해제 |
| 닫기(임시 보관 있음) | 현재 마차부터 모든 마차의 빈자리에 자동 배치. 전부 못 넣으면 닫지 않고 안내 |
| "상행 시작" | 임시 보관에 아이템이 있으면 비활성 |

## 4. 화면

| 항목 | 현행 |
|---|---|
| 상단 물류품 팝업·무역품 구매 패널 | 좌측: 마차 표기 + 스테퍼 + 슬롯, 하단: 임시 보관(가로 목록, 가로 스크롤), 우측: 아이템 정보(세로) + 자동 정렬 |
| 나머지 팝업 3종 | 그리드 + 하단 자동 정렬·정보 줄(기존 배치) |
| 호출 | 마을 우상단 버튼(카테고리별 별개 팝업, 동시에 여러 개 열기 가능). 팝업 안 어디든 누르면 맨 앞으로 |
| 창 이동 | 제목 줄 드래그, 화면 밖으로 못 나감, 실행 중 위치 유지 |
| 품목 표시 | 아이콘 미정 — 품목별 색 사각형 + 이름 |
| 생성 위치 | 마을(Hub)에서만. 상행 중(Field)에는 인벤토리 팝업이 없다 |

## 5. 아이템 데이터

| 항목 | 현행 |
|---|---|
| 테이블 | 공용(데이터·세부 데이터·스트링) + 카테고리별(데이터·세부 데이터·스트링) 6종 체계. 모든 열 값 필수(IconPath만 빈칸 허용) |
| Id | 문자열 슬러그 |
| 가격 | 공용 데이터 `Price`. 마을별 차등은 세부 데이터 시트만 있고 로직 미사용 |
| 교역품 구분 | 일반 품목(무역품 구매) / 특산품(특산물 구매) |
| 기타 카테고리 | 골드 상자(판매 대상 아님, 교역품 그리드에 놓임) |
| 검증용 | `placeholder-1x1/2x1/1x2/2x2` 행과 첫 마차 초기 배치(실제 획득 시스템이 생기면 제거) |

## 6. 무역품 구매

| 항목 | 현행 |
|---|---|
| 흐름 | 목록에서 선택 → 구매 버튼 → 빈자리에 자동 배치(1개 단위, 확인 창 없음) |
| 자리 찾기 | **보이는 마차부터**, 없으면 다음 마차 순서. 인출될 골드 상자 자리는 빈 칸으로 보고, 자리가 없으면 걸리는 물품만 1단계 재배치(골드 소지량 현행 사양 §3). 다른 마차에 들어가면 그 마차 화면으로 전환. 임시 보관은 받지 않음 |
| 구매 불가 | 소유 골드(개인 + 적재) 부족(먼저 표시) / 재배치로도 자리 없음 → 버튼 비활성 + 사유(버튼 툴팁 — 호버·0.3초 누름, 2026-10-26 리팩토링 D-1). 개인 골드가 부족하면 골드 상자 자동 인출 |
| 화면 | 열려 있는 동안 재화 패널 외 UI 숨김. 나갈 때 임시 보관 규칙은 팝업 닫기와 같음 |

## 7. 미정·후속

- 마차 판매·손실 시 적재물 처리. (재화 상한과 적재 공간의 관계는 기획 82로 확정 → 골드 소지량 현행 사양)
- 마차 종류별 적재 모양 차등(현재 전 행 같은 값).
- 나머지 팝업 3종 배치 통일 여부, 팝업 간 이동, 스택·조합, 아이템 설명·아이콘.
- 시설 연계 진입점(대장간·잡화 상점·숙소 등), 상시 호출 키 바인딩.
