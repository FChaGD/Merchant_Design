# 씬 전용 코드 리팩토링 제작 계획 — 2026-10-26

> 실행: 사용자 지시로 이 세션에서 직접 연속 진행(native). 커밋은 사용자 지시가 있을 때만 — 각 태스크는 "검증 완료"까지.

**Goal:** `2026-10-26_씬전용.md` §3 수정안 A~I와 §4.3 적용 조건 ①~⑨를 코드에 반영한다.

**Architecture:** 전투 뷰는 풀+대칭 바인딩, Field·Hub의 도메인 흐름(상행 생명주기·출발 절차)은 순수 C#으로 분리, Hub 시설 화면은 바인딩 단위로 쪼개고, 대화 계약은 말풍선·스탠딩/선택지로 분리, 인스톨러는 공용 유틸·전용 디버그 인스톨러로 나눈다.

**Tech Stack:** Unity 6000.3, C#, NUnit EditMode, Unity CLI(`tools/ut.sh`, 인스톨러 메뉴·씬 저장·Play 실측).

**Spec:** `Docs/Refactor/2026-10-26_씬전용.md` §2~§4

## Global Constraints

- 네임스페이스 `Game.Core`(에디터 `Game.Core.Editor`), 요약 주석은 한국어로 "왜"를 우선, 근거 문서 번호를 적는다(`Docs/Refactor/2026-10-26_씬전용.md` 항목 번호).
- 화면 문구는 현행 그대로. 새 문구 없음(조사 함수 결과 제외).
- `.unity`/`.prefab` 직접 편집 금지 — 인스톨러 재실행(CLI) 후 저장. 실행 전 `editor_status` playMode=stopped 확인.
- 각 태스크 끝: `tools/ut.sh ALL` 전부 통과(시작 799). 씬 영향 태스크는 인스톨러 재실행·저장 + 해시 비교 또는 Play 실측.
- 패널 `Close()`는 표시/숨김만, 네비게이션은 `IPanelNavigator.Close` 위임 — 기존 규칙 유지.

## Review Focus

1. **풀 재사용 뷰의 잔여 상태**: 사망(빨간 틴트·1.1배·알파 0)한 뷰가 다음 전투에서 재사용될 때 색·크기·알파·게이지가 정상이어야 한다 — Task 1 `CharacterView_Rebind_AfterDeath_RestoresVisuals`(Play 실측: 전투 2회 연속).
2. **반환 뒤 늦은 이벤트**: 반환된 뷰에 이전 유닛의 피격·사망 이벤트가 와도 반응하지 않아야 한다 — Task 1 `Unbind_StopsReactingToUnitEvents`.
3. **배틀 테스트 배치 취소·적 구성 적용**: 직접 파괴 대신 반환 경로로 가도 남은 유닛·클릭 대상이 정확해야 한다 — Task 1 Play 실측(배치 → 취소 → 시작).
4. **숨김+입력 차단 겹침**: 같은 레이어에 숨김·입력 차단이 함께 걸리면 숨김, 숨김만 풀리면 입력 차단 상태가 남아야 한다 — Task 5 `LayerHideGate_HideWinsOverBlock`·`LayerHideGate_HideReleased_BlockRemains`.
5. **조사 경계**: 받침 없는 한글·받침 있는 한글·숫자 끝·영문 끝 — Task 9 `KoreanParticle_*`.
