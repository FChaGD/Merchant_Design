## Global Constraints

- 네임스페이스는 전부 `Game.Core`(에디터는 `Game.Core.Editor`) 유지 — 파일 이동은 폴더만 바꾼다.
- `.unity`/`.prefab` 직접 편집 금지. 씬 변경은 인스톨러 재실행(CLI: `open_scene` → `menu` → `save_scene`)으로. 실행 전 `editor_status`의 `playMode`가 `stopped`인지 확인.
- 에셋(스크립트 포함) 이동·이름 변경은 `AssetDatabase.MoveAsset`/`RenameAsset`(CLI `eval`)로 — `.meta`/GUID 유지.
- DI 계약을 나누면 `RegisterSelf`에서 **계약 타입마다 명시 등록**(미등록 타입 `TryResolve`는 조용히 null).
- 새 Bootstrap 상주 저장소 이름은 `XxxManager`(이번 계획에는 해당 없음).
- 주석은 한국어, "왜"를 우선. 화면 문구는 현행 문구 그대로(신규 문구: 드롭 버리기 실패 "아이템이 이미 사라져 버리지 못했습니다.").
- 패널 `Close()`는 표시/숨김만, 네비게이션은 `UIManager.Close(PanelId)` 위임 — 기존 규칙 유지.
- 커밋은 사용자 지시가 있을 때만(각 태스크 끝은 "검증 완료"까지).
- 각 태스크 끝 검증: `ut.sh ALL` 전부 통과. 씬 영향 태스크는 해당 인스톨러 재실행·저장 + Play 실측(1280×720 Game 뷰, 겹침 점검 포함).
