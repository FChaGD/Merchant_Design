# UI 공통 코드 리팩토링 점검 — 2026-10-26

절차: `Docs/Refactor/2026-08-26-리팩토링_점검_컨벤션.md` §0(공통 코드 선점검). 브랜치 `ui`(기준 커밋 `f9e24b2`).
계기: 마을 UI(시설 화면 4종·인벤토리 팝업·재화 HUD 등)가 일단락돼 "하드코딩 후 리팩토링" 방침(2026-09-27)의 정리 시점이 됨.

## 0. 범위·포함 항목 (사용자 결정 2026-10-26)

- 범위: **UI 전체** — `Core/UI` 전체 + UI 인스톨러(`Editor/`) + UIManager 하위 컴포넌트. 전투 도메인·데이터 저장소는 UI가 소비하는 지점만 본다.
- 포함 보류 항목:
  1. UI 관리 축(depth 축·팝업 축) 정리 + Field 씬 적용 (`ui.md` §1-9, 설계 38)
  2. 시설 화면을 모달 팝업 채널에서 분리 — 시설 화면은 "개별 화면 depth"(기획 94 §3, 설계 103 §8)
  3. 다른 비활성 버튼(시설 구매 등) 사유 문구의 공용 툴팁 이관(기획 97 §5) — 화면 동작이 바뀌므로 수정안 단계에서 기획 확인 필요
  4. 2026-10-26 검진 참고 항목(조립 보조 메서드 잔여 중복, 버리기 실패 문구 잔류, 매각 확인 문구 조사 고정, 숙소→휴식 진행 구체 의존)
- 배틀 테스트 UI(`Core/UI/BattleTest/`, `Editor/Debug/BattleTestSceneInstaller`)도 포함(사용자 지시 2026-10-26) — 씬 전용 점검 대상(`2026-10-26_BattleTest.md`).

- E-1·E-4는 S-1(시설 화면 채널 분리)과 같은 축이다. SOLID 우선 원칙대로 S-1의 채널 구조를 먼저 정하고, E-1(종류 추가 방식)·E-4(시설 화면 틀)는 그 구조에 맞춰 정한다.
- E-2는 화면 동작(사유를 문구로 보일지 툴팁으로 보일지)이 바뀌므로 수정안 단계에서 기획 확인이 필요하다.
- E-5는 최적화(O-*)와 무관. 공용 목록 부품으로 뽑을 때 기존 get-or-create 재사용 규칙을 그대로 지킨다.
- 최적화·SOLID 목록과 충돌하는 항목 없음.

### 4.2 적용 조건 (제작 시 지킬 것)

① A-1: 컨테이너 3개는 칸 컨테이너와 같은 영역(전체 덮기, 오프셋 0)이어야 칸 좌표 계산이 그대로 맞는다. 컨테이너에는 Graphic을 붙이지 않는다(칸 드롭·고스트 드래그 레이캐스트 유지). Hub·Field·BattleTest 정비창 인스톨러(`FormationUIBuilder`) 재실행 필요.
② B-1: 시설 화면 루트를 새 `Screens` 레이어로 옮길 때 모달 묶음보다 앞 형제(아래에 그려짐)로 둔다. 골드 변환 모달 루트는 화면 전체를 덮는 반투명 막(`raycastTarget=true`)이 있어 뒤의 시설 화면 클릭이 막힌다 — 확인됨.
③ B-1: 시설 화면 채널도 닫기 직전 확인(`IPanelCloseGuard`)과 씬 로드 시 초기화(`Reset`)를 기존 채널과 똑같이 거친다(라우터가 채널을 같은 방식으로 다룸).
④ B-3: Field의 이벤트·대화 조율자 2곳(`EventEncounterCoordinator`·`TripDialogueCoordinator`)과 배틀 테스트가 DI로 `IUIManager`를 조회한다. 분리한 계약으로 바꿀 경우 **각 계약 타입을 `RegisterSelf`에서 명시 등록**한다 — 등록하지 않은 계약은 `TryResolve`가 조용히 null을 돌려준다(DI 읽기 타입 미등록 사례).
⑤ B-4: Field 이동 뷰의 배경은 자기 CanvasGroup의 `ignoreParentGroups`로 가림에서 빠지는 현행 구성을 유지한다. 게이트는 오브젝트를 끄지 않는다(게이지·알림 구독·코루틴 유지).
⑥ C-1: 이동 대상에 MonoBehaviour·ScriptableObject(편성·활동·현재 위치 저장소, 도착지 배정기, 여정·도로 난이도 상태, 지도 자산 등)가 있다. 에디터가 열려 있으므로 파일 시스템이 아니라 `AssetDatabase.MoveAsset`(CLI)으로 옮겨 `.meta`·GUID를 유지한다. 코드 안 스크립트 경로 문자열 참조는 없음(확인).
⑦ D-1: 사유 문구 줄을 지운 자리의 배치를 다시 잡고(정보 패널·마구간 개체 정보), 툴팁 표시 상태를 포함해 Play 실측 겹침 점검을 한다. 시설 화면은 Hub 로드마다 새로 만들어지므로 툴팁 핸들은 패널 Dispose에서 해제한다.
