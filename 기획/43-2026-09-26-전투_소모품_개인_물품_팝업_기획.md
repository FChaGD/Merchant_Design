## 1. 배경

인벤토리 버튼 4개 중 남은 2개("소모품", "개인 물품")에 팝업이 없다. 두 카테고리 모두 1×1 고정이라 전투 장비 팝업과 조건이 같다. 이번 문서는 두 팝업을 한 번에 정한다.

## 2. 범위

- 전투 소모품 / 상단주 개인 물품 보관 팝업의 표시 요소와 조작.
- 검증용 Placeholder 아이템.
- 범위 밖: **아이템 사용**(소모품 사용, 개인 버프 사용 — 효과 종류·사용 시점 기획 없음), 개인 물품 하위 분류(전용 장비/스토리/버프, 기획 25번 §6 미정), 시설 연계 진입점(잡화 상점/숙소), 버리기, 팝업 간 이동, 상시 호출 키.

## 3. 확정 사항 (사용자 스펙, 2026-09-26)

### 3.1 기능 구성 — 두 팝업 모두 전투 장비와 동일

| 기능 | 채택 |
|---|---|
| 드래그 이동·교환(1×1이라 교환 항상 성공) | O |
| 자동 정렬 | O |
| 아이템 정보 표시(클릭 시 이름) | O |
| 창 드래그(제목 줄, 화면 경계 제한, 실행 중 위치 유지) | O |
| 품목별 색 | O |
| 회전 | X |
| 임시 보관(닫기 차단, 상행 시작 조건 포함) | X |

### 3.2 창 제목 — 기획 문서의 정식 명칭

| 팝업 | 호출 버튼 라벨 | 창 제목 |
|---|---|---|
| 전투 소모품 | 소모품 | **전투 소모품** |
| 상단주 개인 물품 | 개인 물품 | **상단주 개인 물품** |

- 버튼은 작은 크기라 짧은 라벨을 유지하고, 창 제목은 정식 명칭을 쓴다(사용자 확정). 기존 두 팝업(상단 물류품/전투 장비)은 버튼 라벨과 제목이 같아 변경 없음.

### 3.3 아이템 사용
이번 범위에서 제외 — 보관 팝업만 만든다.

## 4. 추천안 → 확정 (사용자, 2026-09-26)

### 4.1 기본 창 위치·크기
네 팝업을 모두 열었을 때 완전히 겹치지 않도록 상단 물류품 → 전투 장비 → 전투 소모품 → 개인 물품 순으로 오른쪽·아래로 조금씩 어긋나게(계단식) 둔다. 그리드 크기에 맞춰 작아진다.

| 팝업 | 그리드 | 추천 위치(화면 비율, 잠정) |
|---|---|---|
| 상단 물류품 | 10×4 + 임시 보관 | (0.02, 0.16)~(0.55, 0.80) — 기존 |
| 전투 장비 | 6×4 | (0.06, 0.10)~(0.42, 0.72) — 기존 |
| 전투 소모품 | 5×4 | (0.10, 0.06)~(0.42, 0.66) |
| 상단주 개인 물품 | 3×3 | (0.14, 0.04)~(0.36, 0.56) |

실전 확인 후 조정하는 것을 추천(전투 장비와 같은 방식).

### 4.2 Placeholder 아이템
- 앞선 두 팝업과 같은 방식: 실제 테이블에 행을 추가하고 저장소가 시작 시 흩어서 초기 배치.
- `Consumable.xlsx`: `placeholder-consumable-1`~`4`, 표시명 "Placeholder 소모품 1"~"4". 초기 위치(5×4): (0,0), (2,1), (4,3), (1,3).
- `PersonalItem.xlsx`: `placeholder-personal-1`~`4`, 표시명 "Placeholder 개인 물품 1"~"4". 초기 위치(3×3): (0,0), (2,0), (1,1), (2,2).

## 5. 설계 단계로 넘길 기술 과제

- `InventoryPopupSpecs`에 두 스펙 추가, 두 저장소 마커 인터페이스에 `IInventoryArrangement` 추가·구현, `HubUIWiring` 소스 목록과 인스톨러에 한 줄씩 추가(설계 42번 §4 확장 경로 그대로).
- Placeholder 저장소 4종의 초기 배치·정리 조작 위임 코드가 거의 같아진다 — 공용화 여부(설계 42번 §5.2는 "실제 시스템 대체 시 함께 제거"를 이유로 공용화하지 않음) 재검토.

## 6. 남은 미정 사항 (후속)

- 아이템 사용(소모품의 전투 중 사용, 개인 버프 사용) 규칙·효과.
- 개인 물품 하위 분류(전용 장비/스토리/버프) 필요 여부.
- 시설 연계 진입점(잡화 상점 → 전투 소모품, 숙소 → 개인 물품).
