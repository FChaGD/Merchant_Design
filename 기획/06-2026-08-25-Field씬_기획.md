## 1. 배경

[[01-2026-08-25-게임개요_핵심루프]]의 핵심 루프 2~7단계(상행 개시 → 인카운터 → 전투 → 결과 반영 → 반복 → 상행 종료)가 진행되는 씬. 상행 준비 UI([[02-2026-08-23-상행준비UI]])에서 "상행 시작"을 누르면 Field 씬으로 전환된다.

전투 로직(`BattleManager`)과 인카운터 판정(`EncounterManager`)은 아직 하위 컴포넌트가 설계되지 않은 스켈레톤 상태다. 이번 기획은 그 로직이 완성되기 전, Field 씬의 **화면 구조와 전환 흐름**을 먼저 확정하는 데 목적이 있다.

---

## 2. 화면 구성 — 이동 뷰

| 요소 | 내용 |
|---|---|
| 진행 게이지바 | 화면 상단, 출발지~목적지 진행률 표시 |
| 배경(상행 풍경) | 상행 진행 중임을 시각적으로 전달 |
| 정비창(Formation) 재호출 버튼 | 이동 뷰 위 오버레이 패널로 정비창을 띄움. 상행 중 언제든 호출 가능 |
| 방향성 지시(Tactics) 재호출 버튼 | 이동 뷰 위 오버레이 패널로 방향성 지시 UI를 띄움. 상행 중 언제든 호출 가능 (UI 자체는 미구현) |
| 파티 상태 패널 | 마차/용병 상태 요약 표시 영역 (테스트 단계에서는 표시 항목 없음) |

- 오버레이 패널(정비창/방향성 지시)이 열려 있어도 진행 게이지는 멈추지 않고 계속 흐른다.
- 오버레이 패널이 열린 상태에서 인카운터가 발생하면, 저장되지 않은 변경 내용은 즉시 취소되고 패널이 강제로 닫힌다.

## 3. 인카운터 발생 → 전투 전환 흐름

```
1. 인카운터 판정 성립 (EncounterManager)
2. 진행 게이지 즉시 정지
   ├─ 오버레이 패널(정비창/방향성 지시)이 열려 있으면: 미저장 변경 취소 + 패널 강제 종료
3. 화면 중앙에 깜빡이는 인카운터 경고창 표시
4. 2초 경과
5. 이동 뷰(배경 + UI 전체) 좌측으로 슬라이드 아웃
   동시에 검은 로딩화면이 우측에서 슬라이드 인
   → 이 구간에서 전투 세팅/초기화 처리 (세부 로직은 BattleManager 설계 단계에서 결정)
6. 검은 화면 페이드아웃 → 전투 뷰 노출, 전투 진행 (BattleManager.StartBattle)
```

전투 전환은 별도 씬(Scene) 전환이 아니라 **Field 씬 내부에서 카메라를 전투 뷰 영역으로 이동**시키는 방식으로 구현한다. `ContentSceneId`에 전투용 항목을 추가하지 않는다.

## 4. 전투 결과 처리 (Placeholder)

실제 전투 로직이 아직 없으므로, 전투 뷰 진입 1초 후 아래 규칙으로 임시 판정한다.

- **70% 확률 승리 / 30% 확률 패배**
- 이 판정 로직은 프로젝트 `CLAUDE.md`의 `Placeholder` 컨벤션에 따라 구현한다 — 실제 전투 시스템(`BattleManager`의 하위 컴포넌트)이 완성되면 이 판정 로직을 통째로 교체/제거한다.

### 4.1 승리 시 (전투 뷰 → 이동 뷰 복귀)

> **갱신(2026-08-25)**: 아래 "이동 뷰 즉시 재표시(비대칭)" 방침은 실플레이 피드백에 따라 폐기됐다.
> 복귀도 진입과 대칭으로 슬라이드 애니메이션을 사용한다 - 카메라가 왼쪽으로 이동하며 전투 뷰가
> 오른쪽으로 밀려나고 이동 뷰가 왼쪽에서 들어온다(Docs/제작/02-2026-08-25-인카운터_전투전환_구현.md 참고).

```
결과 팝업(승리) 노출 → 유저 확인
→ 전투 뷰 우측으로 슬라이드 아웃 + 이동 뷰 좌측에서 슬라이드 인 (동시 진행, 진입 전환과 대칭)
→ 진행 게이지 재개
```

### 4.2 패배 시

```
게임오버 팝업 노출 ("플레이 종료" 버튼 배치)
```

테스트 단계 임시 처리다. 궤주/포로/사망/도주 판정([[01-2026-08-25-게임개요_핵심루프]] 6절 "남은 미정 사항")과 용병 손실 반영 등 정식 게임오버 플로우는 후속 기획 대상이며, 지금은 단순 종료로만 처리한다.

---

## 5. 상행 종료 (도착 성공)

진행 게이지가 100%에 도달하면 도착 성공 팝업을 노출한다. 팝업에는 "도시 입장" 버튼을 배치하며, 클릭 시 Hub 씬으로 전환한다.

---

## 6. 테스트 단계 vs 정식 계획 요약

| 항목 | 테스트 단계 결정 | 정식 계획 (기록만, 지금 구현 안 함) |
|---|---|---|
| 진행 게이지 기준 | 시간 기반으로 즉시 진행 | 거리 + 여러 변수(지형/속도 등)를 조합해 소요 시간을 산출 |
| 배경 풍경 | 고정 이미지 1장 | 애니메이션 배경 |
| 파티 상태 패널 표시 항목 | 없음 | 후속 기획에서 정의 |
| 결과 팝업 정보 | 승리/패배만 표기 | 보상/피해, 궤주·포로·사망·도주 판정 등 상세 정보 |
| 패배 처리 | 게임오버 팝업 + 플레이 종료 버튼 | 용병 손실 반영 등 정식 게임오버 플로우 |
| 전투 결과 판정 | 1초 후 70%/30% 확률 Placeholder | `BattleManager` 하위 컴포넌트 완성 후 실제 전투 로직으로 교체 |

## 7. 남은 미정 사항 (후속 기획 세션 대상)

- 인카운터 경고창이 랜덤/확정 인카운터를 시각적으로 구분해서 보여줄지 여부
- 도착 성공/실패 시 상행 결과가 상단 성장(재화/평판 등, [[01-2026-08-25-게임개요_핵심루프]] 4절)에 반영되는 구체 규칙 — 재화/평판 각각의 용도·저장/척도 방식은 [[23-2026-09-08-플레이어_자원_정의_기획_재화평판]]에서 확정(2026-09-08). 상행 결과 정산 시 정확한 증감 공식은 여전히 미정
- 방향성 지시(Tactics) UI 자체의 화면 구성 (이번 문서는 재호출 진입점만 정의)
- 파티 상태 패널의 정식 표시 항목과 데이터 소스
- 인카운터 발생 시 정비창/방향성 지시 오버레이가 닫히는 연출(즉시 사라짐 vs 페이드 등) 세부
