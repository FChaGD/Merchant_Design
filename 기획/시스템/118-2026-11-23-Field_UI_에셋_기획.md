# Field UI 에셋 기획

작성일: 2026-11-23
상태: 확정 (2026-11-23)
참고: [117 기초 아이콘·UI 에셋](117-2026-11-23-기초_아이콘_UI_에셋_기획.md)(스타일 기준 시안 E·저장 규격·퀄리티 기준·작업 플로우 공용)

---

## 1. 목적

Field 씬(상행 이동·전투·결과 정리·이벤트)에서 쓰는 UI의 자리표시자 그래픽(단색 사각형·기본 도형·Unity 기본 스프라이트)을 AI 생성 에셋으로 바꾼다. 스타일·저장 규격·작업 플로우(기획 확정 → 생성 → 퀄리티 판단 → 적용 → 인게임 판단)는 기획 117을 그대로 따른다.

## 2. 전수조사 방법

- Field.unity의 UI 그래픽 전부(Image·TMP 216개, 비활성 템플릿 포함)를 에디터에서 조회(2026-11-23).
- 런타임에 만들어지는 그래픽은 코드로 확인: 정비창 프리팹 6종(`Prefabs/UI/Formation/`), 전투 월드 프리팹 3종(`Prefabs/UI/Battle/`), 런타임 생성 스프라이트(`BattlePlaceholderSprite`·`BattleGaugeSprite`), 유닛 아이콘(`Sprites/Formation/` 도형 5종).
- 글자(TMP 84개)는 에셋 대상이 아니므로 목록에서 뺐다. 글자색은 적용 단계에서 바탕에 맞춘다.

## 4. 제작 목록 후보

대상을 성격별로 묶었다. 범위·우선순위는 §5에서 정한다.

| 묶음 | 에셋 후보 | 비고 |
|---|---|---|
| A. 패널·바탕 | 기획 117 PanelFrame 재사용(결과 팝업·화물 회수·대화상자·설명 상자·방향성 지시 카드·정비창 정보 패널 등) | 생성 없이 적용만. 큰 패널용 별도 프레임이 필요한지는 인게임 판단 |
| B. 말풍선 | 말풍선 프레임(9-slice) + 꼬리 | 대화(이동 중)·이벤트 대화 공용 |
| C. 게이지·알림 띠 | 진행 게이지 틀·채움, 제한 시간 바, 도착 알림 띠, 전투 경고 띠 | 전투 HP 바는 E 묶음 |
| D. 입력 컨트롤 | 드롭다운 바탕·화살표·목록 바탕·체크, 토글 바탕·체크 | 방향성 지시 패널 전용 |
| E. 유닛·전투 표현 | 아군 역할 3종(전사·궁수·방패병), 마차, 시설, 적 진영 3종(약탈자·괴수·적대자) 아이콘 / 투사체 / HP 바 / 잔해 | 정비창 아이콘과 전투 몸체가 같은 스프라이트를 쓴다. 전투 화면은 위에서 내려다보는 시점(2D 탑뷰) |
| F. 정비창 칸·격자 | 배치 칸(슬롯), 전투 바닥 타일 | |
| G. 화물 아이템 | 무역품 아이템 그림 | 현재 아이템별 그림 자리 자체가 없음(색 블록) - 아이템 수만큼 생성 필요, 표시 구조 변경 동반 |
| H. 인물 | 대화·이벤트 스탠딩, 등장인물 | 캐릭터별 초상 - 콘텐츠(캐릭터 설정) 의존 |
| 유지 | 이동 화면 배경 일러스트, 어둡게 덮기, 전환 커튼, 디버그 OnGUI | 생성 대상 아님 |
