## 1. 배경 (코드 확인)

| 항목 | 현재 동작 |
|---|---|
| 지갑 | 개인 골드만 보관. 상한 = Bootstrap 인스펙터 고정값 10,000. 획득 시 상한 초과분은 잘려 손실 |
| 골드 상자 | 아이템 테이블 `gold-box`(Misc 카테고리, 1×1, 가격 500) 존재. 교역품 그리드에 들어오면 지갑에서 500 차감, 그리드에서 제거되면 500 환급 |
| 골드 상자 획득 경로 | 게임 내 없음(전투 화물 손실의 골드 상자 검증도 이 때문에 불가 — `battle.md`) |
| 골드 상자 제거·환급 | 환급 경로는 테스트에서만 호출. 게임 내 유출은 재배치(지갑 무관)·전투 후 임시 보관 버림(환급 없음)뿐 |
| HUD | Hub 우상단. 개인 골드만 표시, 호버 시 "상한 n" 툴팁 |
| 상행 출발 판정 | ① 대열 끊김·임시 보관 잔여·도착지 미지정 → 출발 버튼 비활성(금지) ② 배치 유닛 0 → 확인 경고창(경고) |

## 2. 범위

- 포함: 골드 소지량 계산(소유 골드 / 소지 가능 골드량), 골드 상자 Placeholder 재사용, 개인 골드 → 골드 상자 변환 모달(Hub), HUD 표기·초과 색·툴팁, 지출 시 적재 골드 자동 인출, 획득 상한 폐기, 출발 시 골드 초과 경고와 버림, 디버그 재화 조절의 초과 허용.
- 제외: 골드 상자 → 개인 골드 역변환("골드 상자 사용", §5), 상행 중(Field) 변환(§5), 새 골드 아이템 종류(§5), 상행 준비 UI의 골드 표기(HUD로 충분), 저장/불러오기.

## 3. 용어와 계산식

| 용어 | 정의 |
|---|---|
| 개인 골드 | 지갑에 있는 골드(아이템화하지 않은 돈) |
| 개인 소유 가능량 | **500** (인스펙터 값) |
| 적재 골드 | 상단 물류품에 있는 골드 상자의 가치 합. **전체 마차 합산 + 임시 보관에 있는 상자 포함** |
| 마차 여유 공간(골드 환산) | 전체 마차의 빈 칸 수 × **골드 아이템의 칸당 최대 효율**. 현재 골드 상자(1칸=500)뿐이므로 **빈 칸당 500** |
| **소유 골드** | 개인 골드 + 적재 골드 |
| **소지 가능 골드량** | 개인 소유 가능량 + 마차 여유 공간(골드 환산) + 적재 골드 |
| 버려질 골드 | max(0, 개인 골드 − 개인 소유 가능량) |

- 임시 보관 상자는 칸을 점유하지 않지만 적재 골드에 들어간다. 임시 보관에 아이템이 있으면 출발이 금지되므로(§1) 출발 시점 계산에는 영향이 없고, 마을에서 상자를 잠시 칸 밖으로 옮겨도 소유 골드 표시가 줄지 않게 하기 위함이다. 전투 후 임시 보관에서 버려지면 소유 골드에서도 빠진다.
- "소유 골드 > 소지 가능 골드량"이면 "개인 골드 > 개인 소유 가능량"이 항상 성립한다. 따라서 출발 경고 조건은 후자 하나로 판정한다(§4 E).

## 4. 확정 사항 (2026-10-09)

### A. 수치

| # | 항목 | 결정 |
|---|---|---|
| A1 | 개인 소유 가능량 | 500 |
| A2 | 여유 공간 환산 | 골드 아이템의 **칸당 최대 효율값** × 빈 칸 수. 현재 500/칸. 골드 아이템 종류가 늘면 최대 효율값을 다시 계산하도록 확장(§5) |
| A3 | 집계 범위 | 전체 마차 합산(배치 여부 무관) |
| A4 | 시작 골드 | 개인 소유 가능량과 분리해 별도 인스펙터 값으로 둔다. 검증용 10,000 유지(시작 직후 초과 상태 → 변환·경고 즉시 확인 가능) |

### B. 골드 아이템

| # | 항목 | 결정 |
|---|---|---|
| B1 | 골드 아이템 | 기존 `gold-box`(1×1, 500 고정)를 Placeholder로 사용 |
| B2 | 변환 진입 | HUD 골드 표시 패널을 **짧게 클릭**하면 변환 모달 열림 |
| B3 | 변환 수량 | **상하 스테퍼**로 골드 상자 개수 지정 + **"초과분 전부"** 버튼. "초과분 전부" = ⌈(개인 골드 − 개인 소유 가능량) / 500⌉, 단 ⌊개인 골드 / 500⌋과 빈 칸 수를 넘지 않음. 스테퍼 상한도 같은 두 값으로 제한 |
| B4 | 적재 위치 | 빈 칸 **자동 배치**(무역품 구매의 자동 배치 재사용). 마차 순서는 상단 보유 목록 순서 |
| B5 | 모달 표시 정보 | 개인 골드, 개인 소유 가능량, 빈 칸 수, 변환 후 예상치(개인 골드 / 출발 시 버려질 골드) |
| B6 | 변환 가능 장소 | 마을(Hub)만. 상행 중 변환은 §5 |
| B7 | 역변환 | 그리드에서 상자를 제거할 때의 환급 동작을 **제거**한다. 상자 → 개인 골드는 "골드 상자 사용"으로 향후 구현(§5) |

### C. 지출·획득

| # | 항목 | 결정 |
|---|---|---|
| C1 | 지출 순서 | 개인 골드를 먼저 쓰고, 부족하면 **적재 골드를 자동 인출**. 부족분을 채우는 데 필요한 상자만 꺼내고 거스름돈은 개인 골드로 돌린다(예: 300 부족 → 상자 1개 인출, 200은 개인 골드) |
| C2 | 인출 순서 | **임시 보관 상자 먼저**, 그다음 **점유율(점유 칸 ÷ 사용 가능 칸)이 높은 마차**부터, 동률이면 상단 보유 목록의 **뒤쪽 마차** 먼저. 점유율은 인출 시작 시 한 번만 계산(2026-10-10 개정, 원안: 임시 보관 → 뒤쪽 마차) |
| C5 | 무역품 구매 공간 판정 | 부족분만큼 인출될 상자의 자리를 빈 칸으로 보고, 그래도 자리가 없으면 **필요한 물품만 재배치**(같은 마차 → 다른 마차, 1단계 이동)해 자리를 만든다. 불가하면 공간 부족(2026-10-10 추가, 설계 83 §5) |
| C3 | 구매 가능 판정 | 구매·고용 버튼 활성 기준을 개인 골드 → **소유 골드**로 변경 |
| C4 | 획득 상한 | **폐기**. 개인 골드는 개인 소유 가능량을 넘어 얼마든지 늘 수 있다. 출발 시 버림이 사실상의 상한 역할 |

### D. 표기 (HUD, Hub만)

| # | 항목 | 결정 |
|---|---|---|
| D1 | 기본 표기 | 소유 골드 상시 표기 |
| D2 | 툴팁 | **호버** 또는 **누르고 있기**(일정 시간, 예: 0.3초 이상) 시 표시. 문구: `최대량 n (개인 a / 적재 b / 여유 공간 c)` — n=소지 가능 골드량, a=개인 소유 가능량, b=적재 골드, c=여유 공간 환산값 |
| D3 | 누르기 구분 | 짧게 눌렀다 떼면 변환 모달(B2), 일정 시간 이상 누르면 툴팁만 표시하고 뗄 때 모달을 열지 않음 |
| D4 | 초과 색 | 소유 골드 > 소지 가능 골드량 → **빨강**. 그렇지 않지만 개인 골드 > 개인 소유 가능량 → **노랑**. 둘 다 아니면 기본색. 노랑·빨강 모두 "출발 시 버려질 골드 있음"을 뜻함 |
| D5 | 상행 준비 UI 표기 | 없음(HUD로 충분) |

### E. 출발 경고

| # | 항목 | 결정 |
|---|---|---|
| E1 | 조건 | 개인 골드 > 개인 소유 가능량 (§3) |
| E2 | 문구 | 버려질 골드 금액 표시(예: "개인 소유 가능량을 넘는 n골드가 버려집니다. 그래도 출발하시겠습니까?"). 확정 문구는 설계에서 정함 |
| E3 | 강행 | 출발 확정 시 개인 골드 = 개인 소유 가능량으로 줄이고(초과분 버림) 상행 출발 |
| E4 | 다른 경고와의 관계 | 골드 경고와 배치 유닛 0 경고는 **각각 독립 판정**. 한쪽이 뜬다고 다른 쪽을 생략하지 않는다 |
| E5 | 둘 다 해당 시 | **순차 표시**: 첫 경고 확인 → 다음 경고 → 모두 확인 시 출발. 어느 쪽이든 취소하면 출발 중단(골드도 버리지 않음) |
| E6 | 금지와 경고 분리 | 금지 조건(대열 끊김·임시 보관 잔여·도착지 미지정)은 지금처럼 **버튼 비활성**. 골드 초과는 금지가 아니라 경고 |

## 5. 향후 확장 (이번 범위 밖, 기록)

1. **골드 아이템 종류 추가**: 여유 공간 환산 계수는 "골드 아이템 중 칸당 가치가 가장 큰 값"으로 다시 계산해야 한다(A2). 변환 모달의 아이템 선택·자동 배치 규칙도 함께 확장.
2. **골드 상자 사용(역변환)**: 골드 상자를 사용해 개인 골드로 되돌리는 기능(B7).
3. **상행 중 변환**: 인카운터 보상으로 상행 중에 골드를 얻을 수 있게 할 예정. 보상 정산 정비 시간에 받은 돈을 변환해 마차에 적재할 수 있게 한다(B6). Field HUD 표시 여부도 이때 정한다(현재 Field 표시 여부 미확인).
4. **지출 인출 정책**: 자동 인출(C1·C2)은 잠정. 인출 순서 선택·수동 인출 등은 기획 확장 요소.
