## 1. 배경 — 현재 "상행 시작" 비활성 조건 (코드 조사, 2026-10-20)

상행 준비 화면의 "상행 시작" 버튼은 아래 세 조건이 모두 맞아야 활성이다. 사유가 표시되는 것은 대열 끊어짐 하나뿐이고, 그것도 버튼과 떨어진 별도 안내 문구다.

| # | 비활성 조건 | 지금 사유 표시 |
|---|---|---|
| A | 씬 전환 커튼이 아직 걷히지 않음(Hub 진입 직후 잠깐) | 없음 |
| B | 도착지를 지정하지 않음(또는 지정했다가 같은 도시를 다시 눌러 해제, 갈 수 없는 도시를 누름) | 없음 |
| C | 정비창 대열의 마차가 끊어져 있음 | 별도 안내 문구 "대열이 끊어져 있습니다. 정비창에서 마차를 이어 붙이세요." |

참고 — 비활성 조건이 아닌 것:
- 임시 보관에 물류품이 남아 있음: 2026-10-15에 **비활성 → 출발 확인 경고**로 바뀌었다(인계 문서의 "임시 보관 때문에 비활성" 기록은 이 변경 전 내용).
- 배치 유닛 없음·골드 초과: 출발을 누른 뒤 뜨는 확인 경고이며 비활성 조건이 아니다. 이번 범위 밖.

## 2. 범위

- 포함: "상행 시작" 비활성 사유 전부(A~C)를 버튼 툴팁 하나로 통합, 기존 대열 끊어짐 안내 문구 정리.
- 제외: 출발 확인 경고(유닛 0·임시 보관·골드), 다른 버튼의 비활성 사유(숙소 휴식 버튼은 94번에서 같은 방식 적용).

## 3. 확정 사항 (사용자 결정, 2026-10-20)

| 항목 | 결정 |
|---|---|
| 표시 방식 | **툴팁** |
| 통합 | 현재 제작된 모든 "상행 시작" 비활성 사유를 툴팁으로 통합 |
| 조사 범위 | 코드상 다른 비활성 조건이 더 있는지 조사해 사유 목록에 포함(§1) |

## 4. 확정 사항 (추천안 그대로 확정, 2026-10-20)

| # | 항목 | 추천 | 근거 |
|---|---|---|---|
| 4-1 | 표시 조건 | 버튼이 비활성일 때만, 버튼에 **마우스를 올리거나 일정 시간(0.3초) 누르고 있으면** 표시. 활성일 때는 툴팁 없음 | 골드 HUD 툴팁(82번 D2)과 같은 조작 |
| 4-2 | 여러 사유가 겹칠 때 | 해당하는 사유를 **전부** 한 줄씩 표시. 순서 B → C → A | 하나를 고친 뒤에야 다음 사유를 알게 되는 것을 막음. 플레이어가 고칠 수 있는 것부터 |
| 4-3 | 사유 문구 | A "화면 전환 중입니다." / B "도착지를 지정하세요." / C "대열이 끊어져 있습니다. 정비창에서 마차를 이어 붙이세요." | C는 기존 문구 그대로 |
| 4-4 | 기존 안내 문구(C) | **제거**하고 툴팁으로만 표시 | "툴팁으로 통합" 결정. 같은 사유를 두 곳에 띄우지 않음 |
| 4-5 | 툴팁 위치 | 버튼 바로 위. 실제 좌표는 설계 단계 겹침 점검으로 확정 | 버튼과 붙어 있어야 어느 버튼의 사유인지 분명 |
| 4-6 | 툴팁 모양 | 골드 HUD 툴팁과 같은 모양(배경 + 문구). 숙소 휴식 버튼(94번 4-11)도 같은 툴팁을 쓴다 | 비활성 사유 툴팁을 한 가지 모양으로 통일 |
| 4-7 | 표시 중 상태가 바뀔 때 | 툴팁이 떠 있는 동안 사유가 바뀌면 즉시 갱신, 버튼이 활성이 되면 즉시 닫음 | 도착지 지정 직후 남은 사유가 바로 보임 |

## 5. 남은 미정 사항 (후속)

- 다른 비활성 버튼(시설 구매 버튼 등 — 지금은 정보 패널의 사유 문구로 표시)을 같은 툴팁으로 옮길지 — UI 전체 리팩토링 때 검토.
