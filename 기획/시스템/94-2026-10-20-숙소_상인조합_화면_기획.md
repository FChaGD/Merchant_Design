## 1. 배경

주점 지구의 숙소와 시청 방면의 상인조합은 버튼만 있고 시설 화면이 없다. 이 문서는 두 시설의 화면 구성과 흐름을 정한다.

## 2. 범위

- 포함: 숙소 화면(휴식 설정 + 우측 인벤토리 탭), 휴식 진행 화면(게이지 depth), 상인조합 화면(퀘스트 게시판), 마구간 매각 UI.
- 제외(system 브랜치): 휴식의 회복 대상 자원과 회복량, 마을 안 시간 개념(84번 §5 "마을 행동의 시간 소모").
- 제외(후속): 휴식 중 이벤트의 내용·발생 규칙, 퀘스트 시스템 자체(목표·진행·보상), 평판 시스템, 저장/불러오기.

## 3. 확정 사항 (사용자 결정, 2026-10-20)

### 3.1 화면 성격

| 항목 | 결정 |
|---|---|
| 시설 화면의 성격 | 시설 화면은 **개별 화면 depth의 별도 화면**이다. 지금 모달 팝업 채널을 재활용하고 있을 뿐, 움직일 수 있는 UI인 모달 팝업과는 개념이 다르다 — 리팩토링 시 구분 |
| 숙소·상인조합 구성 | 기존 시설 화면(무역품 구매·용병단 접촉·마구간)과 같은 방식 |

### 3.2 숙소

| 항목 | 결정 |
|---|---|
| 휴식 흐름 | 휴식 날짜(일수)를 정해 휴식을 확정한다 |
| 휴식 진행 표현 | 게이지 바 형태로 날짜가 서서히 지나가는 것을 보여 준다 |
| 비용 | 숙소 비용은 **날짜가 지날 때마다** 청구한다 |
| 휴식 진행 화면 | 게이지가 나오면 다른 UI를 모두 감추고 **게이지 바 전용 depth 화면**을 새로 둔다. 휴식 중단, 이벤트 발생 여부 등을 이 화면에 띄운다 |
| 우측 인벤토리 | 숙소 화면 우측에 **탭 형태**로 전투 장비 / 전투 소모품 / 상단주 개인 물품을 띄운다 |

### 3.3 상인조합

| 항목 | 결정 |
|---|---|
| 기능 | **퀘스트 수락 게시판만**(2026-10-20 사용자 결정, §3.4 상단 기능 참고). 상단 현황 열람·해고·평판은 이번에 만들지 않고 향후 인터페이스 기능으로 만든다 |

### 3.4 충돌 정리 (사용자 결정, 2026-10-20 — §5 해소)

| 항목 | 결정 |
|---|---|
| 퀘스트 게시판 | **역할 분담**: 상인조합 게시판은 상단 운영 관련 퀘스트(납품 의뢰 등), 시청은 그 밖의 퀘스트 |
| 매각 | **마구간**에 둔다. 상인조합에서는 매각하지 않는다(24번 "마구간 = 마차·시설 매매" 유지). 이번 작업은 **매각 UI까지**, 실제 매각 동작은 system 브랜치 |
| 상단 기능 | 상단 운영 기능(현황·해고·평판)은 시설이 아니라 **인터페이스 기능**으로 향후 확장한다(대도시 한정 문제 해소) |
| 휴식 | **UI 기능만** 이번 작업 범위. 날짜 진행·비용 청구·회복 등 실제 동작은 system 브랜치로 이관(`system.md` 기록) |

## 5. 확인이 필요한 충돌

> **2026-10-20 해소** → §3.4. 아래는 당시 선택지 기록.

- **게시판 위치**: 24번은 "시청 = 퀘스트 전용 창구"다. 상인조합에 퀘스트 게시판을 두면 역할이 겹친다. 선택지: (A) 상인조합 게시판은 상단 운영 관련 퀘스트(예: 납품 의뢰), 시청은 그 밖의 퀘스트로 나눈다, (B) 퀘스트를 상인조합으로 옮기고 시청은 은행·행정만, (C) 상인조합 게시판 철회.
- **매각 위치**: 24번은 "마구간 = 마차·시설 매매". 상인조합 매각과 겹친다. 선택지: (A) 상인조합 매각 유지(마구간은 구매·수리만), (B) 매각은 마구간에 두고 상인조합은 해고만.
- **상인조합 접근성**: 57번에 따라 대도시에만 있어 시작 마을(촌락)에서는 들어갈 수 없다. 해고·매각이 대도시에서만 가능해진다.
- **휴식의 날짜 진행**: 84번은 "마을 행동은 시간 소모 없음"이다. 숙소 휴식이 날짜를 진행시키면 그 첫 예외가 된다. 회복·시간 개념을 system 몫으로 뺀 상태에서, 날짜 +1과 비용 청구까지 이번 ui 작업에서 실제로 동작시킬지, 게이지 연출만 만들고 날짜·비용은 system 작업 때 연결할지 결정 필요.

## 6. 남은 미정 사항 (후속)

- 휴식 회복 대상·회복량(system) — **2026-10-27 보류(사용자 결정)**: 지략·행정력 시스템이 없고 캐릭터 HP는 상행 시작·종료에 전원 회복돼 대상이 없다. 지략·행정력 배정·제작 때 함께 정한다. 진행 화면 회복 표시 자리는 빈 채로 둔다. 마을 시간 개념은 4-10 개정으로 해소(숙소 휴식만 날짜 진행).
- 휴식 중 이벤트 내용·발생 규칙.
- 퀘스트 시스템(목표·진행·보상·수락 상한), 평판 시스템.
- 상단 운영 인터페이스(현황·해고·평판) 기획. 해고된 용병이 다시 나타나는 마을(80번 §5).
- 실제 매각 동작(system), 매각 비율 밸런싱.
