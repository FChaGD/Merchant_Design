## 1. 게임 개요

- 장르: 2D 탑뷰 방치형 전략. 유저는 준비 단계에서만 개입하고, 이동·전투는 AI가 자동으로 진행한다.
- 컨셉: 중세 판타지 세계관의 상단 운영. 용병을 고용해 상행을 조직하고, 무역로를 개척한다.
- 레퍼런스: TeamFight Manager의 "준비 → AI 자동전투 → 결과" 시퀀스 구조만 참고한다. 스탯/스킬/밸런스 등 세부 규칙은 본 프로젝트에서 자체 설계한다.

## 2. 핵심 시스템 정의

플레이어의 개입 행위는 서로 다른 두 시스템으로 분리된다.

| 구분 | 정비창 (배치) | 방향성 지시 (전술) |
|---|---|---|
| 대상 | 마차, 전투 용병 | 용병(유닛) |
| 내용 | 위치 배치/재배치 | 진형·방향 지정 |
| 접근 | 상행과 독립된 별도 UI/시스템 | 정비창과도 독립된 별도 UI/시스템 |
| 변경 시점 | 상행 전 자유 설정, 상행 중에도 언제든 호출 가능 | 정비창과 동일 (상행 전 자유 설정, 상행 중 언제든 호출 가능) |
| 변경 트리거 | 지략/행정력 등 자원 소모 | 지략/행정력 등 자원 소모 |
| 변경 방식 | 마차·캐릭터가 물리적으로 재배치 위치까지 실제 이동 | 물리적 변화 없음 |
| 소요 시간의 성격 | 이동 시간 (실제 이동에 소요되는 시간) | 적응 시간 (추상적 타이머) |
| 시간 경과 중 인카운터 발생 시 | 별도 디버프 수치 없음 — 진형이 흐트러진 상태 자체가 전투에 불리하게 작용하는 자연발생적 페널티 | 명시적 전투 디버프 적용 (적응 시간 미완료 상태로 판정) |

두 시스템 모두 "자원을 소모해 변경 → 즉시 반영되지 않고 시간이 걸림"이라는 공통 규칙을 갖되, 페널티의 성격이 다르다. 정비창은 상태 기반(진형 붕괴가 곧 결과), 방향성 지시는 규칙 기반(플래그 판정에 따른 디버프)이다.

## 3. 핵심 루프 — 상행 1회 (세션 레벨)

1. **상행 준비**: 정비창에서 마차·용병 배치 구성, 방향성 지시로 진형/전술 설정
2. **상행 개시**: 출발지 → 목적지로 이동 시작
3. **인카운터 발생**: 이동 중 랜덤 또는 확정 인카운터로 전투 트리거
4. **전투 진행**: AI가 양측 유닛을 자동으로 움직여 전투 수행 (유저는 사전 설정된 배치/전술로만 개입)
5. **결과 반영**: 전투 결과에 따라 보상/피해/버프/디버프가 상행에 누적
   - 용병대 전멸/이동불가 상태가 되면 **궤주(실패·귀환) / 포로 / 사망(게임오버) / 도주(속행)** 중 확률로 판정
   - 상행 진행 중에도 정비창/방향성 지시 재설정 가능 (각각의 소요 시간 규칙 적용)
6. **반복**: 3~5단계를 목적지 도착까지 반복
7. **상행 종료**: 목적지 도착(성공) 또는 궤주 등으로 중단(실패) → 본부 복귀, 결과 정산

---

## 4. 메타 루프 — 지속 경영형 (모범리 계열)

1. 마을(허브)에서 상단 경영: 용병 고용/육성, 자원 관리, 시설 건설/업그레이드
2. 상행 기획: 목적지/경로 선택, 정비창에서 파티(마차+용병) 구성
3. 상행 실행 (3장 핵심 루프)
4. 상행 결과로 상단 성장: 재화, 평판, 신규 용병/기술 해금 등
5. 반복: 상행 실패해도 상단 전체는 초기화되지 않는다. 단, 개별 용병의 사망/포로는 영구 손실로 남을 수 있다 (반복 플레이의 리스크 요소).

## 5. 인카운터 방식

| 구분 | 랜덤 인카운터 | 확정 인카운터 |
|---|---|---|
| 발생 조건 | 상행 진행 중 주기적으로 확률 판정을 실행, 조건 충족 시 전투 발생 | 특정 시점/조건에서 반드시 발생 (스토리 진행 등 이벤트 목적) |
| 목적 | 상행의 리스크·랜덤성 요소 | 서사·이벤트 진행 장치 |

---

## 6. 전투 승패 판정 기준

| 구분 | 조건 |
|---|---|
| 승리 | 적 사기 저하로 인한 도주, 또는 적 전멸 |
| 패배 | 상행 보호 목표 파괴, 또는 아군 유닛 전멸 |

- **상행 보호 목표**는 고정 대상(마차)이 아니라 인카운터 상황별로 지정되는 가변 대상이다.
- **사기**는 도주 판정의 트리거로 작동하는 별도 수치로, 아군/적군 모두에 적용되는 시스템으로 추정된다 (상세 미정).
