## 1. 배경

상행 준비 UI의 지도는 모든 도시를 지도 한 장(2400 × 2400)에 보여 준다. 도시가 늘면 지도가 좁아진다. 월드를 **지역** 여러 곳으로 나누고, 지도는 **지역 하나만** 보여 주게 바꾼다. 도시는 지도에 불러온 지역에 속한 것만 표시한다.

## 2. 범위

- 포함: 지역 데이터, 도시의 지역 소속, 지역별 지도 표시, 지역 전환(지역 아이콘·드롭다운), 지역을 넘는 도로와 상행(도달 판정), 디버그 편집 도구의 지역 대응.
- 제외: 지역별 지도 배경 그림, 지역 간 이동에 드는 시간·위험도 차등, 지역 해금(가 보지 않은 지역 숨기기), 월드 전체 지도 화면.

## 3. 확정 사항 (사용자 결정, 2026-09-30)

### 3.1 지역과 좌표

| 항목 | 결정 |
|---|---|
| 지역 | 월드를 여러 지역으로 나눈다. 도시는 정확히 한 지역에 속한다 |
| 지도 | 한 번에 **지역 하나**의 지도만 보인다. 그 지역 도시만 표시 |
| 좌표 기준 | **지역별 지도 기준** — 지역마다 자기 지도(좌측 하단 원점)를 갖고, 도시 X·Y는 그 지역 지도 안의 위치 |
| 초기 구성 | 지금 도시 10개 전부 **지역1**. 검증용으로 **빈 지역2**를 둔다(도시 없음) |

### 3.2 지역 전환

| 방법 | 결정 |
|---|---|
| 지역 아이콘 | 지도에 도시처럼 놓인 **지역 아이콘**을 클릭하면 지도가 그 지역 지도로 바뀐다 |
| 드롭다운 | 지도 UI에 지역 선택 드롭다운도 둔다 — 아이콘이 없는(이어지지 않은) 지역으로도 바로 볼 수 있다 |
| 아이콘 위치 | **테이블에 좌표로 적어 배치**한다(도시처럼) |

### 3.3 지역을 넘는 도로·상행

| 항목 | 결정 |
|---|---|
| 상행 | **지역을 넘어 상행할 수 있다** — 다른 지역을 지도에 띄운 뒤 그 지역 도시를 도착지로 고른다 |
| 도로 연결 | **지역 아이콘이 도로의 중간 지점**이다. 도시 ↔ 지역 아이콘을 도로로 잇고, 상대 지역 지도에는 되돌아오는 지역 아이콘이 있어 두 아이콘이 한 쌍으로 이어진다 |
| 도달 판정 | 기존 규칙(기획 16 §6.1 — 현재 위치와 같은 도로망에 속하면 도달 가능)을 지역 아이콘 쌍을 거쳐 지역 너머까지 적용한다 |

### 3.4 디버그 도구

| 항목 | 결정 |
|---|---|
| 적용 대상 | **지금 지도에 띄운 지역**에 도시를 배치·이동·삭제하고 도로를 그린다 |
| 지역 아이콘 | 디버그 도구로 지역 아이콘도 놓고·옮기고·도로로 잇는다. 저장하면 엑셀에 반영(기존 저장 경로) |
| 지역 추가·삭제 | 디버그 도구로 한다(§3.6) |

### 3.5 지역 아이콘 배치 (디버그, 사용자 결정 2026-09-30)

| 항목 | 결정 |
|---|---|
| 방식 | **짝 자동 생성(B안)** — 아이콘을 놓으면 상대 지역 지도에 되돌아오는 짝 아이콘이 자동으로 생긴다 |
| 연결할 지역 선택 | 디버그 패널의 `지역 아이콘` 팔레트 항목 **옆 드롭다운**(`연결할 지역`)에서 **놓기 전에** 고른다. 지금 띄운 지역은 목록에서 빠지고, 기본값은 첫 번째 다른 지역. 지도 상단의 지역 보기 드롭다운(게임 기능)과는 별개 |
| 짝 아이콘 위치 | **상대 지역 지도 중앙**에 생긴다. 그 지역으로 가서 옮긴다 |
| 자기 지역 | 자기 지역을 가리키는 아이콘은 만들 수 없다 |
| 삭제 | 아이콘 하나를 지우면 **짝 아이콘도 함께** 지우고, 두 아이콘에 이어진 도로도 지운다 |
| 이동 | 짝과 관계없이 각자 자기 지역 안에서 이동 |
| 도로 없는 아이콘 | 허용 — 지도 전환 통로로만 쓰이고, 도로가 이어지기 전에는 지역 간 상행 경로가 되지 않는다 |
| 엑셀 직접 입력 | 임포트 때 검증 — 짝이 없거나 자기 지역을 가리키는 아이콘이 있으면 임포트 오류 |

### 3.6 지역 추가·삭제 (디버그, 사용자 결정 2026-09-30 — 추천안 그대로 확정)

| 항목 | 결정 |
|---|---|
| 위치 | 디버그 패널에 `지역 추가`·`지역 삭제` 버튼 |
| 추가 | 새 지역 Id = 기존 최대 + 1, 이름 "지역N", 지도 2400 × 2400, 도시·아이콘 없음. 추가하면 지도가 새 지역으로 바뀐다 |
| 삭제 대상 | **지금 지도에 띄운 지역** |
| 삭제 불가 | 지역이 1개뿐일 때, 현재 위치 도시가 있는 지역일 때 |
| 함께 지우는 것 | 그 지역의 도시·지역 아이콘, 다른 지역에 있는 짝 아이콘, 이것들에 이어진 도로. 도착지가 그 지역 도시였으면 도착지 해제 |
| 확인 | 도시나 아이콘이 있는 지역이면 "도시 N개·아이콘 M개가 함께 삭제됩니다" 확인을 거친다. 빈 지역은 바로 삭제 |
| 삭제 후 | 지도가 현재 위치 도시의 지역으로 바뀐다 |
| 이름 변경 | 범위 밖 — 엑셀에서 고친다 |
| 저장 | 추가·삭제도 다른 디버그 편집처럼 저장 버튼으로 엑셀에 반영 |

## 4. 세부 결정 (2026-09-30 사용자 확정 — 추천안 그대로)

| # | 항목 | 추천 | 근거 |
|---|---|---|---|
| 1 | 데이터 위치 | `City.xlsx`에 지역 시트를 더한다: 지역 목록(Id·지도 크기), 지역 이름(스트링), 지역 아이콘(놓인 지역·가리키는 지역·X·Y). `CityData`에 `RegionId` 열 추가. 도로 시트는 도시와 지역 아이콘을 모두 잇는다 | 도시 데이터와 한 워크북에서 관리(기획 57 원칙). 도로가 한 시트에 모인다 |
| 2 | 지역 지도 크기 | 모든 지역 2400 × 2400으로 시작(지역 목록에 열은 두되 같은 값) | 지금 지도·디버그 도구를 그대로 쓴다. 지역마다 다르게 할 필요가 생기면 값만 바꾼다 |
| 3 | 지역 아이콘 쌍 | 지역1의 "→지역2" 아이콘과 지역2의 "→지역1" 아이콘이 한 쌍. 두 지역 사이에 쌍을 **여러 개** 둘 수 있다(국경 관문 여러 곳) | 지도 모양에 맞춰 길을 여러 갈래로 낼 수 있다 |
| 4 | 지역 아이콘 클릭 | 지도 전환만 한다. 도착지로 고를 수 없다 | 아이콘은 장소가 아니라 길목 |
| 5 | 지도를 열 때 | **현재 위치 도시의 지역**을 띄운다. 드롭다운에 현재 지역 이름 표시 | 출발지가 늘 보이는 상태에서 시작 |
| 6 | 도착지가 다른 지역일 때 | 도착지 정보 패널에 도시 이름과 **지역 이름**을 함께 표시. 지도를 다른 지역으로 바꿔도 도착지 지정은 유지 | 지역을 오가며 확인해도 선택이 풀리지 않는다 |
| 7 | 현재 위치 표시 | 현재 위치 도시가 있는 지역을 볼 때만 표시(기존 표시 방식) | 지도에 없는 도시는 그리지 않는다 |
| 8 | 지역 아이콘 모양 | 도시 아이콘과 구분되는 모양 + 가리키는 지역 이름 표시 | 도시와 헷갈리지 않게 |
| 9 | 빈 지역 | 도시가 없어도 드롭다운·아이콘으로 볼 수 있고, 디버그 도구로 도시를 놓을 수 있다 | 빈 지역2에서 지역 간 상행을 직접 만들어 검증 |
| 10 | 상행 중(Field)·도착 | 지역을 넘는 상행도 지금과 같은 상행으로 처리(이동 규칙 변화 없음). 도착하면 현재 위치가 그 도시로 바뀌고, 다음에 지도를 열면 그 지역이 뜬다 | 이번 범위는 지도·도달 판정까지 |

## 5. 설계 단계로 넘길 기술 과제

- 도로 데이터가 도시 Id(정수) 쌍만 다룬다 — 지역 아이콘도 도로 끝점이 되도록 끝점 식별 방식 정하기(도시 Id와 겹치지 않게).
- 도달 판정: 지역 아이콘 쌍을 한 지점처럼 취급하는 그래프 구성.
- 지도 UI: 지역 전환 시 마커·도로 다시 그리기(재사용 풀), 드롭다운 조립(인스톨러), 지역 이름 표시.
- 디버그 도구·저장 경로(`TripCityMapPersistence`, 엑셀 쓰기)의 지역 대응, 지역 아이콘 드래그·도로 연결.
- 현재 위치·도착지 저장소가 지역을 알아야 하는지(도시 → 지역 조회로 충분한지).
- 마을 규모(57)·시설 배정 등 도시 데이터를 읽는 다른 소비자 영향 확인.
