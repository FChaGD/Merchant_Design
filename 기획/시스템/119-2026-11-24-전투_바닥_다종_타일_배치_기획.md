# 전투 바닥 다종 타일·노이즈 배치 기획

작성일: 2026-11-24
상태: 확정 (2026-11-24)

## 1. 목적

전투 바닥이 그림 1장(BattleFloorTile)의 반복이라 무늬가 눈에 띈다(기획 118 §8). 바닥 타일을 여러 종 만들고, 비율과 펄린 노이즈로 배치 맵을 정해 자연스러운 바닥을 만든다. 배치 맵은 씬 로딩 단계에서 미리 계산해 전투 시작 시 바로 깐다.

## 2. 현행 (코드 확인, 2026-11-24)

| 항목 | 현행 |
|---|---|
| 타일 크기 | 2m × 2m(전장 1단위 = 1m = 정비창 배치 칸 1칸 간격). 그림 256px → 1m당 128px |
| 깔리는 범위 | 적 스폰 반경을 감싸는 정사각형. 스폰 반경 = 대열 반경 + 10m라 전투마다 크기가 다름 |
| 대열 최대 크기 | 정비창 50 × 50칸 → 스폰 반경 약 45m, 한 변 약 46타일 |
| 카메라 | 가장 넓게 보는 줌 = 전장 전체가 보이는 기준 크기, 이동은 전장 경계 안으로 제한 |

## 3. 에셋 (확정)

| 분류 | 개수 | 형태 |
|---|---|---|
| 잔디 | 5종 | 잔디로 가득 찬 타일 |
| 잡초 | 3종 | 잔디 + 잡초가 간간이 난 타일 |
| 꽃 | 3종 | 잔디 + 꽃 몇 송이가 난 타일 |
| 마른 흙 | 3종 | 마른 흙 타일 |

- 합계 14종. 크기·저장 규격은 기존 BattleFloorTile과 같다(256px, `Resources/UI/Textures/`, 2m 타일).
- 퀄리티 기준: 14종 어느 두 장을 이어 붙여도 경계(이음매)가 드러나지 않아야 한다 - 바탕 잔디 색·밝기·질감 크기를 맞춘다. 마른 흙도 잔디 타일과 붙었을 때 각진 경계가 크게 튀지 않아야 한다(인게임 판단 항목).
- 스타일: 기존 BattleFloorTile(기획 118 1안)과 같은 화풍. 기존 BattleFloorTile은 잔디 5종 중 1장으로 재사용할지 생성 결과를 보고 판단한다.

## 4. 배치 규칙 (확정)

### 4.1 비율·구조
- 펄린 노이즈는 **분류**만 정한다. 분류 비율: 잔디 55%, 잡초 20%, 마른 흙 15%, 꽃 10%(잠정 - 인게임 판단 후 조정).
- 노이즈 값을 비율 누적 구간으로 나눠 분류를 정한다(같은 분류가 군집으로 뭉침).
- 같은 분류 안의 변형(잔디 5종 등)은 타일마다 균등 랜덤으로 고른다 - 같은 그림이 덩어리로 뭉치지 않게.
- 군집 크기 = 같은 분류 덩어리 하나가 걸치는 타일 칸 수(노이즈 주파수로 정함). 맵 크기와 무관한 독립 값이다 - 맵 크기는 계산할 칸 수, 군집 크기는 덩어리 하나의 칸 수다. 잠정값: 덩어리 지름 약 6타일(12m).
- 노이즈는 2겹을 섞는다: 군집 크기의 큰 노이즈 + 경계를 들쭉날쭉하게 하는 작은 노이즈(옥타브). 작은 노이즈의 크기·섞는 세기도 조정 값으로 둔다.

### 4.2 노이즈 맵 개수
- 개수 = ⌊상행 전체 시간(초) / 30⌋ + 3.
  - 상행 전체 시간 = 출발 시 확정되는 구간 계획의 총 소요시간.
  - 예: 90초 → 3 + 3 = 6장, 100초 → 3 + 3 = 6장.

### 4.3 노이즈 맵 크기
- 항상 최대 크기로 만든다 - 대열은 정비 중 뭉쳤다가 상행 중 넓게 퍼질 수 있다.
- 최대 크기 = 상단 대열이 가질 수 있는 최대 크기(50 × 50칸)일 때 카메라가 보여줄 수 있는 최대 범위를 덮는 크기. 정확한 값은 카메라 줌·이동 제한 규칙으로 설계 단계에서 산출한다.

### 4.4 전투에서 쓰는 방법
- 전투마다 아직 쓰지 않은 맵을 하나 쓴다. 전부 썼으면 그중에서 랜덤으로 다시 쓴다.
- 이번 전투에 필요한 범위(이번 대열 크기 기준 카메라가 보여줄 수 있는 범위)를 맵에서 잘라 쓴다. 잘라낼 중심은 그 범위가 맵 안에 들어가는 위치 중에서 랜덤으로 고른다.
  - 대열이 최대 크기면 필요한 범위 = 맵 전체라 맵을 그대로 쓴다.

### 4.5 계산 시점
- Field 씬 로딩 작업(설계 67 로딩바 작업 단위)에 "전투 바닥 배치 맵 계산"을 추가한다. 노이즈·분류·변형 선택까지 로딩에서 끝내고, 전투 시작 시에는 잘라낸 범위의 타일에 그림만 바꿔 낀다.

## 5. 확장성 (확정 방향)

- 바닥 세트(분류 목록·분류별 그림·비율)를 하나의 데이터로 묶는다. 이후 지역(지역 시스템, 기획 68)마다 다른 바닥 세트를 연결할 수 있게 둔다.
- 이번 범위는 세트 1개(§3)만 만들고 지역 연결은 하지 않는다.

## 6. 결정 사항 (2026-11-24)

| 항목 | 결정 |
|---|---|
| 6-1 배틀 테스트 씬 | 노이즈 배치 없이 정비창 배치 칸 그림(FormationSlot, 기획 118)을 바닥 전체에 반복한다. 가운데가 옅은 그림이라 틴트 여부는 적용 후 판단 |
| 6-2 조정 값 위치 | 분류 비율·군집 크기·작은 노이즈 값은 인스펙터에서 관리한다. 바닥 세트 데이터에 함께 묶어 두고, 향후 테이블화를 함께 검토한다 |

| 항목 | 비고 |

## 8. 작업 순서

기획 확정 → 생성(14종, 분류별 2안 시험 후 선정) → 퀄리티 판단 → 설계(배치 맵 계산·로딩 연동) → 제작·적용 → 인게임 판단.

## 9. 생성 경과 (2026-11-24, 선정 전)

- 도구: Ludo `createTile`(square, texture) - 결과가 자기 자신과 이음매 없이 반복됨을 3×3 반복으로 확인. 사용 약 27크레딧.
- 후보 원본·미리보기 보관: `ArtSource/BattleFloor/2026-11-24/`(메인 저장소 루트, 미커밋, README에 후보별 조건·판단).

| 시도 | 결과 |
|---|---|
| 큰 붓 터치 잔디(grass_r2_4)를 기준으로 변형 생성 | 변형들이 결이 잘고 옅게 나와 기준과 안 맞음. 섞으면 밝기·결 차이로 사각 경계가 드러남 → 기준 철회(사용자 결정: 결이 잔 계열로 전환) |
| 결이 잔 잔디 레퍼런스 + 카툰 강조 문구 | 녹색 계열이 거의 단색으로 나옴 |
| 레퍼런스 없이 art_style = Western Cartoon | 선명한 카툰 잔디 덩어리. 녹색 계열끼리 색 평균을 맞추면 섞어도 경계가 거의 안 보임 → **채택 후보 세트** |

- 녹색 계열(잔디·잡초·꽃)은 저장 시 채널 평균·표준편차를 기준 잔디에 맞춘다(경계 감소 확인).
- 선정 후보: 잔디 wgrass 1~4(1장 부족), 잡초 wweed 1·3·4, 꽃 wflower 1·3·4.
