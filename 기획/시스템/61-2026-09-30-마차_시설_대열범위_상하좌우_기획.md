# 마차·시설 대열 범위 상하좌우 기획

작성일: 2026-09-30
상태: 확정(사용자 결정, 2026-09-30). **2026-09-30 기획 65번(마스크 데이터화)이 §3.1 저장 방식을 대체** — 상하좌우 4열은 삭제 예정. 작업 브랜치 `system`.
선행 기획: [59-2026-09-28-마차_중심_대열_기획.md](59-2026-09-28-마차_중심_대열_기획.md)(마차 중심 대열 — §6 "영역 모양 확장(직사각형)" 후속 항목을 이 문서에서 다룬다)

## 1. 배경

지금 마차·시설은 테이블의 `Radius` 값 1개로 대열 영역을 정한다. 영역은 중심 칸에서 상하좌우로 같은 거리만큼 뻗은 **정사각형**뿐이다(반경 4 = 9 × 9). 이번 변경에서는 방향마다 거리를 따로 정해 **직사각형** 영역을 만들 수 있게 한다.

## 2. 범위

- 포함: 마차·시설 테이블 열 구성, 영역 모양 규칙, 디버그 핀 입력, 마을 정비창 칸 표시 범위.
- 제외: 마차·시설 회전, 영역 모양의 추가 확장(십자·원 등), 연결·배치·제거 규칙(기획 59번 그대로).

## 3. 확정 사항 (사용자 결정, 2026-09-30)

### 3.1 영역 모양과 데이터

| 항목 | 결정 |
|---|---|
| 결과 모양 | **직사각형**. 마차(시설) 칸이 중심이며 가로 = 좌 + 1 + 우, 세로 = 상 + 1 + 하 |
| 저장 방식 | 테이블에 **상·하·좌·우 열 4개**. 각 값 = 중심 칸에서 그 방향으로 뻗는 칸 수 |
| 기존 `Radius` 열 | **삭제**. 4개 열로 교체 |
| 기본값 | 4개 열 모두 **4**. 기존 5종 전부 같은 값을 옮기므로 현재 동작(9 × 9)은 그대로 유지된다 |
| 값 범위 | 0 이상 정수. 0이면 그 방향으로는 뻗지 않는다 |
| 방향 기준 | **정비창 격자 화면 기준** — 상 = 화면 위쪽. **회전 없음**(배치된 개체가 방향을 바꾸지 않는다) |
| 판 가장자리 | 기존과 같다 — 50 × 50 판을 넘는 부분은 잘린다 |

**예시**

| 상 | 하 | 좌 | 우 | 영역 |
|---|---|---|---|---|
| 4 | 4 | 4 | 4 | 9 × 9 = 81칸 (지금과 같음) |
| 1 | 1 | 4 | 4 | 가로 9 × 세로 3 = 27칸 |
| 3 | 0 | 2 | 2 | 가로 5 × 세로 4 = 20칸 (중심 칸이 맨 아래 줄) |

### 3.2 적용 대상

| 대상 | 결정 |
|---|---|
| 마차 (`Wagon.xlsx`) | 상·하·좌·우 열 적용 |
| 시설 (`Facility.xlsx`) | 상·하·좌·우 열 적용 |
| 디버그 핀 | 반경 입력칸 1개를 **상·하·좌·우 입력칸 4개**로 교체. 기본값은 각 4. 핀 영역도 같은 직사각형 규칙을 따른다 |

### 3.3 마을 정비창 칸 표시 범위

| 항목 | 결정 |
|---|---|
| 지금 | 대열 경계 + (가장 큰 마차 반경 + 1) |
| 변경 | 대열 경계 + (**배치된 모든 마차의 상·하·좌·우 값 중 최댓값** + 1)을 사방에 똑같이 적용 |
| 최대 축소 범위 | 변경 없음(대열 + 2칸) |

- 방향별로 따로 계산하는 방식(예: 왼쪽 여백 = 마차 '우' 최댓값 + 1)은 채택하지 않았다. 규칙이 단순해지는 대신 일부 방향에 칸이 조금 더 깔린다.

## 4. 변경 없음 (기획 59번 유지)

- 연결 판정(영역이 맞닿으면 연결), 마차 제거 조건, 시설 자리(마차·핀 영역 안), 영역 밖 유닛 자동 해제, 마을 정비창 마차 자유 배치, 상행 중 마차 이동만 허용.
- 영역이 직사각형이 되어도 "영역 = 마차·시설·핀 영역의 합집합"이라는 정의는 그대로다.

## 5. 설계 단계로 넘길 기술 과제

- 테이블 열 이름(영문) 결정, 임포터·카탈로그·유닛 계약에서 반경 값 1개를 방향 값 4개로 교체.
- 영역 계산(정사각형 추가 로직)을 직사각형으로 일반화.
- 디버그 패널 재조립(입력칸 4개) — 인스톨러 재실행 필요.
- 전투 쪽 영향 확인 — 전투 대열 범위는 영역 결과에서 계산되므로 직접 영향은 없을 것으로 보이나 **미확인**. 정비창의 상/하가 전투의 전방/후방 중 어느 쪽에 대응하는지도 **미확인**.
- 관련 EditMode 테스트(영역 계산) 갱신.
