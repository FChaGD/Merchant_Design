# 기초 아이콘·UI 에셋 기획

작성일: 2026-11-23
상태: 확정 (2026-11-23)
참고: [98 재화 HUD 상단 보유 현황](98-2026-10-20-재화_HUD_상단_보유현황_기획.md) §4-4(아이콘 자리·용병&시설 묶음), [106 퀘스트 시스템](106-2026-10-27-퀘스트_시스템_기획.md) §4.4(평판 칸), [01 게임 개요](01-2026-08-25-게임개요_핵심루프.md)(중세 판타지 상단 운영 컨셉)

---

## 1. 목적

Hub 메인 화면의 자리표시자(흰 사각형 아이콘, 단색 버튼·패널)를 AI 생성 에셋(Ludo AI)으로 바꿔 기본 아트 방향을 잡는다. 이번 범위는 **Hub 메인 화면**에 한정하고, 적용 후 인게임 품질을 판단해 다른 화면으로 확장할지 정한다.

## 2. 작업 플로우

기획 확정 → 생성 → 퀄리티 검증·판단 → 유니티 적용 → 인게임 적용 퀄리티 판단 (사용자 지시 2026-11-23).

## 3. 아트 스타일

| 항목 | 내용 |
|---|---|
| 기준 | 골드 아이콘 시안 **E**(볼록한 가죽 주머니 + 목 부분 금화 더미 + 앞면 금화 1개)를 스타일 기준으로 쓴다(사용자 결정 2026-11-23). 나머지 에셋은 이 이미지를 스타일 레퍼런스로 생성한다 |
| 특징 | 카툰풍(Western Cartoon). 평면에 가까운 밝은 채색, 약한 면 나눔, 거친 질감 없음, 어두운 외곽선, 밝은 황갈색·금색 계열, 투명 배경, 단일 오브젝트 |
| 근거 | 기획 문서에 아트 스타일 정의가 없어 후보 시안을 비교해 사용자가 결정. 경과: 잉크 페인터리 시안 3번 선택 → 카툰풍으로 조정 요청 → Cel-Shaded(A·B)·Western Cartoon(C·D) 비교 → "화풍은 C, 형태는 B" → B를 원본으로 C 화풍을 입힌 편집본 E·F 중 **E 확정** |

## 4. 에셋 목록

### 4.1 아이콘 (4종)

| Id | 표시 위치 | 소재 | 비고 |
|---|---|---|---|
| Gold | 재화 HUD 골드 칸 | 볼록한 가죽 주머니 + 목 부분 금화 더미 + 앞면 금화 1개 | 시안 E를 그대로 사용(추가 생성 없음) |
| Wagon | 재화 HUD 마차 칸 | 천 덮개 짐마차(측면) | |
| MercenaryFacility | 재화 HUD 용병&시설 칸(`용병 수/시설 수`) | 용병 투구와 교차한 검 + 정란(공성병기). 투구·검이 정란과 반쯤 겹친 구도 | 기획 98 §4-4: 용병·상단 시설 유닛을 아이콘 하나로 묶음(사용자 결정) |
| Reputation | 재화 HUD 평판 칸 | 서 있는 하얀 사람 형체 + 노란 계열 후광 | 사용자 결정 |

- 인벤토리 단축 버튼 4종·마을 카테고리 버튼 4종은 **아이콘을 넣지 않고 글자만 유지**한다(사용자 결정). 이 8종은 생성하지 않는다.

### 4.2 UI 프레임 (2종)

| Id | 용도 | 재질 |
|---|---|---|
| PanelFrame | 패널 배경 | 양피지 바탕 + 가죽 테두리(사용자 결정) |
| ButtonFrame | 버튼 배경(기본 상태 1종) | 양피지 바탕 + 가죽 테두리, 패널보다 테두리가 얇은 형태 |

- 두 프레임 모두 9-slice(테두리 고정·가운데 늘림)로 쓴다. 가운데 영역은 늘려도 무늬가 깨지지 않는 단순한 양피지 질감이어야 한다.
- 버튼 상태별(호버·눌림·비활성) 이미지는 만들지 않는다. 상태 표현은 Unity 버튼의 색 변화(Color Tint)를 그대로 쓴다.

## 5. 적용 범위 (Hub 메인 화면만, 사용자 결정)

| 대상 | 현재 | 변경 |
|---|---|---|
| 재화 HUD 패널 배경 | 검정 60% 반투명 | PanelFrame |
| 재화 HUD 아이콘 3칸(골드·마차·용병&시설) | 흰 사각형 자리표시자 | Gold·Wagon·MercenaryFacility |
| 재화 HUD 평판 칸 | `평판 0` 글자만 | `[Reputation 아이콘][숫자]` — 다른 칸과 같은 형식, "평판" 글자는 뺀다(사용자 결정) |
| 날짜 HUD 패널 배경 | 검정 60% 반투명 | PanelFrame |
| 상행 준비·정비창·방향성 지시 버튼 | 종류별 단색 | ButtonFrame |
| 마을 카테고리 버튼 4종 | 베이지 단색 | ButtonFrame (글자만) |
| 인벤토리 단축 버튼 4종 | 하늘색 단색 | ButtonFrame (글자만) |

- 버튼은 **ButtonFrame 1종으로 통일**하고 종류별 색을 입히지 않는다. 구분은 글자로 한다(사용자 결정).
- 양피지 바탕이 밝으므로 위 요소들의 글자색을 흰색에서 어두운 갈색 계열로 바꾼다.
- 범위 밖: 마을 카테고리 진입 후의 시설 버튼·뒤로 가기, 시설 화면·팝업·모달, Field 씬. 인게임 판단(§2 마지막 단계) 후 확장 여부를 정한다.

## 6. 저장 규격 (사용자 결정: 추천 규격)

| 종류 | 경로 | 크기 |
|---|---|---|
| 아이콘 | `Assets/Resources/UI/Icons/` | 128×128 PNG (HUD에서 32px로 표시) |
| 프레임 | `Assets/Resources/UI/Frames/` | PNG, 임포트 시 9-slice 테두리 설정 |

- 생성 원본(약 768px)은 저장하지 않는다. Ludo 결과 URL은 7일 후 만료되므로 생성 직후 내려받아 저장한다.
- 스타일 기준 시안 E의 Ludo URL은 2026-11-30경 만료된다. 그 뒤 스타일 레퍼런스가 필요하면 `Resources/UI/Icons/Gold.png`를 업로드해 쓴다.

## 7. 퀄리티 판단 기준

### 7.1 생성 직후 (원본·축소본 비교)

| 항목 | 기준 |
|---|---|
| 스타일 일관성 | 골드 시안 E와 외곽선 굵기·채색 방식·색 온도가 나란히 놓았을 때 어긋나지 않음 |
| 32px 가독성 | 32px 축소본에서 소재를 구분할 수 있음 |
| 배경 | 투명 배경, 체크무늬나 잔여 배경 없음 |
| 소재 일치 | §4.1·4.2 소재 설명과 일치(특히 MercenaryFacility의 투구·검·정란 겹침 구도) |
| 프레임 | 9-slice로 늘렸을 때 테두리 왜곡·가운데 무늬 반복 티가 나지 않음 |

### 7.2 인게임 적용 후

| 항목 | 기준 |
|---|---|
| 대비 | 배경 이미지 위에서 패널·버튼이 구분되고, 글자를 읽을 수 있음 |
| 조화 | 아이콘·프레임·배경 톤이 한 화면에서 따로 놀지 않음 |
| 겹침 | 평판 칸 형식 변경 후 재화 HUD 폭 안에 들어가고 다른 UI와 겹치지 않음(UI 배치 겹침 점검 규칙) |

- 기준 미달 시 해당 에셋만 재생성한다.

## 8. 미정 사항

| 항목 | 비고 |
|---|---|
| 다른 화면(시설 화면·팝업·Field)으로의 확장 | 인게임 판단 후 결정 |
| 평판 "평판" 글자 제거 후 의미 전달(툴팁 등) | 후속 |
| 버튼 상태별 전용 이미지 | 필요 시 후속 |
