## 1. 배경 — 현재 재화 HUD (코드 조사, 2026-10-20)

| 항목 | 현황 |
|---|---|
| 위치 | Hub 우상단, 화면 가로 30%, 위·오른쪽 여백 32px. 모달 팝업이 열려도 가려지지 않는 층에 있음 |
| 내용 | 한 줄: 골드 아이콘 + `소유 골드 (마차 적재량 n)` |
| 입력 | 패널 배경 전체가 입력 대상 — 짧게 클릭 = 골드 상자 변환 모달, 호버·길게 누름 = 소지 가능량 툴팁 |
| Field | 재화 HUD 없음 |
| 주변 | 날짜 HUD는 화면 위 가운데. 재화 조절 디버그 줄이 재화 패널 아래에 붙어 있음 |

## 2. 범위

- 포함: 재화 HUD에 보유 마차 수, 고용한 용병 수, 보유 시설 수 표시.
- 제외: Field 재화 HUD, 상단 운영 인터페이스(94번 §3.4 향후 확장).

## 3. 확정 사항 (사용자 결정, 2026-10-20)

| 항목 | 결정 |
|---|---|
| 추가 표시 | 재화 HUD에 **보유 마차 개수, 고용한 용병 수, 보유 시설 수**를 추가 |

## 4. 확정 사항 (2026-10-20)

| # | 항목 | 추천 | 근거 |
|---|---|---|---|
| 4-1 | 배치 | **골드까지 포함해 한 줄**(사용자 결정 2026-10-20): `[골드 아이콘] 소유 골드 (마차 적재량 n)  [마차 아이콘] 마차 수  [용병&시설 아이콘] 용병 수/시설 수`. 패널 폭은 화면 30% 고정 유지, 내용이 넘치면 **글자 크기를 줄여 맞춤**(사용자 결정) | 골드 HUD 30% 고정(2026-09-23 확정) 유지 |
| 4-2 | 입력 | **골드 부분만** 반응(짧게 클릭 = 변환 모달, 호버·길게 누름 = 소지 가능량 툴팁). 마차·용병&시설 부분은 입력 없음(사용자 결정 2026-10-20 — 지금 패널 배경 전체인 골드 변환 접근을 골드 부분으로 좁힘) | 보유 수를 눌러 변환 모달이 열리지 않게 |
| 4-3 | 표시 순서 | 골드 → 마차 → 용병/시설 | 4-1 표기 순서 |
| 4-4 | 표기 | 아이콘 + 숫자. 용병과 시설은 **아이콘 하나에 `용병 수/시설 수`로 묶음**(사용자 결정 2026-10-20 — 둘 다 실제 전투에 영향을 주는 유닛이라 묶음, "용병&시설 아이콘"). 아이콘은 **지금은 자리만**(흰 사각형 자리표시자, 사용자 결정). 상한 표기 없음(80번 보유 상한 폐기) | — |
| 4-5 | 세는 기준 | 마차·시설 = 지금 보유한 개체 수(파괴·매각되면 제외). 용병 = 고용 중인 캐릭터 수(배치 여부 무관, 사망은 80번에 따라 영구 제거되어 제외) | 정비창 팔레트 보유 수와 같은 기준 |
| 4-6 | 갱신 | 고용·구매·전투 정산 등으로 바뀌면 즉시 갱신 | 골드 표시와 같은 방식 |
| 4-7 | 디버그 줄 | 한 줄 유지라 높이 변화는 작지만, 글자 축소·아이콘 추가로 재화 조절 디버그 줄과 겹치면 **디버그 줄을 아래로 옮긴다**. 좌표는 설계 단계 Play 실측 겹침 점검으로 확정 | CLAUDE.md UI 배치 겹침 점검(디버그 UI를 먼저 옮김) |

## 5. 확인 결과

- **"시설"의 뜻**: 마구간에서 사는 **상단 시설 유닛**(정비창에 배치, 실제 전투에 영향)이다 — 마을 시설 아님(사용자 확인 2026-10-20).

## 6. 남은 미정 사항 (후속)

- Field(상행 중) 재화·보유 현황 표시.
- 보유 현황 줄의 클릭 동작(상단 운영 인터페이스 진입점 후보 — 94번 §3.4).
