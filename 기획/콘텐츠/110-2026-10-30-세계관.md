## 1. 지리

Merchant의 무대는 부마누-지그라 대륙과 나양호-이마라 대륙을 잇는 대지협이다.

| 지명 | 위치·성격 |
|---|---|
| 부마누-지그라 대륙 | 북쪽 대륙 |
| 나양호-이마라 대륙 | 남쪽 대륙 |
| 쿠르도리아 제국 | 인간의 제국. 부마누-지그라 대륙으로 이어지는 길목을 틀어막고 있다 |
| 토워마 왕국 | 쿠르도리아에서 바다 건너 서남쪽의 5군도. 수인족의 발상지 |
| 릴츠시아 | 토워마 남쪽, 나양호-이마라 대륙과 떨어진 거대한 섬 |
| **잔트미안-아룻바사 지대** | **주 무대.** 릴츠시아에서 바다 건너 동쪽, 쿠르도리아 남쪽, 나양호-이마라 북쪽. 두 대륙의 교차점이자 광활한 지역으로, 다양한 종족·국가·부족이 존재하는 "춘추전국" 같은 혼란과 기회의 땅 |

### 1.1 무대 범위

- 주 무대는 잔트미안-아룻바사 지대다.
- 다른 지역(쿠르도리아·토워마·릴츠시아·양 대륙)이 플레이 지역이 되는지는 **미정**. 경우에 따라 다른 지역의 외곽 도시를 방문할 수는 있다.

## 2. 종족

| 종족 | 영문 식별자 | 지향 |
|---|---|---|
| 인간족 | Human | 번영과 지배를 추구 |
| 용인족 | Dragon | 지식을 갈구. 감정과 본능이 결여된 생물 |
| 수인족 | Beast | 강설·설파·전도 같은 사상의 확장을 추구 |
| 장이족(엘프) | Long_Ear | 영원한 것을 추구하고 숭배 |
| 제장족(드워프) | Iron_Hander | 끝없는 변화·발전·진보를 추구하고 숭배 |
| 신환족(천사) | Fathring | 종교적 고찰과 실행을 목표로 삼는 통찰의 종족 |
| 취혈족(뱀파이어) | Vampir | 취기 — 본능적·본질적인, 거부할 수 없는 감각을 추구 |
| 몽열족(서큐버스·몽마) | Succuber | 열락 — 욕망·성취처럼 제어·조절 가능한 쾌락을 추구 |
| 정령족 | Sprit | 미정 |
| 어인족 | Seaborn | 미정 |
| 거인족 | Giant | 미정 |
| 기타 | — | 미정(추가 종족 존재) |

## 3. 주인공(상단주)

- 종족·출신 등 정체는 게임 끝까지 밝혀지지 않는다. 플레이어의 상상과 결정에 맡긴다.
