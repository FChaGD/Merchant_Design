# 발단 기술 점검

작성일: 2026-11-05
상태: 점검 결과(콘텐츠 기획 플로우 3단계 — 후보 표시만, 구현 판단은 4.5단계 뒤). 작업 브랜치 `content`.
대상: [114 발단 콘텐츠 배치](114-2026-11-05-발단_콘텐츠_배치.md). 기준: 메인 저장소 `content` 브랜치 코드(`ef8de85`).

분류: **가능** = 현행 시스템에 데이터·대본만 넣으면 됨 / **확장** = 기존 시스템 수정·연결 필요 / **신규** = 해당 시스템 없음.

---

## 1. 공통 규칙

| 항목 | 분류 | 현행 근거 |
|---|---|---|
| 시작 시 전 기능·UI 잠김, 단계별 해금 | 신규 | 기능 해금 상태를 관리하는 시스템 없음. 해금 조건의 원천 후보로 이벤트 이력의 플래그(Yarn 참/거짓 변수와 공유)가 있음 |
| 지구 표시(소속 시설 사용 가능 시) | 확장 | 시설 제공 판정(`ITownFacilityAvailabilityReader`, 마을 규모 기준)이 이미 "제공 시설 1개 이상이면 지구 노출"로 파생됨. 해금 판정을 이 판정에 결합하면 됨 |
| 메인 퀘스트 상시 열림 | 확장 | 퀘스트 종류 Main, 후속 자동 수락, 목표(도착·납품·전투 승리) 있음. 트리거형·이벤트형 수락은 정의만 있고 동작 미연결(설계 107 §6.5). 퀘스트 목록 UI 없음(상인조합 화면에서만 의뢰 표시) — 메인 퀘스트 표시 UI는 신규 |
| 상행 준비 해금 전 자동 목적지 배정 | 확장 | 도착지 지정기(`ITripDestinationAssigner`)는 있으나 상행 준비 화면에서 고르는 경로뿐. 시나리오가 목적지를 정해 출발시키는 경로 없음 |
| 정보 획득으로 도시·상행로·게이트 공개 | 신규 | 지도는 지역의 도시·관문·도로를 전부 표시. 발견(공개) 상태 없음 |
| 습격 인카운터(전투)는 #5 이후 | 확장 | 상행 중 랜덤 전투 판정(구간 난이도 기반 확률)은 상시 동작. 조건부로 끄는 장치 없음 |

## 2. 위치별

| # | 항목 | 분류 | 현행 근거 |
|---|---|---|---|
| 1 | 산길의 마차에서 시작(새 게임 시작 위치) | 신규 | 게임 시작은 Hub, 현재 위치 최초값은 도시 4(임시값). 상행 도중에서 시작하는 흐름 없음 |
| 1 | 이벤트 방식 대화 출력 | 가능 | Field 이벤트 화면(설계 89) |
| 1 | Field 상행 진행 | 가능 | 해금 여부는 §1 해금 시스템에 의존 |
| 1 | 최초 확정 이벤트 인카운터 | 가능 | 이벤트 발생 방식 Fixed(확정) + 조건(진행률·지역·도로·플래그·본 이벤트·퀘스트 등) |
| 2 | 이피네 동행 | 가능 | 이벤트 명령 `join`(캐릭터 합류). 이피네를 상단원으로 다룰지는 4단계 |
| 2 | 상행 중 대화 | 가능 | 상행 대화(설계 88). 해금 여부는 §1 |
| 2 | 최초 확정 도시 진입 이벤트 | 확장 | 이벤트 장소는 상행·휴식 2종뿐, 마을 진입 시점 장소 없음. Hub 이벤트 화면은 휴식 이벤트용으로 있음(재사용 후보) |
| 3 | 숙소 | 가능 | 숙소 휴식(설계 105·109) |
| 3 | 한 번에 하루만 휴식(아룻바사 이후 해제) | 확장 | 휴식 일수 범위가 1~30 고정 상수. 단계별 상한 없음 |
| 3 | 최초 휴식 중 확정 이벤트 | 가능 | 휴식 장소 + Fixed |
| 4 | 주점 | 신규 | 시설 Id·카탈로그 항목만 있고 화면·기능 없음. 획득 정보의 종류·방식은 기획 24 미정 |
| 4 | 지도(별도 화면) | 신규 | 상행 준비 화면 안의 지도 표시(`TripMapPresenter`)만 있음. 재사용 후보 |
| 5 | 알아낸 도시·상행로 추가 | 신규 | §1 정보 공개와 같음 |
| 5 | 마구간·무역품 구매·상행 준비·용병단 접촉·정비창 배치 | 가능 | 모두 구현됨. 해금 여부는 §1 |
| 5 | 상단 결성 후 첫 인접 마을 이동부터 습격 인카운터 | 확장 | §1 습격 인카운터와 같음 |
| 6 | 잡화상점 | 신규 | 시설 Id·카탈로그 항목만 있고 화면·기능 없음 |
| 6 | 다른 지역 게이트 공개 | 신규 | 관문 데이터·지역 전환은 있음. 공개 상태는 §1 정보 공개와 같음 |
| 7 | 출발 당일 마을 습격 | 가능 또는 확장 | 상행 출발 직후 확정 이벤트 + 이벤트 명령 `battle`이면 가능. 마을 안에서 일어나야 하면 #2 마을 장소 이벤트와 같은 확장 |
| 7 | 산맥을 넘어 아룻바사로 | 가능 | 관문 짝을 통한 지역 간 상행 |

## 3. 4단계 전에 확인할 점

결정(2026-11-05): 마을 규모 → 규모별 기본 시설 + 마을 개체별 추가 시설(확장, 116 #E7). 공통 UI → 골드는 #1 기초 자금 습득 시, 날짜는 #2 첫 마을 입성 시, 상단 물류품 인벤토리는 #5 무역품 구매와 함께 해금(114 반영). 저장/불러오기 → 신규 제작 요소(116 #N7).

| 항목 | 내용 |
|---|---|
| 마을 규모와 시설 | 주점·용병단 접촉·마구간은 "도시" 규모 이상에서만 제공된다(기획 57). 숙소·무역품 구매·잡화상점은 촌락에서도 제공. 아블린다 마을들의 규모를 정할 때 반영 필요 |
| 공통 UI 해금 시점 | 골드 HUD·날짜 표시·상단 물류품(무역품 적재) 팝업 등 화면 공통 UI의 해금 시점이 배치에 없음. 인벤토리는 아룻바사 이후 해금인데, #5 무역품 구매는 상단 물류품 적재를 쓴다 |
| 저장/불러오기 | 저장 시스템 없음(현재 위치도 Play 세션 동안만 유지). 해금 상태도 같은 제약을 받음 |
| 데이터 | 지역·도시·용병·아이템·이벤트 데이터는 전부 Placeholder·테스트용. 아블린다·아룻바사 지역과 도시는 5단계에서 새로 입력 |

## 4. 요약

| 분류 | 항목 |
|---|---|
| 신규 | 기능 해금 시스템, 정보 공개(도시·상행로·게이트), 새 게임 시작 흐름, 주점, 지도 화면, 잡화상점 |
| 확장 | 지구 표시 결합, 메인 퀘스트(트리거형 수락·표시 UI), 시나리오 목적지 배정, 습격 인카운터 조건부 차단, 마을 진입 이벤트 장소, 휴식 일수 상한 |
| 가능 | 이벤트 화면, 확정 이벤트(상행·휴식), 동행(`join`), 상행 대화, 숙소, 마구간·무역품 구매·상행 준비·용병단 접촉·정비창, 지역 간 상행 |
