# 콘텐츠 기획 전제 조건

작성일: 2026-11-05
상태: 확정(2026-10-30 세션 확정 사항 문서화, 2026-11-05 엔딩을 단일→멀티로 개정). 작업 브랜치 `content`.
용도: 콘텐츠 기획 전 단계(러프 시나리오·배치·상세화)에 공통으로 적용하는 구조 전제. 세계관은 [110 세계관](110-2026-10-30-세계관.md) 참조.

## 1. 시나리오 구조

| 항목 | 내용 |
|---|---|
| 핵심 시나리오 | 플레이를 견인한다. 진행할수록 게임 능력·활동 범위가 확장된다(§3) |
| 사이드 시나리오 | 연계 퀘스트 또는 단일 퀘스트. 특정 인물·사건을 마무리하며, 사이드 스토리별로 엔딩이 있다 |
| 막과 지역 | 시나리오는 막 단위로 나누지 않는다(2026-11-05 개정, 이전: 막은 사건 기준). 지역은 시나리오와 별도로 확장한다 |
| 완주 목표 | 메인 시나리오 15~30시간 |
| 엔딩 | **멀티 엔딩**(2026-11-05 개정, 이전: 단일 엔딩). 모든 엔딩에서 엔딩 이후에도 계속 플레이할 수 있다 |

## 2. 상인 갈래

시나리오와 별개인 플레이 축. 5종을 동시에 병행할 수 있다(섞어서 플레이).

| 갈래 | 성격 |
|---|---|
| 밀수꾼 | 지역에서 허용하지 않는 상품 취급 |
| 호위 전문 | 지역 간 이동 지원, 전투 위주 |
| 대상단 | 돈벌이, 상단 운영 |
| 모험가 | 숨겨진 비밀·유물 |
| 개척가 | 지역·도시 확장 |

| 관계 | 내용 |
|---|---|
| 핵심 시나리오 | 해금으로만 연결된다 |
| 사이드 시나리오 | 구조상 완전 별개. 단, 테마 차원에서 특정 갈래와 밀접한 사이드 콘텐츠를 배치하는 것은 가능 |
| 지속성 | 시나리오와 별개로 지속되며, 엔딩 이후에도 계속 플레이한다 |

## 4. 기획 플로우

| 단계 | 내용 | 작업 성격 |
|---|---|---|
| 1 러프 시나리오 | 줄거리 | 기획 |
| 2 콘텐츠 배치 | 시나리오 위치마다 필요한 콘텐츠 분류 | 기획 |
| 3 기술 점검(배치 단위) | 현행 시스템으로 가능/확장/신규 후보 **표시만** | 정보수집 |
| 4 상세화 | 서사(대본·인물·지명)는 확정, 수치(가격·보상·스탯·난이도)는 범위·의도까지 | 기획 |
| 4.5 가벼운 기술 점검 | 상세화 결과 대조. 추가 시스템 구현(설계→제작)은 이 뒤에 진행 | 정보수집 |
| 5 콘텐츠 적용 | 테이블·Yarn 반영, 수치 조정. 테스트·Placeholder 콘텐츠(E1~E4·QuestTest·Rest_*·"직업이름N" 등) 교체·삭제·디버그 분리 포함 | 제작 |
| 6 플레이 검증·조정 | 결과를 다음 구간의 배치·상세화에 반영 | 검증 |

- 진행 방식: 버티컬 슬라이스. 시나리오의 한 구간을 2~6단계까지 끝까지 통과시킨 뒤 다음 구간으로 확장한다(1단계 러프 시나리오는 전체 대상).
- 첫 구간: [112 핵심 시나리오 러프](112-2026-11-05-핵심_시나리오_러프.md) §3.1 발단(깨어남~산맥을 넘어 아룻바사로, 2026-11-05 확정).
- 원칙: 콘텐츠 기획 중에는 기존 시스템을 과도하게 의식하지 않는다. 콘텐츠를 먼저 상세화하고, 기존 시스템 분류에 들어가는 요소만 분류하며, 들어가지 않으면 신규로 뺀다.
