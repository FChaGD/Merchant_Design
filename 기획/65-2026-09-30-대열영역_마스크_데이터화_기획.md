## 1. 배경

지금 마차·시설의 대열 영역은 상·하·좌·우 4열로 정하는 **직사각형**뿐이다(기획 61번). 적재 공간처럼 **마스크 문자열**로 적어 직사각형이 아닌 모양(십자, L자, 한쪽으로 치우친 모양 등)도 만들 수 있게 한다.

## 2. 범위

- 포함: 마차·시설 테이블의 대열 영역 열, 마스크 표기 규칙, 디버그 핀 입력, 마을 정비창 칸 표시 범위.
- 제외: 회전, 연결·배치·제거 규칙(기획 59번 그대로), 적재 공간 마스크(기획 63번 그대로).

## 3. 확정 사항 (사용자 결정, 2026-09-30)

### 3.1 표기 규칙

| 항목 | 결정 |
|---|---|
| 저장 방식 | **마스크 문자열 1열**. `/`는 줄 구분(위 줄부터) |
| 문자 | `1` = 대열 칸, `0` = 대열 아님, **`2` = 기준 칸**(마차·시설이 놓인 칸) |
| 기준 칸 | 마스크 안에 **정확히 1개**. 기준 칸도 대열 칸이다 |
| 결과 모양 | 마스크 모양 그대로. 배치하면 기준 칸이 마차·시설 위치에 오도록 판 위에 겹친다 |
| 방향 | 정비창 격자 화면 기준(위 줄 = 화면 위쪽), 회전 없음(기획 61번과 같음) |
| 판 가장자리 | 판 밖으로 나가는 칸은 잘린다(기존과 같음) |
| 입력 규칙 | 줄 길이가 모두 같을 것, `0`/`1`/`2` 이외 문자 없음, `2`가 정확히 1개. 어기면 임포트 오류 |

예시:

| 마스크 | 모양 |
|---|---|
| `010/121/010` | 기준 칸 + 상하좌우 1칸 = 십자 5칸 |
| `111/111/121` | 기준 칸이 맨 아래 가운데, 위로 2줄 뻗은 3 × 3 |
| `1111111/1111111/1111111/1112111/1111111/1111111/1111111` | 7 × 7 정사각형(지금 값 상3·하3·좌3·우3과 같음) |

### 3.2 테이블

| 항목 | 결정 |
|---|---|
| 대상 | `Wagon.xlsx`, `Facility.xlsx` 데이터 시트 |
| 기존 열 | `Up`/`Down`/`Left`/`Right` **삭제** |
| 새 열 | 마스크 1열(열 이름 예: `AreaShape`) |
| 초기값 | 지금 값(전 행 3/3/3/3)을 옮긴 **7 × 7 전부 대열, 가운데 기준 칸** — 현재 동작이 유지된다 |

### 3.3 디버그 핀

| 항목 | 결정 |
|---|---|
| 입력 | 상·하·좌·우 입력칸 4개 → **마스크 문자열 입력칸 1개** |
| 형식 | 마차·시설과 같은 규칙(§3.1) |
| 형식 오류 | 핀을 놓지 않고 디버그 패널에 안내 문구 표시 |
| 기본값 | 지금 핀 기본값(각 4 = 9 × 9)과 같은 9 × 9 전부 대열, 가운데 기준 칸 |

### 3.4 마을 정비창 칸 표시 범위

| 항목 | 결정 |
|---|---|
| 지금 | 대열 + (마차 상하좌우 값 중 최댓값 + 1), 사방 균일 |
| 변경 | 대열 + (**기준 칸에서 가장 먼 대열 칸까지의 가로·세로 거리 중 최댓값** + 1), 사방 균일 |
| 비교 | 7 × 7 가운데 기준이면 3 + 1 = 4칸 — 지금과 같다 |

### 3.5 떨어진 조각 (2026-09-30 추천안 채택)

| 항목 | 추천 | 근거 |
|---|---|---|
| 떨어진 조각 허용 | 허용한다 — 대열 칸이 기준 칸과 이어져 있지 않은 마스크(예: `101/020`)도 유효 | 연결 판정이 칸 단위라 규칙 추가 없이 그대로 동작한다. 막아야 할 이유가 생기면 임포트 검증에 추가 |

## 4. 변경 없음

- 연결 판정(영역이 맞닿으면 연결), 마차 제거 조건, 시설 자리(마차·핀 영역 안), 영역 밖 유닛 자동 해제, 마을 정비창 마차 자유 배치, 상행 중 마차 이동만 허용(기획 59번).
- 전투 대열 범위는 영역 결과(경계 상자·마차 중심)에서 계산하므로 규칙 변경 없음(기획 61번 설계 62번 §8 확인 결과와 같음).

## 5. 설계 단계로 넘길 기술 과제

- 기획 61번의 방향 범위 값 타입(`FormationAreaSpan`)을 마스크 모양 타입으로 대체. 적재 모양 파서(`InventoryShape`, `0`/`1`)와 표기 규칙이 비슷하므로 공용화할지 판단.
- 영역 계산: 직사각형 추가를 "기준 칸 기준 오프셋 목록 추가"로 일반화.
- 디버그 패널 재조립(입력칸 4개 → 1개 + 안내 문구) — Build Hub Scene·Build Field Scene 재실행.
- 임포터 검증(§3.1 입력 규칙), 엑셀 2종 열 교체.
- 영역 계산 테스트 갱신(십자·치우친 모양·떨어진 조각·판 가장자리 잘림).
