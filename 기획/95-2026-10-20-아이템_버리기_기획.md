## 1. 배경

인벤토리 그리드에서 아이템을 없앨 수단이 없다. 팝업 밖에 놓으면 원래 자리로 돌아가고(39번), 판매도 없어 그리드가 가득 차면 비울 수 없다. 이 문서는 아이템을 영구히 삭제하는 "버리기" UI를 정한다.

## 2. 범위

- 포함: 쓰레기통 아이콘, 드래그 드롭 버리기, 쓰레기 선택 상태 버리기, 안내 경고 모달, 적용 대상 UI.
- 제외: 판매(판매 시스템 기획), 버린 아이템의 회수·되돌리기.

## 3. 확정 사항 (사용자 결정, 2026-10-20)

| 항목 | 결정 |
|---|---|
| 진입 수단 | 쓰레기통 아이콘 |
| 방식 1 — 드래그 드롭 | 아이템을 쓰레기통 아이콘에 드래그 드롭 → 안내 경고 모달 → 확인 시 버림 |
| 방식 2 — 선택 상태 | 쓰레기통 아이콘 클릭 → **쓰레기 선택 상태**로 전환 → 버릴 아이템 선택 → 확인 → 안내 경고 모달 → 확인 시 버림 |
| 적용 대상 | **아이템과 관련된 모든 UI** |
| 39번 원칙 변경 | "버리기 없음" 폐기. 단 팝업 바깥(쓰레기통 외) 드롭은 지금처럼 원위치 복귀 |

## 4. 확정 사항 — 조작·표시 (추천안 그대로 확정, 2026-10-20)

### 4.1 적용 대상 UI (코드 조사 기준, 2026-10-20)

| # | UI | 위치 | 추천 |
|---|---|---|---|
| 4-1 | 인벤토리 팝업 4종(상단 물류품·전투 장비·전투 소모품·개인 물품) | Hub | 적용 |
| 4-2 | 무역품 구매 화면 좌측 상단 물류품 패널 | Hub 시설 | 적용 |
| 4-3 | 숙소 우측 탭 그리드 3종 | Hub 시설(94번) | 적용 |
| 4-4 | 전투 후 회수 적재 패널 | Field | 적용 — 지금도 [완료] 시 임시 보관 잔여분이 버려지므로 같은 조작을 명시적으로 제공 |

### 4.2 조작 규칙

| # | 항목 | 추천 | 근거 |
|---|---|---|---|
| 4-5 | 아이콘 위치 | 각 그리드 패널 하단 오른쪽(정렬 버튼 옆) | 그리드마다 하나. 실제 좌표는 설계 단계 겹침 점검으로 확정 |
| 4-6 | 선택 상태 다중 선택 | 여러 개 선택 가능(클릭으로 선택/해제 토글), 선택한 아이템 강조 표시 | 한 번에 여러 개를 비우는 용도 |
| 4-7 | 선택 상태 UI | 아이콘 옆에 "확인 / 취소" 버튼과 "n개 선택" 표시. 확인은 1개 이상 선택 시만 활성 | 상태 전환이 화면에 드러나야 함 |
| 4-8 | 선택 상태 해제 | 취소 버튼 또는 쓰레기통 아이콘 재클릭. 버린 뒤에도 해제 | 일반 상태로 확실히 복귀 |
| 4-9 | 선택 상태 중 다른 조작 | 드래그·회전·정렬 막음 | 선택 클릭과 드래그 시작이 겹치지 않게 |
| 4-10 | 임시 보관 아이템 | 버리기 대상에 포함(드래그·선택 둘 다) | 임시 보관을 비우는 수단이 됨 |
| 4-11 | 경고 모달 문구 | "다음 아이템을 버립니다. 되돌릴 수 없습니다." + 아이템 이름 목록(같은 이름은 "이름 ×n") + 확인/취소 | 영구 삭제 안내 |
| 4-12 | 골드 상자 | 버릴 수 있음. 모달에 "골드 상자 n개(골드 x)가 사라집니다" 추가 경고 | 82번: 상자 제거 시 환급 없음 → 골드 손실을 따로 알림 |
| 4-13 | 모달 구현 | 기존 공용 확인 대화상자(회수 적재 완료 확인·마을 출발 경고가 쓰는 것) 재사용 | 같은 "메시지 + 확인/취소" 구조 |
| 4-14 | 취소 시 | 드래그 버리기는 원위치 복귀, 선택 상태 버리기는 선택 유지한 채 선택 상태로 복귀 | 다시 고를 수 있게 |

## 5. 남은 미정 사항 (후속)

- 버리기가 판매 시스템과 공존할 때의 역할 분담(판매 불가 아이템만 버리기 등).
- 퀘스트 아이템 등 버릴 수 없는 아이템 종류(아이템 데이터 미정).
