## 1. 배경

상인조합 게시판은 UI만 있고(기획 94 §4.3, Placeholder 퀘스트 3건) 퀘스트 자체의 규칙이 없다. 이 문서는 퀘스트 공통 체계를 정하고, 이번 구현 범위를 상인조합 의뢰 수락형으로 한정한다.

## 2. 범위

| 구분 | 내용 |
|---|---|
| 공통 체계(이번 정의) | 수락 형태 3종, 핵심·보조 목표, 실패 조건, 상행 영향, 보상, 후속, 분류(메인/일반·단발/반복) |
| 이번 구현 | 상인조합 **의뢰 수락형** 일반 퀘스트 + 목표 5종 + 상행 영향 + 보상(재화·평판·아이템) + 평판 수치 + 게시판 상세 확장 + 의뢰 화물 경고 팝업 |
| 구조만(적용 안 함) | 트리거형·이벤트형 수락, 메인 퀘스트, 유닛 보상(로직 구조까지 제작) |
| 범위 밖(별도 기획) | 퀘스트 목록 UI(진행 중·완료·실패 이력), 메인 퀘스트 실패 흐름(게임오버/재도전), 평판 효과(가격·인카운터), 시청 퀘스트, 저장/불러오기 |

## 3. 공통 체계

### 3.1 수락 형태

| 형태 | 내용 | 이번 |
|---|---|---|
| 트리거형 | 이벤트 이후 퀘스트가 발동하면 자동 수락 | 구조만 |
| 이벤트형 | 이벤트 결과에 따라 수락 여부·퀘스트 종류가 결정 | 구조만 |
| 의뢰 수락형 | UI 루트(게시판)에서 수락 | 구현 |

### 3.2 분류

| 축 | 값 |
|---|---|
| 종류 | 메인(핵심 시나리오 줄기) / 일반(곁다리) |
| 반복 | 단발성(1회 클리어) / 반복성(여러 번 수주) |

### 3.3 목표

| 구분 | 규칙 |
|---|---|
| 핵심 목표 | 1개 이상 필수. **모두** 충족해야 성공 |
| 보조 목표 | 0개 이상. 추가 보상·트리거(후속 분기 등)의 기준 |

목표 유형(핵심·보조 공용, 값은 퀘스트 데이터로 지정):

| 유형 | 판정 |
|---|---|
| 도착 | 지정 도시에 상행 도착 |
| 납품 | 지정 품목·수량을 지정 도시로 가져감. 물품은 **완료 시점**에 화물에서 차감(즉시 완료형 = 대상 도시 도착 시, 보고형 = 보고 시) — 그 전까지 화물에 남아 손실 위험 유지 |
| 기한 | 기한 내 달성. 기준은 **수락일부터 N일** 또는 **고정 날짜** — 퀘스트마다 선택 |
| 전투 승리 | 승리 횟수. 집계 대상(적 진영 종류 필터, 확정 전투 한정 여부)은 퀘스트마다 지정 |
| 보존 | **의뢰 화물** 손실 없음 |

### 3.4 완료

- 완료 방식은 퀘스트마다 지정: **즉시 완료**(핵심 목표 충족 시점) / **보고**(지정 도시 상인조합 게시판에서 보고).
- 보고 장소는 퀘스트마다 지정한 도시의 상인조합.

### 3.5 실패

| 조건 | 내용 |
|---|---|
| 기한 초과 | 기한 목표가 핵심인 경우 |
| 핵심 목표 불가 | 예: 의뢰 화물 손실·버리기·판매로 납품 불가 |
| 플레이어 포기 | 일반 퀘스트만. **메인 퀘스트는 포기 불가** |

- 일반 퀘스트 실패 불이익: 퀘스트마다 지정(평판 감소, 위약금(골드), 없음).
- 메인 퀘스트 실패: 게임오버 또는 재도전에 준하는 흐름으로 넘김(세부는 메인 퀘스트 기획 시).
- 단발성 실패·포기 후: 퀘스트마다 지정(일정 일수 후 재게시 / 영구 소멸).

### 3.6 상행 영향

퀘스트마다 지정. 수락 중인 퀘스트가 상행에 다음을 주입한다.

| 항목 | 내용 |
|---|---|
| 적용 상행 | 퀘스트마다 선택: 목적지가 대상 도시인 상행 / 수락 중 모든 상행 |
| 난이도 변경 | 상행 난이도 가산 |
| 확정 이벤트·전투 | 지정 사건 발생. 횟수는 퀘스트마다 선택(퀘스트당 1회 / 적용 상행마다). 발생 시점은 **진행률 지정**과 **무작위 시점** 둘 다 제작, 퀘스트마다 선택 |

### 3.7 보상

| 항목 | 내용 |
|---|---|
| 종류 | 평판·아이템·재화·유닛. 이번 구현은 재화·평판·아이템. 유닛은 지급 로직 구조까지만 제작(적용은 캐릭터 생성 규칙 이후) |
| 보조 목표 추가 보상 | 지급 시점은 퀘스트마다 지정(성공 시 일괄 / 달성 즉시) |
| 명성 | 기획 23의 **평판과 같은 수치** |

### 3.8 후속 퀘스트

퀘스트마다 지정: 성공 시 지정 게시판에 등장 / 자동 수락. 보조 목표 달성 여부로 후속 분기 가능.

## 4. 이번 구현 상세 (상인조합 의뢰형)

### 4.1 게시판

| 항목 | 결정 |
|---|---|
| 게시 구성 | 대도시별 등장 퀘스트를 데이터로 지정. 단발성은 완료까지 게시, 반복성은 완료·실패 후 일정 일수(퀘스트마다) 뒤 재게시 |
| 수락 조건 | 퀘스트마다 지정(선행 퀘스트 완료·최소 평판, 없으면 무조건). 미충족은 목록에 나타나지 않음 |
| 동시 수락 | 무제한 |
| 목록 상태 | 수락 가능(그 조합 게시) · 진행 중(그 조합에서 수락) · 보고 가능(그 조합이 보고처). 완료·실패는 목록에서 제거(이력은 퀘스트 목록 UI 기획에서) |
| 상세 확장 | 퀘스트 목록 UI가 생기기 전까지 우측 상세에서 목표 진행·기한 표시, 포기·보고 버튼 |

### 4.2 의뢰 화물

| 항목 | 결정 |
|---|---|
| 출처 | 퀘스트마다 지정: 수락 시 지급 / 플레이어 조달 |
| 취급 | 일반 무역품과 동일(적재 칸 차지, 피격 손실, 버리기·판매 가능) |
| 경고 팝업 | 의뢰 화물을 버리거나 팔 때 확인/취소 팝업(의뢰 화물임과 퀘스트 이름, 수행 불가 가능성 안내). 확인 후 핵심 목표가 불가해지면 실패 |
| 실패·포기 시 지급 화물 | 퀘스트마다 지정(회수 / 남김) |

### 4.3 적재 공간 부족

| 상황 | 처리 |
|---|---|
| 수락 시 지급 화물 | 공간이 부족하면 수락 불가 |
| 보고형 보상 아이템 | 수령 불가 → 보고 차단 |
| 즉시 완료형 보상 아이템 | 기존 **임시 보관**에 수령 후 기존 정리 UI 흐름(인벤토리 팝업 임시 보관 영역)으로 넘김 |

### 4.4 평판

- 수치만 구현: 저장, 증감, HUD 표시. 효과(가격·인카운터)는 기획 23대로 미정 유지.
- 0에서 시작, 범위 제한은 인스펙터(기본 −100~100).
- 표시: 재화 HUD 옆 항목 추가. 배치 전 겹침 점검.

### 4.5 데이터·저장

- 퀘스트·목표·보상 등은 엑셀 테이블(기존 데이터 파이프라인).
- 진행 상태는 런타임 유지만. 저장 시스템 제작에 대비해 저장 대상(수락 퀘스트·목표 진행·만료일·재게시 예정일·평판·완료 이력)을 설계 문서에 기록해 둔다.

## 5. 미정·후속

- 퀘스트 목록 UI(진행·완료·실패 이력 표시, 포기 조작 이관).
- 메인 퀘스트 실패 흐름, 트리거형·이벤트형의 이벤트 연결 방식.
- 유닛 보상 적용(기획 80 4-10 캐릭터 생성 규칙 이후).
- 평판 효과, 시청 퀘스트, 저장/불러오기.
- 실제 퀘스트 콘텐츠(데이터 행)는 제작 시 테스트용 소수만 — 값 없는 텍스트는 "값 없음".
